# Производственный пайплайн видеозаписи — Stepik-релиз (RU)

Рабочий документ для записи видеоверсии курса «Deep Learning for Search».
Видео записывает человек; всё, что можно подготовить заранее (сценарии, нарезка, тайминги,
маркеры кликов), лежит в этой папке: `l00-script.md` … `l03-script.md`.

---

## 1. Формат

**Скринкаст офлайн-дека + закадровый голос по сценарию.**

- Источник изображения: standalone-дек `Lectures/NN-slug.html` (собирается `npm run build`),
  открытый в браузере по `file://` — сеть не нужна, дек спроектирован под **1920×1080**.
- **RU-режим:** в деке горячая клавиша **`L`** переключает язык RU↔EN (кнопка есть и в тулбаре
  по клавише `T`); выбор запоминается. Перед записью один раз нажать `L` → все слайды по-русски.
- Другие горячие клавиши (пригодятся при записи): `F` — фулскрин, `D` — светлая/тёмная тема
  (записывать в одной теме на весь курс; рекомендация — светлая), `→`/`Space` — следующий
  шаг/слайд (степперы внутри слайда шагаются той же стрелкой), `←` — назад, `Esc`/`O` — обзор
  (в записи не использовать).
- Голос: закадровый, по посегментным сценариям `lNN-script.md` (тезисы диктора на русском,
  маркеры `[КЛИК: …]`, `[ПАУЗА …]`, `[ПОКАЗАТЬ КУРСОРОМ …]` уже расставлены).
- Говорит преподаватель от первого лица, на «ты» — тем же голосом, что и книга курса.
  Серёга и прочие маскоты — персонажи на слайдах, диктор ссылается на них в третьем лице.

## 2. Инструменты (всё бесплатное/стандартное)

| Задача | Инструмент | Настройки |
|---|---|---|
| Захват экрана | **OBS Studio** | Canvas и output 1920×1080, 30 fps, CRF ~18–20; источник — окно браузера в фулскрине на 1080p-дисплее (или дисплей 4K с масштабом 200% — тогда захват области 1920×1080) |
| Браузер | Chrome/Edge | `file://…/Lectures/NN-slug.html`, `L`→RU, `F`→фулскрин; скрыть курсор-«хвосты»: системный курсор стандартного размера |
| Голос | Любой конденсаторный USB-микрофон + поп-фильтр | 48 кГц, mono; тихая комната; расстояние до микрофона постоянное |
| Запись/чистка звука | **Audacity** или Reaper | Noise reduction по профилю комнаты, компрессор, нормализация до **−16 LUFS** (стандарт для e-learning) |
| Суфлёр | Второй монитор/планшет с открытым `lNN-script.md` | Читать не дословно — тезисы написаны как устная речь, допускается живая вариация |
| Монтаж | **DaVinci Resolve** (free) или ffmpeg для склейки | Резать по сегментам из сценария; jump-cut оговорок; экспорт H.264, 1080p, ~8–10 Mbps, AAC 192 kbps |

**Два допустимых режима записи** (выбрать один и держаться его):
1. **Одновременно** (проще монтаж): читаешь сценарий и кликаешь по маркерам, звук пишется в OBS
   отдельной дорожкой. Ошибся — пауза 2 с, повтор фразы с начала абзаца, вырезается на монтаже.
2. **Раздельно** (чище звук): сначала начитка сегмента по сценарию, потом прогон экрана под
   готовую дорожку (в сценариях есть оценка длительности каждого слайда — по ней темп кликов).

## 3. Нормы

- **Длительность одного видео (урока): 5–12 минут.** Нарезка на такие сегменты уже сделана в
  сценариях — по актам дека (агенда → акты → синтез); один сегмент = одно видео на Stepik.
- Темп речи: ~130 слов/мин; оценки в сценариях посчитаны от этой нормы + 10–15 с/слайд на
  паузы и клики. Если сегмент вылезает за 12 минут — в сценарии указано, где резать.
- Каждое видео начинается с одной фразы-крючка (есть в сценарии) и заканчивается мостиком
  к следующему сегменту — не обрывать на полуслове степпера.
- Один дубль-прогон «вхолостую» перед записью сегмента обязателен (клики степперов должны
  быть отрепетированы — их последовательность и число шагов указаны в маркерах).

## 4. Структура релиза: ранний доступ

По `data/course.json`: основной курс — **13 модулей (L0–L12)**; офлайн-семестр шёл 7 недель по
2 пары в неделю (пара = 2 лекции). Для Stepik темп мягче:

- **Запуск (ранний доступ): модули L0–L3 готовыми** — это ровно те четыре, на которые уже
  написаны съёмочные сценарии (`l00`–`l03`), плюс Лаба 1 и A1 (задания и автогрейдеры уже
  портированы на Stepik — `stepik/graders/…` в `src/lib/assignments.js`).
- Дальше — **«модуль в неделю»**: L4 через неделю после запуска, …, L12 на 9-й неделе.
  Это соответствует смысловому темпу офлайн-расписания (там модуль ≈ полпары) с запасом
  на самостоятельные лабы.

| Неделя релиза | Выходит | Вехи |
|---|---|---|
| 0 (запуск) | L0, L1, L2, L3 | Лаба 1 (BM25), выдать A1 |
| 1 | L4 (метрики ранжирования) | дедлайн A1 |
| 2 | L5 (эмбеддинги) | |
| 3 | L6 (контекстные эмбеддинги, трансформеры) | Лаба 2 (каскад) |
| 4 | L7 (би-/кросс-энкодеры) | выдать A2 |
| 5 | L8 (ColBERT, SPLADE, LTR) | |
| 6 | L9 (ANN, FAISS, векторные БД) | Лаба 3 (ANN) |
| 7 | L10 (основы RAG) | |
| 8 | L11 (оценка RAG, агентный RAG) | выдать A3 |
| 9 | L12 (продвинутый RAG, мультимодальность, этика) | финальный проект |
| 10+ | бонус-деки (L13–L20: негативы, rewriting, BERT, late chunking, энтропия, геометрия, схемы, русский поиск) | как «глубокие погружения» для удержания |

Сценарии для L4+ пишутся тем же конвейером, что и `l00`–`l03` (нарезка по актам из
`Lectures/NN-slug/parts/`, notes → разговорный русский): один модуль сценария ≈ 1 сессия работы,
писать с опережением минимум на 2 недели от графика выхода.

## 5. Чеклист качества (перед заливкой каждого видео)

- [ ] Дек в **RU-режиме** (клавиша `L`), тема одна и та же во всех видео.
- [ ] Захват ровно 1920×1080, без масштабных артефактов, без панелей ОС/браузера.
- [ ] Все маркеры `[КЛИК: …]` из сценария отработаны (степперы дощёлканы до конца — недокликанный
  степпер = пропавший контент).
- [ ] Звук: −16 LUFS, без клиппинга, без «горохового» шума; первая и последняя секунда — тишина.
- [ ] Длительность в норме 5–12 мин; название видео = названию сегмента из сценария.
- [ ] Логистика аудитории заменена на реплики `[Stepik-версия]` из сценария (никаких «в пятницу
  в 106-й аудитории»).
- [ ] На финальном слайде каждого модуля — устный мостик к следующему видео/модулю.
