# Передача слайдов дизайнеру — что в пакете и как с ним работать

Пакет собирается из исходников курса двумя командами (см. «Как пересобрать» внизу).
Результат: по одному `.pptx` на лекцию + папка ассетов.

---

## 1. Что внутри каждого `.pptx`

| элемент дека | во что превратился | можно ли править |
|---|---|---|
| заголовок, подзаголовок, буллеты, подписи, таблицы | **настоящие текстовые рамки** с сохранением жирного/курсива | да, это текст |
| AI-иллюстрации (`Lectures/assets/img/...`) | вставленный PNG на своём месте | как картинку |
| интерактивные виджеты (80 шт., SVG) | снимок элемента с прозрачным фоном | как картинку |
| формулы (KaTeX) | **исходный TeX прямо в тексте** — `\(x\)` и `\[x\]` | да, как текст |
| заметки докладчика | заметки к слайду в PowerPoint | да |

Рядом с каждым `.pptx` лежит папка **`ref/`** — рендер каждого слайда 1920×1080 ровно
таким, каким его видит студент. Это эталон: pptx несёт **редактируемое содержимое**,
`ref/` показывает **желаемый результат**. Сверяться нужно с ним, а не с тем, как
PowerPoint отрисовал текстовые рамки.

**Геометрия точная.** Позиции сняты из браузера в собственном пространстве дека
1920×1080 и перенесены один в один: 1 пиксель макета = 1/144 дюйма. Слайд PowerPoint —
13,333×7,5 дюйма. Ничего не переверстывалось «на глаз».

**Язык.** По умолчанию экспортируется **русский** слой (курс выходит на русском).
Английский доступен ключом `--lang en` — деки двуязычные.

## 2. Чего ждать не надо (честные ограничения)

- **Шрифты.** В макете использованы IBM Plex Sans, Newsreader, JetBrains Mono и
  рукописный Pangolin (кириллица). Если их нет в системе, PowerPoint подставит свои —
  имена шрифтов в файле проставлены правильно, достаточно поставить сами шрифты
  (все под лицензией SIL OFL, лежат в `Lectures/vendor/fonts/`).
- **Метрики текста.** Браузер и PowerPoint верстают строку по-разному. Рамки сделаны с
  небольшим запасом, но длинная строка может перенестись иначе, чем в деке. Это нормально:
  дизайнер всё равно будет перекладывать.
- **Виджеты — картинки.** Они интерактивные (шаги, анимации); в pptx попадает то
  состояние, в котором слайд открывается. Если нужен другой шаг — скажите, экспорт умеет
  снимать конкретные шаги.
- **Формулы — текстом, а не картинкой.** В тексте стоит исходник вида `\(k_{\text{neg}}=5\)`.
  Так абзац вокруг формулы остаётся редактируемым; как формула должна выглядеть — смотрите
  в `ref/`. В финальном макете их нужно набрать заново (или мы отрендерим их отдельными
  прозрачными PNG — скажите, если так удобнее).
- **Обратной дороги нет.** Источник истины — фрагменты `Lectures/<дек>/parts/*.html`.
  Правки, сделанные в pptx, **в курс не вернутся**: сайт, офлайн-деки и книга собираются
  из исходников. Поэтому pptx — это макет для дизайна, а не рабочая копия контента.
  Итог работы дизайнера нужно переносить обратно в CSS/фрагменты.

## 3. Фирменный стиль — то, что дизайнеру нужно знать до начала

Источник: `tokens/design-tokens.css` (один файл, светлая и тёмная темы).

**Поверхности и текст (светлая тема)**

| роль | HEX |
|---|---|
| фон страницы | `#FAF6ED` (тёплая бумага) |
| фон карточки | `#FFFFFF` |
| фон-вставка | `#EBE7DA` |
| основной текст | `#14181F` |
| вторичный текст | `#3D434E` |
| приглушённый | `#6B7280` |

**Акценты**

| роль | HEX |
|---|---|
| основной синий | `#2A6FDB` |
| синий для текста | `#1B4FA0` |
| тёплый (акцент-2) | `#E8743B` |
| красный · зелёный · янтарный | `#D7522C` · `#3A8A5C` · `#E0A82E` |
| фиолетовый · циан · розовый | `#7D5BA6` · `#1AA7B5` · `#C9447A` |

У каждого акцента есть «мягкая» подложка (`*-soft`) — см. токены.

**Шрифты**

- заголовки и текст — **IBM Plex Sans**
- акцидентный серифный — **Newsreader**
- моноширинный (код, числа) — **JetBrains Mono**
- рукописный (титулы, разделители) — **Patrick Hand** (латиница) + **Pangolin** (кириллица)

**Жёсткое правило бренда.** Зелёный цвет в иллюстрациях используется **только** для
тюбетейки маскота Серёги. Это проверяется автоматическим гейтом (`_research/check_images.py`);
если в новом дизайне появится зелёный в других местах — сборка курса упадёт.

**Сетка.** Кадр 1920×1080. Поля, размеры карточек и шкала кеглей заданы в
`Lectures/css/` (`slides.css`, `components.css`). Пол читаемости: 11 px для текста
слайда (гейт `readability-gate`), фигуры масштабируются отдельно.

## 4. Как пересобрать пакет

```bash
# 1) снять геометрию и ассеты (браузер; ~1–2 мин на дек)
node scripts/export-pptx-extract.mjs                      # все деки, RU
node scripts/export-pptx-extract.mjs 13-crucible-of-negatives.html --lang en

# 2) собрать .pptx из снятого
_research/.venv-pptx/bin/python scripts/build_pptx.py     # все извлечённые
_research/.venv-pptx/bin/python scripts/build_pptx.py 13-crucible-of-negatives
```

Результат: `_internal/pptx-export/_pptx/<дек>.pptx`, ассеты — рядом в
`_internal/pptx-export/<дек>/fig/`.

Зависимость `python-pptx` живёт в отдельном окружении `_research/.venv-pptx` и на курс
не влияет: студенческий рантайм остаётся без тяжёлых зависимостей (ограничение H5).
Каталог `_internal/` не попадает в репозиторий — пакет для дизайнера передаётся файлами.
