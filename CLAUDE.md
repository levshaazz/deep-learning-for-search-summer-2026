# Deep Learning for Search — repo map

Course site (Astro) + offline lecture decks + trilingual Book + vanilla-JS SVG widgets, gated by 22 numbered CI gates (G1–G24, no G4/G5) + a facts-gate. **Goal when editing: touch the fewest files; load one unit, not the repo.** This map exists so you don't have to re-derive structure each session.

## Where things live
- `Lectures/<slug>/parts/*.html` — **the editable deck source** (one fragment per `<section class="slide">`, plus `00-head`/`zz-tail`). All 21 decks (L0–L20) are sharded.
  - `Lectures/NN-*.html` — the **offline standalone deck** (shipped artifact; loads `css/ js/ vendor/` relatively, runs over `file://`, 1920×1080, EN). It is **BUILD OUTPUT** (gitignored): `npm run build` reassembles it byte-identically from the fragments (`scripts/assemble-deck.mjs build`). **Do not edit it** — edit the fragments.
- `content/book/<stem>/beats/*.js` — **the editable Book chapter source** (one fragment per beat, trilingual en/ru/tt). `content/book/lN.js` is the assembled chapter — **BUILD OUTPUT** (gitignored), reassembled byte-identically by `npm run build` (`scripts/assemble-chapter.mjs build`); **don't edit it**, edit the beat fragments. Glob-discovered via `src/lib/chapters.js` (adding a chapter needs no registration).
- `widgets/<name>/` — `logic.js` + `manifest.json` + `i18n.json` + `style.css` (+ `demo-slide.html`). Shared primitives: `widgets/_widget-base.js`, `_plot-util.js`, `_layout.js`. Auto-registered.
- `data/*.json` — **the single source of grounded numbers** (facts-gated). `data/course.json` = lecture catalog + logistics. Reproduced by `_research/gen_*.py`; `_research/data/*.json` are upstream generator artifacts.
- **⚠ TWO numberings coexist, deliberately.** The Aug-2026 reorder renumbered the *curriculum* (deck dirs `Lectures/NN-slug/`, book chapters `content/book/NN/` + the `id:` in their `00-head.js`, `data/course.json`, all prose refs "L7"). It did **NOT** renumber the *production* artifacts: `data/lNN-*.json`, `_research/gen_lNN.py`, and `Lectures/assets/img/LNN/` keep the numbers they were generated under — renaming them would break H3 byte-identity for zero benefit. So `data/l20-ru.json` legitimately feeds the deck now called `19-russian-search`, and `gen_l7_real.py` ("Scouts and Judges") feeds `10-bi-cross-encoders-reranking`. **This is not drift — do not "fix" it.** The old→new map lives in `_internal/plans/SYLLABUS-v2.md`.
- `_research/check_claims.py` — **facts-gate** (data→generator provenance, deck displays == data, arithmetic). Run: `python3 _research/check_claims.py` (`--selftest` too).
- `narrative/style-ru.md` — **the RU editorial style guide + approved glossary** (обращение «ты», decimal comma, term canon: чанк/эмбеддинг/би-энкодер/трудный негатив/развязка…). Any RU prose edit follows it; `scratchpad`-style fixers + the `check_style.py` linter enforce the mechanical half.
- `narrative/practice-standard.md` — **the floor under every seminar/lab notebook** (the practice analogue of the deck Definition of Done below). Derived by measuring 6 real notebooks: the exemplar reads its own results 27 times, the weak ones 1–3 — that ratio, not cell count, is what separates a live seminar from a script dump. Fixes the thresholds (≥80% of substantive code cells followed by markdown analysis · ≥8 traps across ≥4 of 6 types · 3–5 tasks each with an `assert` · two-layer `<details>` solutions), the runtime (Colab T4 free tier driven from VS Code — so no `#@param`, no `files.upload()`, no ipywidgets) and the markers (§15a) its gate reads. The gate is live: `python3 _research/check_practice.py` (**G24**, 10 HARD + 4 WARN, `--selftest`, `--measure "tmp/*.ipynb"` re-derives the thresholds). Check #1 — *did the notebook read its own result* — is the only one that separates the exemplar (81%) from the five below-bar notebooks (21–61%); three of those five clear the prose-share threshold, so the gate must never be reduced to word counting. Seminars live in `seminars/` (see its README for the 7 slots). **Write no seminar without the standard.**
- `stepik/` — Stepik release kit: `scripts/stepik-export.mjs` renders the Book's RU layer into 470 step HTML files + `manifest.json` (gitignored output), `stepik/graders/` holds the offline autograders; widgets embed via `src/pages/embed/[widget].astro` (`?lang=ru`).

Инструкция и фирменный стиль: `release/design-handoff.md`. Зависимость `python-pptx` живёт в gitignored `_research/.venv-pptx` — студенческий рантайм не трогает (H5).

## Per-task recipes (touch only these)
- **Fix one slide:** edit the fragment `Lectures/<slug>/parts/<NN-slug>.html`, then `node scripts/assemble-deck.mjs build <slug>` (or `npm run build`) to reassemble `Lectures/<slug>.html`. Never edit the assembled `Lectures/NN-*.html` (it's gitignored build output and gets overwritten). Verify: `cd _audit && node wbw-check.mjs <slug>.html` (+ `node slide-viz-gate.mjs --strict`, whose curated per-figure targets sit on L6/L7) and `node offline-deck.mjs <slug>.html` for the `file://` guarantee.
- **Change one number:** edit `data/<file>.json` (the source); re-run its generator and prove H3 byte-identity with `bash _research/reproduce.sh`; `check_claims` enforces deck==data, Book==data, AND (coverage-guard `[G]`) that no NEW displayed number is un-gated. The number is also hand-typed prose at each display site — `git grep` it across the deck + Book to update all copies (a new display site must be gated or it HARD-fails the coverage-guard).
- **Add a widget:** create `widgets/<name>/{logic.js,manifest.json,i18n.json,style.css}` — auto-discovered by Book, Playground, and `widget-render-check`.
- **Add lecture L7:** `data/course.json` entry + the Book chapter (write `content/book/l7.js`, then `node scripts/assemble-chapter.mjs split l7` to shard it — the monolith is gitignored, the `beats/` fragments are tracked) + the deck under `Lectures/07-slug/parts/`. Registries are glob-driven — `BOOK_READY`, `check_claims DECKS`, `wbw-check`, `responsive-gate`, book route, beat/scroll/i18n gates all auto-discover. (Curated `slide-viz` `DECK_TARGETS`/`BOOK_TARGETS` are optional per-figure defect targets, not per-unit registration.) **Illustrations:** add the briefs to `_research/gen_images.py` `JOBS` reusing the `mascots.py` cast — Séréga must appear in ≥40% of plates AND in the hero + final plate (the image-gate enforces this; don't ship Séréga-less abstract plates). Generate with `python3 _research/gen_images.py L7`.
- **Add homework/seminar:** `src/lib/assignments.js` — content-first, ~0 plumbing (the reference model).

## Hard constraints (do not break)
H1 decks are offline standalone (`file://`, zero network, 1920×1080, EN/RU). H2 Book is trilingual via i18n. H3 numbers come from `data/` + are reproducible/facts-gated (any data/generator change must leave `data/` JSON byte-identical: `check_claims` green + empty `git diff data/`; **prove with `bash _research/reproduce.sh`** — the full local toolchain is CPython 3.9 + vendored pylibs, spec frozen in `_research/requirements-repro.txt`). H4 the CI gates + facts-gate stay working (consolidate/strengthen, never weaken) — incl. the depth/asset/composition/readability gates **G17 `check_assets`** (every referenced/briefed illustration exists), **G18 `parity-gate`** (depth + no walls of text), **G19 `composition-gate`** (no frame overflow), **G20 `readability-gate`** (масштаб: no PROSE below the legibility floor — deck 11px / book 12px raw font), and **G13 `viz-probe`** which now HARD-fails a SEVERE label overlap (≥50% box cover — наложения), not just WARN; see the Definition of Done below. H5 no heavy runtime deps for students; widgets are vanilla-JS SVG.

## Verify before committing
`python3 _research/check_claims.py` (+`--selftest`) · `npm run build` (must be **204 pages**) · the relevant `_audit/` gate(s) · for an illustration/`gen_images.py` change: `python3 _research/check_images.py` (+`--selftest`) **and** `python3 _research/check_assets.py` (+`--selftest`) · for a seminar change: `python3 _research/check_practice.py` (+`--selftest`) · for a deck change: `node _audit/parity-gate.mjs` + `node _audit/composition-gate.mjs` + `node _audit/readability-gate.mjs` (+`--selftest`; G20 also covers the Book) · for a `data/`/generator change: `bash _research/reproduce.sh` (byte-identity, H3). Deep context + the refactor plan/log: `_audit-report/` (`CONTEXT-ARCH-AUDIT.md`, `REFACTOR-LOG.md`).

## Definition of Done for a lecture — gates are the FLOOR, L10–L12 are the BAR
**Green gates mean "no regression in correctness" — they do NOT mean "good."** The bar is: *indistinguishable from L10–L12 in depth + polish, proven by LOOKING at the rendered slides.* A lecture is born to this bar, never rebuilt to it. Before calling a deck done, every box must be ticked:
- [ ] **Depth ≥ ~50 slides** (L10–L12 = 50–63), one idea per slide, full scaffolding (you-are-here · agenda · objectives · per act: divider → hook → problem → formal → climb-widget → worked-by-hand → real example → frontier → boundaries · synthesis · references). **Build FROM the reference deck's structure, not from scratch.** → `node _audit/parity-gate.mjs` (**G18**).
- [ ] **No walls of text** — median ≤ ~1150 visible chars/slide; use def-cards / formula-stages / cmp-tables / images, never paragraphs. → parity-gate (**G18**).
- [ ] **Illustrations actually generated** — every `gen_images.py` brief → a committed PNG, every referenced image exists on disk, made with the course's reference model **`nano-banana-pro`** (not gpt-image-1). → `python3 _research/check_assets.py` (**G17**) + brand `check_images.py` (**G12**).
- [ ] **Composition holds** — no slide content overflows/clips the 1920×1080 frame. → `node _audit/composition-gate.mjs` (**G19**) + `slide-viz-gate.mjs` (**G9**) for figures.
- [ ] **Readable — scale + no collisions** — масштаб: no PROSE authored below the floor (deck 11px / book 12px raw); наложения: no figure-label collision ≥50%. → `node _audit/readability-gate.mjs` (**G20**) + `node _audit/viz-probe-gate.mjs` (**G13**, severe overlap now HARD). Figures fit-scale by design; their legibility is G9/G13's, not a raw-font concern.
- [ ] **Auto-fit ≥ 0.65, and never below 0.62** — `legibility-gate` (**G22**) HARD-fails under **0.62** and WARNs in the **0.62–0.65** band, because a slide authored at 0.61 passes on macOS and fails on CI's Linux (it did, twice). Aim for the target, not the floor. Sub-16px labels INSIDE figures are ratcheted by `viz-probe` against `_audit/baselines/viz-tiny-text.json`: NEW or WORSE is HARD. **Both baselines may only shrink** — re-freezing upward is how this debt grew in the first place.
- [ ] **Agenda anchors verified by CLICKING** — `#/N` is a slide POSITION, not the number in `data-screen-label`; the two diverge the moment a lettered insert (`25a`) lands. Navigate each anchor in a browser and confirm it reaches a divider — `check_narrative` agrees with the engine only since its section regex was fixed to match `class="… slide …"`, not `class="slide"` exactly.
- [ ] **You LOOKED at it** — `node _audit/composition-gate.mjs --contact NN-slug.html` → review every screenshot in `_internal/contact-sheets/NN-slug/` against L10–L12. **Never declare done on gate output alone.**

Why this list exists: each item is a failure mode that *shipped with every legacy gate green* (L13 once shipped at 13 dense slides, image-less, with an overflowing ablation slide). Sessions have no memory — the bar lives HERE + in the gates (**G17/G18/G19/G20** + **G13**), never in anyone's head.
