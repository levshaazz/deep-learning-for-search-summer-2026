# RUBRIC.md — per-iteration evaluation (used by the VLM reviewer + session self-check)

The reviewer reads the session's screenshots (light + dark) and the decks, scores each dimension
**0–5** (5 = excellent), lists concrete slide-level findings, and writes machine-readable JSON to
`session_NN/vlm.json` of the form:
```json
{ "session": N,
  "scores": { "narrative": 0-5, "examples": 0-5, "stepwise": 0-5, "templating": 0-5,
              "history": 0-5, "cases": 0-5, "layout": 0-5, "art": 0-5, "data_grounding": 0-5 },
  "blocking": [ "deck:slide — issue" ],         // must-fix before next session
  "findings": [ "deck:slide — issue + fix" ],   // prioritized
  "wins": [ "what improved this session" ] }
```

## Dimensions
1. **narrative** — slides in the right order; a clear through-line per deck; the lecture's
   catchphrase opens and closes; transitions make sense; no orphan slides.
2. **examples** — examples are complete and deep enough; concrete, not hand-wavy; cover the idea
   from first principles to a realistic instance.
3. **stepwise** — every step-by-step / worked example has a detailed breakdown that explains the
   task **formally AND** shows **every arithmetic operation** (no skipped steps; numbers visible).
4. **templating** — each slide uses the **correct template type** from our list for its content
   (definition→definition, derivation→formula/walkthrough, comparison→two-col/table, etc.).
5. **history** — historical context present where relevant; the **evolution / "why it came to be"**
   logic is visible (origins, timeline, what problem each step solved).
6. **cases** — application cases, corner cases and failure modes are **explicit and detailed**,
   not just named.
7. **layout** — auto-layout/auto-scale holds: **nothing overflows**, scale is right for a **large
   hall**, all charts/illustrations **fully visible**, light **and** dark both clean. (Most
   objective dimension — cross-check with `wbw-check` + the screenshots.)
8. **art** — illustrations match the locked style (marker-doodle, two accents); **Serega's
   tübetey is GREEN every time**; **no baked-in text/titles/"Wait But Why"**; art reads at hall
   scale; right art on the right slot (hooks/dividers/metaphors, never on precise schemes).
9. **data_grounding** — numbers/examples that *can* be data-grounded ARE generated by Python from
   **open datasets**, with the artifact saved under `_research/data/` and documented (source +
   script + output + how it maps to the slide). Flag any invented ("отсебятина") numbers.

## Hard gates (binary — a session FAILS if any is red)
- `wbw-check` is **0/0/0** on all three decks (slide counts as expected).
- No raw `$$`, math/code/QR render, light+dark both paint correctly.
- No illustration with baked-in style text or a non-green tübetey.
