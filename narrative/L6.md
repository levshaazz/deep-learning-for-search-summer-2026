(Measure). The **Transformer is the engine**; **attention** is how the crew decides who to heed; **contrastive
learning** shapes the space so retrieval works. Full transformer block taught (per decision), kept anchored to
"why this matters for search."

## Widgets & data (NEW)
- **`attention-e2e`** ← `data/l6-attention.json` — a small worked self-attention: tokens, \(Q,K,V\) matrices,
  \(QK^\top\) scores, \(/\sqrt{d_k}\), softmax weights, weighted-sum output; a 2-head variant. Steps:
  Q·Kᵀ → scale → softmax (attention heatmap) → ·V → output. (Can reuse the deck's existing `e2e` attention slide.)
- **`positional-enc`** ← `data/l6-positional.json` — the sinusoidal PE grid (pos × dim values); a viz/heatmap.
- **`transformer-block`** — the full encoder block as a deck **`archflow`** (attn → Add&Norm → FFN → Add&Norm,
  ×N); a stepped Book scrolly if cheap, else a static labeled figure.
- **`contrastive-space`** ← `data/l6-contrastive.json` — anchor/positive/negative vectors, their cosines, the
  loss; steps: scatter → pull positive in / push negatives out → loss drops. Sir Cosine powers the metric.
- Data gen: `_research/gen_l6.py` (reproducible; reuse the embedding pattern). Attention numbers can be a
  fixed small matrix (deterministic); contrastive over real L5 vectors; PE is closed-form. Facts-gate-checkable.
