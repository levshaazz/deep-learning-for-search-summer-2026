## Worked examples (precision beats — pošаговые, exact)
Computed by **`_research/gen_l4.py`** on the **same 20 Newsgroups sub-corpus + BM25 ranking from L3**
(continuity: we grade the very catalog we just built). Relevance = **same 20NG category** (qrels from
labels — the L1/L2/L3 convention). One running example: a query's top-10 ranked docs with a
relevant/not mark, e.g. ranks → `[R, ., R, R, ., ., R, ., ., .]` (4 relevant in top-10, say 6 total).
- **Recall@k / Precision@k:** at k=5: found 3 of 6 relevant → Recall@5 = 3/6 = 0.50; 3 of 5 retrieved
  relevant → P@5 = 0.60. Show how each moves as k grows.
- **MRR:** first relevant at rank 1 → RR = 1/1 = 1.0; average RR over the query set = MRR.
- **MAP:** AP = mean of P@k *at the ranks where a relevant doc appears* (P@1, P@3, P@4, P@7 …) / #relevant;
  MAP = mean AP over queries. Show the per-hit precision table and the average.
- **nDCG (headline):** graded gains (e.g. 3 = same subgroup, 1 = same top-category, 0 = off-topic).
  `DCG@k = Σ gain_i / log₂(i+1)`; `IDCG@k` = DCG of the ideal (sorted-by-gain) ranking;
  `nDCG@k = DCG/IDCG`. Walk the discount column (`1/log₂2, 1/log₂3, …`), the actual DCG, the ideal
  IDCG, and the ratio. End: nDCG@10 for our BM25 ranking — a single comparable number in [0,1].

## Python / data plan
`_research/gen_l4.py` (seeded; sklearn + numpy; imports L3's ranking output for continuity):
- reuse `data/l3-bm25.json` ranking (or recompute the same way); build qrels from 20NG categories.
- compute, for a small set of queries: Recall@k, P@k (k∈{1,3,5,10}), RR/MRR, AP/MAP, DCG/IDCG/nDCG@k.
- output `data/l4-metrics.json`:
  `{ query, ranked:[{id, rel(0/1), gain(0..3), rankInIdeal}], k:[...],
     recallAtK, precisionAtK, rr, ap, dcg, idcg, ndcg, mapOverQueries }`.
- a deliberately *gamed* ranking (stuff a popular-but-irrelevant doc at rank 1) to demonstrate the
  Goodhart beat: CTR-style "popularity" optimisation tanks nDCG. (Illustrative second list.)
- Lab tie-in (Fri): students compute nDCG@10 by hand on a 5-doc list, then verify with the script.
