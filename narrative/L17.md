## Thesis
Information is surprise: I(x) = −log₂ p(x). Entropy H = −Σ p log₂ p is *expected* surprise — and the
hard floor of compression (source coding theorem). English carries ~1 bit per letter (Shannon's
guessing game), far below the 4.7-bit naive estimate, because language leans on context (Markov).
Cross-entropy is the bill paid *above* the floor — exactly what a language model's loss measures —
and IDF from L3 is self-information wearing a retrieval uniform.

## Beats
1. **hook-telegraph** — after «th», the «e» is almost free: language is predictable, prediction is money.
2. **morse-e-dot** — the dot they gave to E: Morse already priced letters by frequency.
3. **information-quantity** — Hartley & Nyquist: "how much information" becomes a number via the logarithm.
4. **markov-onegin** — language is not a coin toss: the next letter leans on the last (Markov's Onegin count).
5. **the-bit-and-surprise** — the bit: a needle for surprise; I(x) = −log₂ p(x).
6. **climb-entropy-gauge** *(scrolly · `entropy-gauge`)* — turn p yourself: self-information → weighted
   contributions → the H(p) curve → our coin → the wrong model's KL wedge.
7. **entropy-formula** — entropy: the surprise I should expect, in bits; H = −Σ p log₂ p.
8. **biased-coin** — a crooked coin, by hand: H = 0.811 bit — less than a bit.
9. **entropy-of-english** — the gauge on English: 4.76 bits → down layer by layer toward the floor.
10. **guessing-game** — Shannon's guessing game: four letters in five, already known (~1 bit/letter).
11. **conditional-entropy** — the quantity the whole act was about, finally written: H(X|Y), the chain
    rule, and mutual information — worked on Markov's own 1913 counts (0.2247 bit for one letter of memory).
12. **source-coding-floor** — the floor no code can cross: Kraft, then the source coding theorem.
13. **optimal-code** — the code that lands exactly on the floor (the dyadic toy source).
14. **when-the-code-misses** — the ordinary case: Huffman overpays 0.0469 bit, and block coding walks
    1.0000 → 0.8158 down toward 0.8113. Why arithmetic coding exists.
9. **climb-letter-entropy** *(scrolly · `letter-entropy`)* — reshape the letters and watch the floor
   move: uniform ceiling vs the measured F₁, in the SAME unit (the trap slide 21b disarms).
15. **climb-huffman** *(scrolly · `huffman-build`)* — build the tree one merge at a time; watch L̄ fall
    to a floor that never moves.
16. **cross-entropy-bridge** — cross-entropy: the bill paid above the floor; H(p,q) = H(p) + KL(p‖q).
17. **bits-per-char** — the 1951 pencil and the neural net read the same gauge (bits-per-character today).
18. **idf-is-self-info** — IDF is Shannon's surprise: the L3 callback, opened.
19. **idf-almost** — and the label it needs: Robertson 2004 — event spaces, query terms, and the fact
    that a *summand* carries no coding theorem. Analogy, not identity.
20. **bits-in-the-index** — the same bill counted over postings; and BIC at 2.94 under a 3.02 "floor",
    because the floor belonged to the wrong source model.
21. **synthesis** — one gauge, one red line.
