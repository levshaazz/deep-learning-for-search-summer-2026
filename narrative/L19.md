## Thesis
Russian carries its grammar *inside* its words (fusional morphology), which sends three bills against a
pipeline built on English assumptions: a **token tax** (BPE fragments Russian into many more sub-words),
a **surface-form miss** (BM25 shares zero strings between query and answer), and an **embedder mismatch**
(an English-only encoder never saw the endings). One principle answers all three — and it is *not*
"normalize three times", because **act 3 performs no normalization at all**: there you choose a model and
hold one space. The thesis is **the same transformation on both sides**. For the lexical arm that
transformation is the analyzer (one declaration on the field, governing indexing and search alike); for the
dense arm it is the same encoder with the same `query:` / `passage:` prefixes on the corpus and on the
query. Every failure in the lecture — the fragmented token, the vanished negation, the corpus encoded by a
model the query never met — is one asymmetry somebody introduced and nobody measured. Measured payoff on
the toy: the gold answer's BM25 goes 0.0 → 1.3884 and it moves from *not retrieved at all* (its
postings list is empty, df = 0 — the old "rank 2" was only a stable-sort artefact among the zeros) to
rank 1, the moment the forms match.

## Data (H3 — reproducible generator, facts-gated)
`_research/gen_l20.py` (stdlib only, deterministic) → `data/l20-ru.json` (MEASURED toys). It now emits, on
top of the original three: a **stdlib port of the Snowball Russian algorithm** (regions RV/R1/R2 + 4 steps
+ the 2018 ё→е prelude), self-checked at generation time against a 36-word control list, so every stem in
the lecture comes from one source; a **three-pass BM25** over the same 5-doc corpus (surface / stem /
lemma) — the middle pass is the one the deck never ran, and it shows Snowball rescuing the gold doc from
the void but still ranking it behind the puppy; a **paradigm bench** (noun 12 slots→10 forms, verb 16,
adjective 18, plus the cases beyond the six-case table); the **stop-word trap** (*карта не работает* ≡
*карта работает* after stop-word removal); the **ё/е ladder** (recall 0.0 → 0.3333 → 0.6667, with
index-only folding *worse* than doing nothing); the **ЙЦУКЕН↔QWERTY layout map** (34 keys — this is what
corrects `cbthf` = *сиера*, not *сибирь*); the **homoglyph set** (7 lowercase / 12 uppercase Cyrillic
confusables); and the **byte count** (Cyrillic = 2 bytes per character, where the fragmentation begins).

`data/l20-bench.json` (CITED facts, `reported by <cite>` provenance) is extended with: **Savoy 2009**

## Beats
1. **hook-torn-forms** — the answer *котёнок играет* is in the corpus; search walks past *котята играют*.
2. **fusional-language** — one ending fuses several values; 6 cases × 2 numbers; the root hides.
3. **token-tax** — *widget-free image*: BPE trained on English shreds *запроса* into 7; 1.0 vs 5.8 tok/word.
4. **vocab-arc** — the tax is a vocabulary budget, not a law: ×5.74 → ×2.49 → ×1.42 across r50k / cl100k /
   o200k; 17 Cyrillic tokens in `r50k_base` (none with two Cyrillic characters in a row) vs 729 vs 14 211;
   ×1.089 characters but ×1.984 bytes; XLM-R = BGE-M3 = mE5 at ×1.17 (one number ties act 1 to act 3);
   ruBERT at ×0.67 — the only tokenizer where Russian is *cheaper*. Caveat: no public Claude tokenizer.
5. **surface-form-miss** — BM25 sums only over `t ∈ q ∩ d`; no shared string → score 0.0, wrong doc wins.
6. **lemma-vs-stem** — stemming (chop, cheap) vs lemmatization (dictionary form, homonymy); apply symmetrically.
7. **snowball-inside** — what the cheap tool actually does: RV/R1/R2 + 4 steps, *запросами* → *запрос* by hand;
   then the honest counterexamples from our own port (*котёнок / котята / котят* = three stems; *стал·сталь·стали*
   → one, *стать* → *стат*), the correction of the folklore *мир / мировой / мирный* example (three distinct
   stems — the real merges are *мир*+*мириться* and *небо*+*нёбо*), Segalovich 487 vs 41 lost conflations, and
   the lemmatizer's own blindness (*том* → *тот* at 0.896; PyMorphy2 91.23 vs oracle 94.08 = 3 points of homonymy).
8. **bm25-worked** — the inversion, measured: gold 0.0 (NOT retrieved) → 1.3884 (rank 1); distractor 1.3608.
9. **normalization-stack** — the analyzer: index-time chain + the *same* analyzer at query time (ES `russian`).
10. **the-negation-trap** — the warning label the previous beat lacks: in ES the stop filter runs *before* the
    stemmer, so *карта не работает* ≡ *карта работает*; Lucene's 159-entry stop list has **no ё forms**, so *всё*
    survives stop-word removal and *все* does not; cures (ё→е `char_filter` first, subtract negations, negation
    bigrams, dense arm) + the honest Savoy ~2 % caveat — the damage is in a query *class*, not in mean recall.
11. **dense-speaks-russian** — bi-encoder matches by cosine; sub-words + contrastive training absorb morphology.
12. **multilingual-vs-ru** — multilingual-E5 / BGE-M3 / LaBSE vs ru-specific; shortlist then evaluate on your data.
13. **benchmarks-translationese** — MIRACL (native) vs mMARCO (translationese) vs ruMTEB; the L5 Goodhart lesson.
14. **the-length-regime** — RusBEIR Table 5: sentences (17.6 w) BM25 13.58 vs FRIDA 20.79; w6 (105.8 w) BM25 31.54
    catches the multilinguals; full articles (2059 w) BM25 74.95 vs mE5-large 60.62. "Dense always wins" is a
    statement about chunk size → bridge to L10/L16. Plus the third bill: MIRACL-ru 0.334 / 0.407 / 0.532 (Recall@100
    0.661 / 0.797 / 0.874), honestly flagged as score fusion, not RRF.
15. **small-cuts** — ё/е, case, transliteration, keyboard-layout (ghbdtn→привет); each one line, symmetric.
16. **when-to-reach** — BM25+lemma · multilingual dense · ru-specific · hybrid (RRF) as the production baseline.
17. **the-checklist** — the payoff-shaped launch list (prose, not bullets), paired with the deck's checklist slide:
    measure *your* fertility · normalize in both arms · negations out of the stop list · ё→е before the stop filter ·
    NFC on input · a `keyword` field for entities · layout restoration in query preprocessing · pick the embedder by
    ruMTEB **Retrieval**, not the 23-task average · `query:` / `passage:` prefixes · evaluate on *your* Russian data.
    The tenth item is the rule that holds the other nine: the same transformation on both sides.
18. **payoff** — morphology strikes back, loses to the same move three times; not a new model, the tuned pipeline.
