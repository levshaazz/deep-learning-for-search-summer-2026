# Русский стайлгайд курса (ru-слой: Книга + деки + виджеты)

Единый редакторский стандарт для всех ru-строк репозитория: `content/book/*/beats/*.js`
(ключи `ru:`), `Lectures/*/parts/*.html` (`<span lang="ru">`, `<p lang="ru">`),
`widgets/*/i18n.json` и `widgets/*/manifest.json` (ключи `"ru"`), `release/video/*.md`
(проза сценариев; строки-метаданные слайдов и код линтер пропускает), `src/i18n`. Два аудита нашли системный разнобой;
этот файл — точка фиксации решений. Линтер: `check_style.py` (см. набор скриптов
`ru-fixes/`; кандидат в CI-гейты).

---

## 1. Обращение к читателю — «ты», всегда

- Курс говорит с одним читателем на «ты» (со строчной): «возьми словарь», «перечитай»,
  «теперь измерь». Это уже голос Книги — деки подтягиваются к нему. «Вы/вас/вам» в
  ru-строках — ошибка стиля (кроме прямой речи персонажей и цитат).
- **Финалы-благодарности — безличные, без гендер-маркировки.** Прошедшее время 2-го лица
  («прочитал», «стоял», «провёл») навязывает читателю род — запрещено. Перестраиваем:
  - гендер-нейтральные формулы: «Спасибо за компанию у станка», «Спасибо, что мы прочли
    всю книгу вместе», «Спасибо, что эта съёмка проведена вместе»;
  - приёмы: «мы»-совместность, пассив («книга прочитана»), отглагольное существительное
    («спасибо за время у ключа»), настоящее время («спасибо, что читаешь»).
- В основном тексте повелительное наклонение («сравни», «запомни») гендер-нейтрально —
  это предпочтительная форма обращения-действия.

## 2. Числа

- **Десятичный разделитель — запятая** во всех ru-строках: «12,7 %», «0,75», «2,3–2,9».
  - В LaTeX-формулах внутри ru-текста — `0{,}75` (фигурные скобки убирают лишний
    пробел после запятой; так уже сделано в свежих главах: `\(=1{,}0\)`).
  - **Точка остаётся** в версиях и идентификаторах: GPT-3.5, Python 3.9, ColBERTv2.0,
    Llama 3.1, номера версий/релизов, URL, имена файлов, код внутри `<code>`.
- **Разряды тысяч — пробелом, никогда запятой**: «32 768», «50 000».
  - Книга (beats): узкий неразрывный пробел U+202F (легаси-обычный пробел «50 000»
    допустим, не переделываем ради переделки);
  - деки (parts): `&nbsp;` (уже сложившийся паттерн: `150&nbsp;000`);
  - LaTeX: `32\,768`. Форма `32{,}768` в смысле тысяч запрещена — теперь `{,}`
    зарезервирована под десятичную запятую.
- Проценты: с пробелом перед знаком допускается и слитно тоже — не трогаем, но внутри
  одного слайда/такта единообразно.

## 3. Типографика

- Кавычки — «ёлочки»; вложенные — „лапки". Прямые `"…"` — только в коде и JSON-ключах.
- Тире — длинное `—` с пробелами вокруг (в HTML допустим `&mdash;`). Дефис `-` в роли
  тире — ошибка. Диапазоны чисел — короткое тире без пробелов: «2,3–2,9», «30–50 %».
- **Ё обязательна** везде: «ещё», «объём», «трёхмерный», «Серёга».
- Знак умножения — «×» (не «x»), минус в формулах — LaTeX/`−`, не дефис.

## 4. Ввод терминов

- При **первом употреблении** в главе/деке: «русский термин (english term)» — например,
  «полнота (recall)», «позднее взаимодействие (late interaction)», «функция потерь (loss)».
  Дальше по тексту — только русский термин.
- Имена систем, моделей, статей, датасетов — латиницей как есть: BM25, ColBERT, SPLADE,
  FAISS, BEIR, InfoNCE. Их не переводим и не транслитерируем.
- Устоявшиеся транслитерации пишем кириллицей: эмбеддинг, токен, батч, чанк, реранкер,
  софтмакс, хаб. Полулатинские гибриды («chunk'и», «loss-функция») запрещены.

## 5. Имена маскотов — только кириллицей в ru-строках

Канон (ru): **Серёга** (не Séréga/Серега, тем более не гибрид «Séréга»), **Артефактор**
(не Артифактор), **Токенозавр**, **Сэр Косинус** (всегда с прописной «Сэр» — это часть
имени), **Лексический Гремлин**, **Гудхарт** (не Goodhart в ru-прозе; «закон Гудхарта»),
**Чанк Норрис**, **Знаменосец**, **Пришелец**. Латинское написание — только в en-строках
и в подписях внутри английских SVG/иллюстраций.

## 6. Канцелярит и голос

Запрещены: «данный» (→ этот), «является» (→ это / есть / тире), «осуществлять /
производить + отглагольное» (→ прямой глагол), «в рамках», «имеет место». Голос курса —
живой разговорный, короткие предложения, действие в глаголе.

## 7. Утверждённый глоссарий

Формат: **канон** — запрещённые варианты. При первом употреблении — с английским в
скобках (правило §4).

| Канон | Запрещённые варианты | Примечание |
|---|---|---|

| **чанкование** (chunking) | чанкинг, нарезка-как-термин | |
| **эмбеддинг** (embedding), сущ. | embedding | |
| **закодировать / кодировать** (глагол к эмбеддингу) | заэмбедить, эмбеддить, эмбеддит(ся), эмбедди/эмбеддь | «прогнать через энкодер» — допустимый вариант |
| **энкодер**, **би-энкодер**, **кросс-энкодер** | «двойной энкодер», biencoder | |
| **позднее взаимодействие** (late interaction) | «поздняя интеракция» | |
| **отбеливание** (whitening) | «выбеливание» | Выбрано «отбеливание»: 15:1 по корпусу и устойчивый термин в ру-литературе. Обещание в l5 «слово вернётся в L7» обязано сходиться: в обеих главах — «отбеливание» |
| **трудный негатив** (hard negative) | жёсткий негатив, сложный негатив, хард-негатив | |
| **майнинг негативов / добывать** | mining без перевода | |
| **полнота** (recall) | recall в ru-прозе после ввода | В метрических обозначениях recall@k остаётся латиницей |
| **реранкер** (reranker) — агент | переранкер, ре-ранкер, переранжировщик | Процесс — **переранжирование**. Выбрано «реранкер»: самый частотный и короткий; «переранжировщик» тяжёл, «переранкер» — гибрид приставок |
| **переранжирование** (reranking) — процесс | — | |
| **переписывание запроса** (query rewriting) | «перепись» | Агент — **переписчик** (не «переписыватель») |
| **словарный разрыв** (vocabulary gap) | «лексический разрыв» | Имя маскота «Лексический Гремлин» — не трогаем, это имя собственное |
| **развязка** (payoff — структурный такт) | «расплата» | Денежная метафора остаётся только там, где речь буквально о цене/затратах (напр. L9 «Счёт — расплата» — осознанный каламбур о FLOPs-счёте) |

| **хаб / анти-хаб** (hub / anti-hub) | антихаб | Через дефис |

| **скалярное произведение** (dot product) | дот-продакт | |
| **сопоставление** (matching) — процесс/правило («правило сопоставления», «строковое сопоставление»); единичный результат — **совпадение** (match) | матчинг, матч, матчер | Решение 17.08.2026: оба слова уже жили в корпусе (сценарий L3 «Сопоставление бинарно», midterm «много хороших совпадений»); агент «матчер» перефразируется через «сопоставление». | **трансформер, внимание (attention), запрос/ключ/значение** | — | При вводе: «внимание (attention)», «запрос (query)» и т.д. |

### Спорные пары — зафиксированные решения, коротко

1. **отбеливание** > выбеливание — частотность в корпусе и в русскоязычной ML-литературе;
   правится ровно одна глава (l5), а не двенадцать файлов.
2. **реранкер** > переранжировщик/переранкер — частотность (44 против 16 и 3), краткость;
   для процесса остаётся полное «переранжирование» — пара «реранкер/переранжирование»
   разводит агента и действие.
3. **такт** > бит — устраняет прямой конфликт с L4, где «бит» — предмет лекции;
   «такт» поддерживает музыкальную метафору ритма главы и склоняется так же, как «бит»
   (замена сохраняет грамматику).
4. **словарный разрыв** > лексический разрыв — разводит термин и имя маскота
   (Лексический Гремлин остаётся); «словарный» точнее передаёт vocabulary mismatch.
5. **Тысячи**: Книга — U+202F, деки — `&nbsp;`, LaTeX — `\,` — по одному канону на слой,
   совпадающему с уже сложившейся практикой слоя.

## 8. Что чинится автоматически, а что руками

Автоматически (скрипты `ru-fixes/`, режимы `--dry-run`/`--apply`):
десятичные запятые, Серёга-варианты, однозначные замены глоссария
(отбеливание, позднее взаимодействие, трудный негатив, реранкер, Артефактор,
одношаговый, такт-паттерны, глагольные формы «эмбеддить»).

Только руками (редактор, по флагам линтера): «вы»→«ты» (42:39 в деках — нужна правка
согласования), гендер в финалах вне зафиксированных формул, «поиск» vs «извлечение»,
«ломоть»-образы, латинский Goodhart/Chunk Norris в ru-прозе (морфология), канцелярит.


### §7-тер. Осознанно оставленные термины

| термин | почему оставлен |
|---|---|
| **заземление** (grounding, ~140 вхождений) | сквозной и согласованный по всему корпусу; в RAG-контексте читается однозначно, а курс держится на метафорах (корабль, кузница, станок). Замена на «привязку к источнику» — смена концепции, а не редактура. В i18n виджета `llm-judge` рядом дан глосс. |
| **precision / recall** в перечислениях метрик | это имена метрик (§9.2); при первом вводе даётся канон «полнота (recall)». |
| **«вы» в шести местах** (`W-VY`, август 2026) | это не обращение к читателю, а чужая речь: цитата в L0 («Я сделаю вашу жизнь невыносимой»), строки интерфейса («вам также может понравиться» в L1, «возможно, вы искали» в L19), лингвистические примеры («из ваших домов» в L2 и в книге) и реплика олицетворённого слова в L7 («сколько мне учесть то, что говорит каждый из вас?»). Ломать их ради счётчика — испортить и цитату, и пример. Линтер оставлен предупреждающим ровно затем, чтобы каждое новое «вы» приходилось объяснять. |

## 9. Повторяющиеся дефекты — что чинить в сплошном проходе

Раздел вырос **из корпуса, а не из общих соображений**: цифры ниже измерены на
1790 ru-строках Книги (756 тыс. знаков) и 3273 ru-спанах деков; цитаты — дословные.
Каждый класс имеет детектор в `_research/ru/check_style.py`, так что после правки
прогресс виден числом.

Порядок правки внутри абзаца: **сначала смысл, потом синтаксис, потом лексика.**
Если правка меняет смысл технического утверждения — не правь, вынеси в отчёт.

### 9.1 Относительное «что» вместо «который» — 123 (`W-CHTO`)

Главный тик этого текста. В русском «что» как относительное местоимение живёт в
фольклорно-поэтическом регистре («тот, что всех сильней»). В технической прозе оно
читается как стилизация под сказ и на второй сотне повторов утомляет. Меняй на
«который» везде, кроме случаев, где это осознанная реплика маскота.

| было (файл) | стало |
|---|---|
| `метрики, что оценивают ответ` (L16 дек) | метрики, которые оценивают ответ |
| `слова, что отличают` (L3 дек) | слова, которые отличают |
| `техникой, что чинит` (l10) | техникой, которая чинит |
| `прокси, что непрерывно валидируешь` (l11) | прокси, который постоянно проверяешь |
| `дерево решений, что гонишь в голове` (l9) | дерево решений, которое прогоняешь в уме |

Не трогай: «не спросил, что будет» (изъяснительное «что» — другая конструкция),
«то, что» в роли подлежащего, устойчивое «потому что».

### 9.2 Транслит вместо русского слова — 15 (`W-TRANSLIT`) + латиница 202 (`W-LAT`)

Правило простое: **термин из глоссария §7 — транслитом; всё остальное — по-русски.**
Слово, у которого есть обиходный русский эквивалент, транслитерировать нельзя.

| было | стало |
|---|---|
| `дай я прогоню весь свип` (l10) — при том, что заголовок того же бита уже «Прогон по перекрытию» | дай я прогоню весь ряд настроек |
| `точным скорером` (l10) | точным оценщиком |
| `и пулингуй` (l16) | и усредняй |
| `это потеря *полноты (recall)*` — ✅ канон | так и оставить |
| `recall растёт с глубиной` (L10 дек) | полнота растёт с глубиной |

**Латиница, которая остаётся:** имена моделей и методов (ColBERT, SPLADE, HyDE, RAGAS,
word2vec, Transformer), обозначения метрик (`recall@10`, `nDCG@10`, `R-precision`),
англоязычные примеры-слова внутри разбора («bank», «cat», «river»), код и формулы.
`W-LAT` — предупреждение, не ошибка: он подсвечивает **все** вхождения, решение за тобой.

### 9.3 «Вы» в курсе на «ты» — 148 (`W-VY`)

Книга почти чиста, беда в деках (68 спанов, ядро — L1 и L17) и в i18n виджетов.
Правится не одним словом: меняется согласование всей фразы.

| было | стало |
|---|---|
| `L15 вручил вам меню из пяти приёмов` (L17) | L15 вручил тебе меню из пяти приёмов |
| `IR даёт вам задачу и метрики` (L1) | IR даёт тебе задачу и метрики |
| `Подойдите к моему чертёжному столу. Протягиваю вам линейку` (l18) | Подойди к моему чертёжному столу. Протягиваю тебе линейку |
| `хочу вас отучить` (l16) | хочу тебя отучить |

Отдельно: **финалы-благодарности не должны иметь рода** — «Спасибо, что прочитал»
→ «Спасибо за компанию» (формулы в §1).

### 9.4 Канцелярит — 35 (`W-KANC`)

После чистки ложных срабатываний осталось настоящее: «в рамках», «является»,
«данный момент», «данной релевантности». Заметь: **«данные» в значении *data* —
нормальное слово и не правится** (линтер это уже различает).

| было | стало |
|---|---|
| `в рамках бюджета` | в пределах бюджета / укладываясь в бюджет |
| `является ключевым` | ключевой / решает дело |
| `в данный момент` | сейчас |

### 9.5 Пропущенное тире в «X — это Y» — ~36

Русский требует тире между подлежащим и сказуемым-существительным.

| было | стало |
|---|---|
| `красная черта внизу это порог` (l17) | красная черта внизу — это порог |
| `оно оправдание всей` (l9) | оно — оправдание всей |

Не трогай: «Считай это повышением» (здесь «это» — дополнение, тире не нужно).

## 10. Как работать редактору (и агенту)

1. **Читай абзац целиком**, а не строку из линтера: половина дефектов — согласование,
   которое видно только в контексте.
2. **Правь ru, не трогай en/tt.** Числа, формулы, `\\(...\\)`, код, `:::calc`-блоки,
   markdown-разметку и `[C]`-якоря не трогай вообще — на них завязан facts-gate.
3. **Сохраняй голос.** Курс написан живо, с маскотами и метафорами; задача прохода —
   убрать кальки, а не выпрямить интонацию в учебник. Если фраза дерзкая, но по-русски
   естественная — оставь.
4. **Не переписывай технические утверждения.** Смена термина, порядка шагов или
   акцента в определении — не редактура, а смена содержания.
5. **Проверка после правки:**
   `node scripts/assemble-chapter.mjs build lNN` (или `assemble-deck.mjs` для дека),
   `python3 _research/check_claims.py` (обязательно — правки задевают отображаемые числа),
   `python3 _research/check_lexicon.py`, `python3 _research/ru/check_style.py --summary`
   (счётчики твоих классов должны упасть, чужие — не вырасти).
