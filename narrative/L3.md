## Worked examples (precision beats — pošаговые, exact)
All numbers are **computed by `_research/gen_l3.py`** on a tiny **20 Newsgroups** sub-corpus (the
dataset L1/L2 already use), so they're real and reproducible, and a future facts-gate claim can pin them.

1. **Inverted index (climb-index).** Take ~8 short docs across 2 categories (e.g. `sci.space`,
   `rec.sport.hockey`). Show the postings for 3 query terms (`space`, `orbit`, `team`): `term → [docIDs]`.
   A 2-term AND query = intersection of two postings lists (show the merge step by step).
2. **TF-IDF (climb-tfidf).** For query `space orbit` vs a chosen doc d:
   - `tf(t,d)` (raw count), `df(t)`, `N` (docs), `idf(t) = ln((N − df + 0.5)/(df + 0.5) + 1)`.
   - weight = `tf · idf`; sum over query terms. Show that `orbit` (rarer) contributes more than `space`.
3. **BM25 (climb-bm25) — the headline.** Same query/doc, `k₁ = 1.5`, `b = 0.75`:
   `BM25(q,d) = Σ_t idf(t) · ( tf · (k₁+1) ) / ( tf + k₁·(1 − b + b·|d|/avgdl) )`.
   Show, step by step: (a) idf per term; (b) the saturation factor (going from tf=1→2→5 adds *less*
   each time — contrast with linear TF-IDF); (c) the length-norm `|d|/avgdl` penalising a long doc.
   End on the final per-doc score and the ranking of 3 candidate docs.
4. **RRF (climb-rrf).** Two rankers for one query — BM25 vs TF-IDF-cosine — give two ranked lists.
   `RRF(d) = Σ_rankers 1/(k + rank_r(d))`, `k = 60`. Show the table: each doc's rank in each list,
   its reciprocal-rank contributions, the summed RRF score, and the fused order. Point: a doc ranked
   well by *both* rises; rank-based fusion is robust to incomparable score scales.

## Python / data plan
`_research/gen_l3.py` (seeded, stdlib + sklearn + numpy; same family as `gen_highd.py`):
- load 20NG, select a small deterministic sub-corpus; tokenize (reuse the L2 tokenizer notion).
- build the inverted index → `data/l3-index.json` (`{term: [docIDs], df}` + the AND-merge trace).
- compute TF-IDF and BM25 (`k₁=1.5, b=0.75`) for a fixed query → `data/l3-bm25.json`
  (`{N, avgdl, query, docs:[{id, len, terms:[{t, tf, df, idf, tfidf, bm25}], tfidfScore, bm25Score}]}`).
- produce two ranked lists + the RRF fusion (`k=60`) → `data/l3-rrf.json`
  (`{lists:{bm25:[...], cosine:[...]}, fused:[{id, rrf, contributions}]}`).
- **Relevance for the narrative** uses the L1/L2 convention: *relevant = same 20NG category* (this
  is what L4 metrics will consume — keep the qrels here too for continuity).
- Lab tie-in (Fri session): students reimplement BM25 from the postings and reproduce the ranking.
