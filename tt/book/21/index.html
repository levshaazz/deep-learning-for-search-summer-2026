Якын документ әле җавап түгел

Серёгада кыска исемлек бар, Сэр Косинус документларны тәртипкә куйган. Хәзер сорау катлаулырак: Корабка аларга таянып җавап бирергә ярыймы? Документ сораудагы һәр сүзне кабатлый ала, ләкин җавапны хәл итүче шартны әйтмәскә мөмкин. Ранжирлау башта нәрсә укырга икәнен сайлый; карар кагыйдәсе системага нәрсә эшләргә рөхсәт ителгәнен билгели.

Бу өстәмә бүлек L16 дан соң укыла. Get Data → Measure → Rank → Generate юлында без генерациядән үлчәүгә кайтабыз. Jev — өйрәнү өчен конкрет мисал, барлык реранкерларны алыштыру вәгъдәсе түгел. Бүленештән тәртип чыгарабыз, ихтималлык шкаласын тикшерәбез һәм гамәл бәясен билгелибез. Түбәндәге җайланмалар һәм саннар — укыту өчен уйлап чыгарылган мисаллар; алар Jev җаваплары да, чын техника турында фактлар да түгел.

Тәртип, ихтималлык, гамәл

Сорау: M2 мониторын Vega14 ноутбугының U1 портына C7 кабеле белән тоташтырып буламы? A фрагменты Vega гаиләсен һәм аксессуарларны мактый. B C7 нең уйлап чыгарылган V7 профилен һәм M2 белән ярашуын әйтә, әмма Vega14 турында дәшми. C нәкъ бу тоташуны раслый. D башка ноутбук клавиатурасына хезмәт күрсәтү турында. Кулдан куелган файдалылык бәяләре: A=1, B=2, C=3, D=0. Начар A,D,B,C тәртибе — мисал гына, BM25 үлчәве түгел.

Хәзер C тоташуның мөмкин түгеллеген ачык әйтсен. Ул һаман сорауга тулы җавап бирә. Файдалы релевантлык, җитәрлек мәгълүмат һәм уңай расламаны хуплау — төрле максатлар. Шуңа өч хисап кирәк: ранжирлау метрикалары тәртипне, ихтималлык метрикалары билгеләнгән вакыйганы, ә югалту сайланган гамәл нәтиҗәсен тикшерә. Бер хисаптагы җиңү калган икесен расламый.

Интерфейс, уйлап чыгарылган архитектура түгел

Jev уртак халәт һәм типлы сораулар кабул итә. Күренә торган контрактны \(f_\theta(\text{state},\text{question})\to p\) дип языйк. Халәттә сорау һәм фрагмент ята; күрсәтмә бәяләүне, критерийлар мөмкин җавапларны билгели. Аннары безнең код бүленештән тәртип яки гамәл чыгара. Бу — API чиге, модельнең яшерен катламнары схемасы түгел. TypeSafe белдерүе.

Эзләү каскадындагы урын таныш: би-энкодер яки лексик эзләү кандидатлар таба, кыйммәтле пар бәяләүчесе кыска исемлекне укый. Безнең тәҗрибәдә Jev икенче урынны били. Ул индекс төземи һәм соңгы җавапны язмый. Типлы нәтиҗә форматның билгесезлеген бетерә, ләкин мәгънә хатасын түгел: дөрес форматтагы категория ялгыш була ала. Генератив модельләр дә чикләнгән формат бирә; шуңа JSON булуын түгел, карарларны һәм чыгымнарны чагыштыр.

Өч тип, өч мәгънә

Choice исемле вариантны сайлый һәм вариантлар ихтималлыкларын кайтара. Раслама өчен supports / contradicts / not_stated куллан: соңгысы дәлил җитмәгәндә мәҗбүри хөкемнән саклый. Score тәртипләнгән тасвирлы дәрәҗәләрне, аларның бүленешен һәм номерларның авырлыклы уртачасын бирә. Вакланмалы бәя — рубрикадагы урын, ихтималлык түгел. Noul бер бинар сорауга «әйе» ихтималлыгын бәяли. Примитивлар.

C өчен өч типны куллан: файдалылык дәрәҗәсе, уңай расламага мөнәсәбәт һәм бер фрагментның җитәрлеклеге. Нәтиҗәләре туры килсә дә, болар төрле сораулар. Noul яртыга якын булса, вакыйга билгесез; документның яртысы гына релевант дигән сүз түгел. Төгәл санны Score аша чыгарма: «күп объект» дигән мәгънә бәясе санауны алыштырмый. Структуралы саннарны гадәти код белән сана һәм чагыштыр.

Чикне күзәтелә торган ит

Рубрикада дүрт дәрәҗә бар: 0 — төгәл сорауга файдалы мәгълүмат юк; 1 — тема уртак, җавапка кирәкле факт юк; 2 — кирәкле фактларның бер өлеше бар, җавап тулы түгел; 3 — уңай яки тискәре җавап өчен җитәрлек ачык мәгълүмат бар. Кагыйдә: тулысынча үтәлгән иң югары дәрәҗә. Һәр критерий үзеннән-үзе аңлашылсын: «алдагысыннан яхшырак» күзәтелә торган чик түгел. Башта бәхәсле мисалларны кешеләр белән тикшер.

B — төп чик мисалы. Ул кабель белән мониторның ярашуын раслый, ләкин ноутбук портының мөмкинлеген расламый. «Бик релевант» дигән сүз җитмәгән шартны яшерә; 2 дәрәҗә аны аңлата. Билге куючылар яшерен техник белем аркасында бәхәсләшсә, максат әле беркетелмәгән. Дәлилне тексттан сора һәм билгесезлекне теркә. Тест бәяләрен күргәч рубриканы үзгәртү сүзләрне генә түгел, мәсьәләне үзгәртә.

Параллель сораулар бәйсез вакыйгалар түгел

Бер мөрәҗәгатьтәге сораулар уртак халәтне куллана, ләкин бер-берсенең җавапларын укымый. Икенче бәяләүгә беренчесенең нәтиҗәсе кирәк булса, ачык төзелгән яңа халәт белән икенче мөрәҗәгать яса. Сорау идентификаторы — код ачкычы, күрсәтмә урынына йөрми: passage, query һәм claim мәгънәләрен яз. Сораулар контракты.

Хисаплау тәртибе статистик бәйсезлекне исбатламый. «Файдалы факт бар» һәм «расламаны хуплый» вакыйгалары бер үк җөмләгә бәйле була ала. Аларның аерым ихтималлыкларын тапкырлау гадәттә дөрес җавап ихтималлыгын бирми. Бер бинар вакыйганы сора, тулыландыргычын бердән p ны алып исәплә: аерым соралган сораулар килешмәскә мөмкин. Карар уртак вакыйгага бәйле булса, шул вакыйганы билгелә һәм тикшер; уңайлы кырлардан аның ихтималлыгын уйлап чыгарма.

RLCD исеме нәрсәне аңлата һәм нәрсәне аңлатмый

TypeSafe үз ысулын Reinforcement Learning for Calibrated Decisions — RLCD дип атый. Ачык тасвирлама программаларда кулланырлык ихтималлыклы карарларга басым ясый. Әмма анда тулысынча кабатлана торган өйрәтү рецепты, RLCD нең төгәл максат функциясе һәм тулы хисаплау графы юк. Шуңа кыскартмадан реализацияне яки параметрлар санын чыгарып булмый. Җитештерүче аңлатмасы.

Өч белем дәрәҗәсен аер: күзәтелгән API контракты, җитештерүченең өйрәтү турындагы белдерүе һәм бәйсез аерылган тәҗрибә дәлиле. Алар төрле нәтиҗәләрне нигезли. Калибрланган фараз өйрәтү нияте русча сорауларда калибрлауны әле расламый. Киләсе чыгару ихтималлыкны намуслы хәбәр итүнең гомуми сәбәбен күрсәтә. Бу Jev нең яшерен югалту функциясе дип тәкъдим ителми.

Ни өчен дөрес бәяләү намуслылыкны бүләкли

Вакыйганың чын ихтималлыгы \(\pi\), хәбәр ителгән фараз \(p\) булсын. Бинар нәтиҗә \(Y\) өчен көтелгән квадрат хата \(\mathbb E[(p-Y)^2]=\pi(p-1)^2+(1-\pi)p^2=(p-\pi)^2+\pi(1-\pi)\). Икенче кушылучы фаразга бәйле түгел. Беренчесе тискәре түгел һәм нәкъ \(p=\pi\) булганда юкка чыга. Brier ның бу бинар вакыйга өчен катгый дөрес бәяләү кагыйдәсе булуы шуннан килә.

Хисап төзәтелә торган хатаны намуслы фаразда да кала торган билгесезлектән аера. Ул аерым документның чын ихтималлыгын ачмый һәм өйрәтелгән модельнең минимумга җитүен исбатламый. Билгеләр, популяция һәм модель мөмкинлекләре һаман мөһим. Иң мөһиме: бу гомуми математик чыгару, RLCD нең басылган формуласы түгел.

Тәртипкә салганчы файданы сайла

Бүленеш әле ранжирлау кагыйдәсе түгел. Башта дәрәҗәләрнең кыйммәтен сайла: монда \(g(r)=2^r-1\), ягъни 0,1,3,7. Аннары \(s(q,d)=\sum_r P(r\mid q,d)g(r)\) исәплә. Бу — көтелгән gain. Без тулы җавапны тема искә алудан күпкә югары бәялибез; башка мәсьәләгә сызыклы файда кирәк булырга мөмкин. Кагыйдә «релевант» сүзендә яшеренми, кодта күренә.

Ни өчен көтү буенча тәртипкә салырга? DCG да ике документны алыштыру көтелгән сумманы \((\mathbb E[g_a]-\mathbb E[g_b])(w_i-w_j)\) га үзгәртә; иртәрәк урынның авырлыгы зуррак. Зуррак көтүне алгарак куйсаң, аерма тискәре түгел. Көтүнең сызыклылыгына документ билгеләренең бәйсезлеге кирәкми. Бу чыгару кандидатлар беркетелгән һәм файда позиция буенча аддитив булганда дөрес; төрлелекне яки очраклы бүленүчесе булган көтелгән nDCG ны оптималь дип расламый.

C урынын хисап билгели

C өчен 0–3 дәрәҗәләр буенча синтетик бүленешне ал: [0,02; 0,03; 0,15; 0,80]. Көтелгән дәрәҗә \(0{,}03+2\times0{,}15+3\times0{,}80=2{,}73\). Көтелгән gain \(0{,}03+3\times0{,}15+7\times0{,}80=6{,}08\). Шул ук ихтималлыклар төрле кыйммәтләр белән уртачалана. Score.score беренче хисапка туры килә, икенчесенә түгел. Score мәгънәсе.

Шул ук укыту хисабы A өчен көтелгән дәрәҗә 1,15, gain 1,50; B өчен 1,95 һәм 3,25; D өчен 0,21 һәм 0,29 бирә. Gain буенча кимү тәртибе C,B,A,D була. Хисап алдыннан һәр бүленеш суммасының бер булуын тикшер.

Икене уртача дәрәҗәгә күтәрмә: гомумән \(\mathbb E[2^r-1]\ne 2^{\mathbb E[r]}-1\). Сызыксыз функция уртачалауга кадәр нәтиҗәләргә кулланыла. Тулы бүленешне кешта сакла: башка файданы модельгә яңадан мөрәҗәгать итмичә тикшереп була.

Башка файда тәртипне үзгәртә

A–D тәртибе сызыклы һәм экспоненциаль gain өчен саклана. Һәр көйләү үзгәргәндә урыннар алмашыр дип вәгъдә итмә. Механизм өчен аерым синтетик пар ал: X=[0; 0,45; 0,55; 0] һәм Z=[0,55; 0; 0; 0,45]. Сызыклы көтүләр 1,55 һәм 1,35: X җиңә. Экспоненциаль көтүләр 2,10 һәм 3,15: Z җиңә. Z тулы җавапка да, файдасыз нәтиҗәгә дә зуррак мөмкинлек бирә.

Бер кагыйдә дә барлык мәсьәләләр өчен дөрес түгел. Сайлау тулы җавапның өлешчә мәгълүматка карата кыйммәтен белдерә. Аны нәтиҗәләрне бәяләгәнче яз. Интерактивта башта A–D ны кара, аннары X/Z га күч һәм файданы үзгәрт. Модель бүленеше үзгәрми; безнең карар кагыйдәсе үзгәрә. Икесен дә күренеп торырлык итүнең мәгънәсе шул.

Бүленеш мөмкин дәрәҗәләрне тасвирлый. Дүрт ихтималлык суммасы бергә тигез; бу ирекле сүзле үзбәя түгел.

Һәр ихтималлыкны дәрәҗә файдасына тапкырла һәм куш. C өчен көтелгән экспоненциаль gain — 6,08.

Көтелгән файда буенча тәртипкә сал. X/Z сайлап, сызыклы һәм экспоненциаль gain чагыштыр: шул ук бүленешләр төрле тәртип бирә.

L5 кә кайт һәм билгеләрне үзгәртмә

Синтетик тәртипне сортлауда кулланылган фаразлар буенча түгел, кулдан куелган билгеләр буенча тикшер. Баштагы A,D,B өчлегендә gain 1,0,3 була. Димәк \(DCG@3=1+0/\log_2 3+3/2=2{,}5\). Идеаль C,B,A өчлеге \(IDCG@3=7+3/\log_2 3+1/2\approx9{,}3928\) бирә. Баштагы nDCG якынча 0,2662; C,B,A,D тәртибеннән соң ул бу укыту кандидатлары өчен бергә тигез.

Бинар файдалылыкны кимендә икенче дәрәҗә дип билгелә. B һәм C файдалы. Беренче файдалы документ өченче урыннан беренчегә күчә: кире ранг өчтән бердән бергә, Recall@3 яртыдан бергә үсә. Бу — бер сорау өчен RR, җыелма буенча MRR түгел. Күнегү төзелгән мисалның арифметикасын раслый. Ул чын Jev бәяләренең шушы билгеләрне кайтаруын исбатламый.

Юк документны яңадан ранжирлап булмый

Икенче этап алдыннан C ны алып ташла. Иң яхшы мөмкин тәртип хәзер B,A,D, ләкин тулы җавап югалды. Кандидатларга шартланган nDCG һаман бергә җитә ала: идеаль исемлектә бары булган документлар гына. Каршылык юк: метрика «бу җыелма ничек сортланган?» дип сорый, «эзләү бөтен кирәклесен тапканмы?» дип түгел. Беренче этап тулылыгын аерым хәбәр ит; бөтен корпус билгеләнмәгәндә киңрәк билгеләнгән пул куллан.

Бүлүче — метрика билгеләмәсенең өлеше. Кандидатлар буенча nDCG һәм гомуми пул буенча nDCG аерым баганаларда булсын. Билгесез документны тавышсыз гына файдасыз дип санама. Идеаль пулдагы бөтен gain нуль булса, бу бүлек кагыйдәсе буенча nDCG билгеләнмәгән: уртачадан чыгар һәм чыгарылган сораулар санын хәбәр ит. Җавапсыз сораулар контроллерны бәяләүдә калсын.

Ышаныч бүленешне тасвирлый, хакыйкатьне түгел

Jev дагы confidence кыры кайткан бүленеш формасыннан исәпләнә. Документация төгәл формуланы ачмый, шуңа аны нормальләштерелгән энтропия белән алыштырма. Noul да аерым confidence юк. Ышаныч. Ялгыш, ләкин тупланган бүленеш һаман тупланган булып кала: бу статистика җавап дөреслегенең бәйсез шаһиты түгел.

Өч зурлыкны аер: рубрика дәрәҗәсенең көтелгән кыйммәте, исемләнгән вакыйга ихтималлыгы һәм бүленеш формасы күрсәткече. Энтропияне үзең исәпләсәң, аны үз диагностик күрсәткечең дип билгелә. Ышаныч бусагасын куллану өчен аның кирәкле хаталар белән бәйләнешен аерылган мәгълүматта үлчә. Бер мисалдагы матур сан моны расламый; нәтиҗә билгесе модельдән тыш килергә тиеш.

Санны укыганчы вакыйганы ата

Фрагмент файдалылыгы өчен \(Y=\mathbf 1[r\ge2]\) билгелә. Бер-берсен кире кага торган дәрәҗәләр бүленешеннән \(p_\text{useful}=P(r=2)+P(r=3)\) алабыз. Бу — нәтиҗәләр суммасы, модельнең яңа фаразы түгел. Ул «фрагмент бөтен сорауга җавап бирә» вакыйгасы белән бер түгел: икенче дәрәҗә җитмәгән фактларны рөхсәт итә.

Соңрак контроллер \(Y_\text{ctx}\) — бөтен сайланган контекстның җитәрлеклеген куллана. Бу вакыйгаларга төрле билгеләр һәм, бәлки, төрле ихтималлык калибрлавы кирәк. Чыннан да җитәрлек контекст генераторның аңа дөрес таянуын гарантияләми. Һәр ихтималлык баганасы янында вакыйганы яз: ялангач p төп фаразны яшерә.

Калибрлау — ешлыклар турында раслама

Калибрлау фараз вәгъдә иткән ешлыкларның күзәтелгән вакыйгаларга туры килүен сорый. 0,8 гә якын чагыштырырлык фаразлар арасында якынча уннан сигезе уңай билгелеме? Бу — популяция үзлеге, аерым документ гарантиясе түгел. Калибрлау диаграммасы фаразларны төркемли, уртача ихтималлыкны уңай нәтиҗә өлеше белән чагыштыра һәм төркем зурлыгын күрсәтә. Саннар һәм билгесезлек күрсәтелмәсә, матур диагональне артык бәяләү җиңел.

Ранжирлау исә бәяләрнең катгый үсә торган үзгәрешендә саклана. Киләсе мисал барлык парлы тәртипләрне калдыра, ләкин ихтималлыкның квадрат хатасын һәм беркетелгән бусагадагы карарларны үзгәртә. Дүрт нокта бу аерманы күрсәтергә җитә, калибрлауны расларга җитми. Укыту контрмисалын модельнең үлчәнгән үзлеге дип кабул итмә.

Бер үк тәртип, төрле Brier бәясе

Синтетик y=[0,0,1,1] билгеләре өчен p=[0,1; 0,2; 0,7; 0,8] һәм p′=[0,6; 0,7; 0,9; 0,95] не чагыштыр. Ике җыелма да объектларны бертөрле сортлый. Brier — квадрат хатаның уртачасы: p өчен \((0{,}01+0{,}04+0{,}09+0{,}04)/4=0{,}045\); p′ өчен \((0{,}36+0{,}49+0{,}01+0{,}0025)/4=0{,}215625\). Ранжирлау метрикалары шкаладагы бу үзгәрешне күрми.

Үткәрү бусагасы 0,65 булганда p ике уңай объектны кабул итә. p′ тагын бер тискәре объектны үткәрә. Бу температура белән масштаблау түгел: уңай температура бинар ихтималлыкны ярты аша күчерә алмый. Интерактивта күчерелгән вектор һәм температура тәҗрибәсе — аерым режимнар. Brier ихтималлыкның гомуми сыйфатын тикшерә, калибрлауны гына түгел; аны диаграмма һәм даими ихтималлык нигезе белән бергә укы.

Башлангыч фаразлар өчен Brier — 0,045. 0,65 бусагасында ике уңай мисал гына сайлана.

Тәртип шул ук, ләкин Brier 0,215625 була, ә элекке бусага тискәре мисалны үткәрә.

Аерым тәҗрибә: башлангыч логитларның уңай температурасын үзгәрт. Тәртип саклана, Brier һәм бусага карарлары үзгәрергә мөмкин. T ны калибровка өлешендә генә өйрәт.

Ышанычлы хата кыйммәткә төшә

L4 кә кайтыйк: бинар log loss \(-N^{-1}\sum_i[y_i\ln p_i+(1-y_i)\ln(1-p_i)]\) була. Уңай объектның штрафы \(-\ln p\); нульгә якын фараз аны зур итә. Монда сүз уңай билгенең мәгънәсен үзгәртү турында түгел, ялгыш ышаныч бәясе турында. Һәр ысул өчен вакыйга да, аерылган объектлар да бер үк булсын.

Чын уңай нәтиҗәгә төгәл нуль ихтималлыгы бирү математик югалтуны чиксез итә. Код еш кына санлы хисап өчен кечкенә epsilon белән чикли; аны чагыштыру алдыннан беркет һәм хәбәр ит. Чикләү фаразны калибрламый, ә теләсә нинди бәяне минимум һәм максимум буенча нормальләштерү ихтималлык ясамый. Brier һәм log loss ны ешлык диагностикасы белән бергә күрсәт: бер сан характерлы хатаны яшермәсен.

Диагональ әле эзләү системасы түгел

b интерваллары өчен уңай вакыйга ECE сы \(\sum_b(n_b/N)|\overline p_b-\overline y_b|\) була. Төп хисапта алдан биш тигез киңлектәге интервал сайлыйбыз; соңгысы берне кертә, бушларының авырлыгы нуль. Фаразларны үзгәртмичә интервалларны алыштыру ECE ны үзгәртә ала. Төркем саннарын һәм билгесезлекне күрсәт; башка бүленешләрне сизгерлек анализы итеп бир, иң матур диаграмманы сайлама.

Популяциянең төп ешлыгына тигез даими фараз калибрланган булса да, файдалы документны башкаларыннан аермаска мөмкин. Шуңа калибрлау ранжирлау сәләте түгел, Brier да калибрлауны гына үлчәми. Гомуми диаграмма аерым төркем проблемаларын яшерә ала. Кирәкле телләрне һәм мәсьәлә төрләрен тикшер, ләкин буш диярлек интервалдан ышанычлы нәтиҗә чыгарма. «Дәлил җитми» — дөрес нәтиҗә.

Температура шкаланы үзгәртә, тәртипне түгел

Бинар z логиты өчен \(p_T=\sigma(z/T)\), \(T\gt0\) дип билгелә. Уңай санга бүлү дә, сигмоида да катгый үсә, шуңа тәртип саклана. Ләкин беркетелгән ихтималлык бусагасына аралар үзгәрә. Уңай логит уңай булып кала, димәк яртыдан югары ихтималлык яртыны үтми. Шуңа алдагы p дан p′ ка күчүне бер температура үзгәреше дип атап булмый.

T ны калибрлау өлешендә тап, аннары тестта бер тапкыр бәялә. Төп ешлык үзгәрүе ирекле кушылучы яки башка күчерү таләп итәргә мөмкин: бер температура барысын да төзәтми. Guo һәм башкалар — соңыннан калибрлау буенча беренчел тикшеренү. Jev ны гына җентекләп тикшереп, кросс-энкодерның чимал сигмоидасын расланган ихтималлык дип кабул итмә.

Сорау гаиләләрен аер

Development та рубрика, алдан эшкәртү һәм кыска карар кагыйдәләре исемлеге сайлана. Calibration да ихтималлык күчерүләре һәм беркетелгән критерий буенча бусагалар өйрәтелә. Test карарлар туңдырылганнан соң нәтиҗәне бәяли. Парафразларны, тәрҗемәләрне һәм охшаш чыганак битләрен бер гаиләдә тот һәм гаиләләр буенча бүл. Сорау–документ парларын очраклы бүлү бер үк мәгълүматны чик аша үткәрә.

Тест хаталарын күреп рубриканы яхшыртсаң, иске тест эшләү материалына әйләнә: яңа раслау җыелмасы кирәк. Калибрлау өлешен дә күп кагыйдә сынап артык кулланып була; эзләүне алдан чиклә яки эчке бүленеш керт. Яраткан система җиңгәнче хата бәяләрен үзгәртмә. Бәяләр хисап стилен түгел, кулланма өстенлекләрен белдерә.

Бусаганы ике югалтудан чыгар

Y файдалылык вакыйгасы өчен файдасыз фрагментны үткәрү бәясе \(C_{FP}=4\), файдалысын ташлау бәясе \(C_{FN}=1\) булсын. Дөрес гамәлләр бушлай. p ихтималлыгында көтелгән югалтулар \(L(\text{pass})=4(1-p)\) һәм \(L(\text{drop})=p\). Үткәрү \(4(1-p)\lt p\), ягъни \(p\gt0{,}8\) булганда отышлы. Тигезлектә безнең кагыйдә ташлый. Бу — шартлы югалту берәмлекләре, үлчәнгән акча зыяны түгел.

p=0,85 булганда үткәрү югалтуы 0,60, ташлауныкы 0,85: үткәрәбез. p=0,70 булганда югалтулар 1,20 һәм 0,70: ташлыйбыз. Бу матрицаның гомуми бусагасы \(C_{FP}/(C_{FP}+C_{FN})\).

Формулага нәкъ бу вакыйганың мәгънәле ихтималлыгы һәм туры килгән популяция кирәк. Бу универсаль «Jev бусагасы» түгел. Вакыйганы, дөрес гамәл бәясен яки гамәлләр җыелмасын үзгәртсәң, кагыйдәне яңадан чыгар. Киләсе интерактив башта фрагмент югалтулары нисбәтен үзгәртә, аннары башка мәсьәләгә — контекстка күчә.

Үткәрү югалтуы — 4(1−p), төшерү — p. p > 0,8 булганда гына үткәрү отышлы.

Ялгыш рөхсәт бәясен 9 га күтәр. Өзек фильтры бусагасы 0,9 га үсә; документлар тәртибен үзгәртергә кирәкми.

Вакыйганы һәм югалтулар матрицасын үзгәртәбез: җитәрсез контекст бәясе — 9, кичектерү һәрвакыт 1 тора. p > 8/9 булганда гына рөхсәт итәбез.

Бөтен контекст — башка объект

C ны яшер. E өстә: Vega14 M2 не U1 гә уйлап чыгарылган V7 профильле кабель белән тоташтыра ала, ә конкрет кабель профилен аның паспортыннан карарга кирәк. B C7 нең V7 үткәрүен әйтә. Аерым фрагментлар җитми; бергә алар кирәкле тоташуны нигезли. Фрагмент җитәрлеклеге бәяләренең максимумын алу бу тулылануны югалта. Киресенчә, C һәм каршы C− аерым ышандырырлык күренсә дә, бергә җавапны хәл итми.

Сорау һәм бөтен сайланган контекст буенча аерым бәяләү сора. Каршылыкта чыганакларның кулланылуын һәм версияләрен тикшер: «иң яңа текстны ал» автоматик дөрес кагыйдә түгел. RAG фрагментларын классификацияләү ачык бәяләүләргә бүлүне күрсәтә.

Рөхсәт итү яки кичектерү — үткәрү яки ташлау түгел

Лабораториянең минималь контроллерында ике гамәл бар: хәзер генерациягә рөхсәт итү яки автоматик җавапны кичектерү. \(Y_\text{ctx}\) вакыйгасы — контекст җитәрлеклеге. Җитмәгән контекстта рөхсәт бәясе тугыз; җитәрлектә нуль; кичектерү һәр ике билге өчен бер тора. Димәк \(L(\text{allow})=9(1-p_\text{ctx})\), ә \(L(\text{defer})=1\). \(p_\text{ctx}\gt8/9\) булганда гына рөхсәт итәбез; тигезлектә кичектерәбез.

Тугыз һәм берне фрагмент фильтры формуласына куйма: фильтр файдалы документны ташлаганда гына түли, контроллер һәр кичектерү өчен түли. Матрицалар төрле. Кичектерү киләчәктә һичшиксез коткаруны да аңлатмый. Күнегү соңгы җавапның бөтен зыянын түгел, хәзерге рөхсәтне бәяли. Өч гамәлле контроллерга ачыклауның һәм яңа эзләүнең көтелгән нәтиҗәләре һәм бәяләре дә кирәк.

Эшләмәү бушлай ышанычлылык бирми

Каплау — кагыйдә автоматик җавапка рөхсәт иткән сораулар өлеше. Сайланма хәвеф монда нигезсез рөхсәтләр санын барлык рөхсәтләргә бүлүдән чыга. Каплау нуль булса, бүлүче нуль: хәвеф нуль түгел, билгеләнмәгән. Хәвефне каплау һәм бирелгән матрица буенча уртача югалту белән күрсәт. Югыйсә «һәрвакыт кичектер» файдалы һәм камил имин система булып күренер.

Алдан бирелгән бусагаларны calibration да тикшер, беркетелгән югалту буенча сайла һәм карарны туңдыр. Test та «һәрвакыт рөхсәт ит» һәм «һәрвакыт кичектер» белән чагыштыр. Кечкенә тестта аз хата да билгесезлек калдыра. Сервис хатасында сорау нәтиҗәсен сакла: авыр сорауларны тавышсыз төшерү хәвефне яхшыртмасын. Түбәнрәк хәвеф ноктасы каплау һәм бәя белән бергә генә файдалы.

Һәр бәяләүче нәрсә күрүен беркет

Намуслы реранкер чагыштыруы беренче модель җавабына кадәр башлана. Һәр сорау өчен бер кандидат исемлеген, төгәл ID ларны, күренә торган текстларны һәм баштагы тәртипне сакла. BM25 тәртибе, кросс-энкодер һәм Jev бер үк кандидатларны алсын. Лимитлар төрле булса, уртак күренә торган текстта чагыштыр; тулы контекстны аерым абляция итеп бир. Jev ка эталон билгеләрне, баштагы урыннарны яки башка система бәяләрен ишарә итеп бирмә.

Кешеләр туңдырылган рубрика буенча бәйсез билге куя; бәхәсләр модель бәяләрен күрмичә хәл ителә. Контроллер өчен контекст җыю кагыйдәсен беркет һәм аның тулы җитәрлеклеген аерым билгелә. Кулдан ясалган каршылыклар һәм тулыландыручы фрагментлар исемле стресс-җыелмага керә, төп ешлыкка яшерен кушылмый. Синтетик лаборатория протоколны өйрәтә; чын чагыштыруга чын беркетелгән керешләр һәм үлчәнгән җаваплар кирәк.

Алдан җиңүчесез өч таблица

Ранжирлау таблицасында кандидатлар буенча nDCG, кире ранг уртачалары һәм эзләп алу тулылыгы аерым тора. Ихтималлык таблицасында исемләнгән вакыйга өчен Brier, log loss, төп ешлык һәм калибрлау төркемнәре бар. Контроль таблицасында югалту, каплау, нигезсез рөхсәт хәвефе һәм хаталар күрсәтелә. Барлык чагыштырулар бер үк яраклы сорау ID ларын куллана; билгеләнмәгән метрикалар һәм чыгармалар ачык санала. Башта сорау буенча парлы аермаларны тап; bootstrap ны бәйсез гаиләләр буенча яса.

Бу бүлек Jev ны үлчәнгән җиңүче дип атамый. Чын хисап модель версияләрен, рубрика хешын, текст кыскартуны, телне һәм вакыт протоколын беркетә. Җитештерүче мисаллары куелышны күрсәтә, ләкин контрольле чагыштыруны алыштырмый. Реранжирлау мисалы. Бенчмарк укыганда сора: инде билгеләнгән кандидатлар сортланамы, әллә бөтен эзләү тикшереләме? Бу тәҗрибәләр төрле расламаларны нигезли.

Рус теле һәм дошман текст — сынау шартлары

Русча табигый язылган сорауларны куллан, инглиз җыелмасының тәрҗемәләрен генә түгел. Рубрика телен беркет; автоматик тәрҗемәне аерым конвейер варианты дип сана. Һәр кисемнең зурлыгын һәм билгесезлеген хәбәр ит. Күптелле кросс-энкодер русча өчен инглизчә генә модельдән файдалырак нигез. Аның ревизиясен test нәтиҗәләреннән соң түгел, development та сайла.

Җитештерүче арифметикада, туры булмаган фикерләүдә, читкә юнәлтүче контекстта һәм дошман күрсәтмәләрдә сыйфат тигез түгеллеген яза. Jev чикләре. Зыянлы фрагмент күрсәтмәләрен аерым стресс-җыелмага куй һәм башкару вәкаләте түгел, мәгълүмат итеп тот. «Документ күрсәтмәләрен игътибарсыз калдыр» — тикшерелә торган саклану, иминлек дәлиле түгел. Структуралы даталарны һәм саннарны мөмкин булганда код эшкәртсен.

Ачык контрактлы бер мөрәҗәгать

Өстәмә челтәр режимы бу бүлек өчен 2026 елның 1 октябрендә тикшерелгән typesafe-sdk==0.7.2 һәм jev-1.13.0 моделен куллана. TYPESAFE_API_KEY ачкычы чыганак кодтан тыш саклана. Халәт query һәм passage ны атый; Score соравында үзеннән-үзе аңлашылган рубрика бар. Җавапны типлы коллекцияләр аша укы, response.model һәм usage.input_tokens ны сакла. Python клиенты, җавап типлары.

Минималь чакыру формасы: with TypeSafeClient(model="jev-1.13.0", timeout=30) as client: response = client.system_one(state = state, questions={"relevance": Score(instructions=rule, criteria=levels)}). state, rule һәм levels — югарыда беркетелгән кереш, күрсәтмә һәм рубрика, яшерен көйләүләр түгел. Аннары grade = response.scores["relevance"] һәм gain = sum((2**r - 1) * p for r, p in grade.probabilities.items()). Python да дәрәҗә ачкычлары бөтен сан, JSON да юл була.

Тулы өстәмә мисал һәм автоном юл лабораториядә бар. Бүлекне уку болытка мөрәҗәгать итми һәм акча тотмый. Сортлау алдыннан дәрәҗә ачкычларын, саннарның чиклелеген, аралыгын һәм ихтималлык суммасын тикшер. Юк яки бозылган җавап — эксплуатация хатасы, документның нуль релевантлыгы түгел.

Вакыт чиге — файдасыз документ түгел

Модельгә мөрәҗәгать — кыска исемлекне яңадан ранжирлауның бер генә операциясе. Параллельлекне, кабатлауларны, гомуми вакытны һәм чыгымны чиклә. Бер мөрәҗәгать таймауты бөтен top-k ны чикләми. Хатада безнең гади кагыйдә бөтен сорауның баштагы тәртибен кайтара һәм начараюны терки. Берничә көтелгән gain ны калган BM25 бәяләре белән кушма: шкалалары алышына алмый.

Чимал җавапларны модель версиясе, рубрика һәм кереш хешлары, тел һәм алдан эшкәртү белән кешла. Кабатлауларны һәм кеш халәтен кертеп, бөтен исемлек вакытын үлчә, бер чакыруны гына түгел. Серләрне һәм ябык текстларны бастырма: SDK тән журналы башлыклар яшерелсә дә керешне ача ала. Челтәр сынавы алдыннан хәзерге лимитларны һәм бәяләрне тикшер. Модельләр, клиент көйләүләре.

«Jev ны өстәмә» — мөмкин нәтиҗә

Куллануга кертү тәкъдиме файданы һәм чикләрне атарга тиеш. Яхшырак nDCG яңадан ранжирлауны нигезли ала, ләкин ихтималлык бусагаларын түгел. Яхшырак контекст карарлары документ тәртибен үзгәртмичә контроллерны нигезли ала. Охшаш сыйфат һәм начаррак тоткарлык хәзерге системаны калдырырга сәбәп. Русча кисем зәгыйфь булса, гомуми уртача яхшырса да, ул трафикта кулланудан баш тартырга мөмкин.

Кабул итү критерийларын тест алдыннан яз: кирәкле сыйфат аермасы, рөхсәт ителгән нигезсез гамәлләр, минималь каплау, вакыт һәм бәя чикләре. Аннары нәрсә үтәлгәнен, нәрсә үтәлмәгәнен һәм кайда дәлил аз икәнен хәбәр ит. Синтетик мисаллар механизмның аңлашылуын һәм кабатлануын күрсәтә. Алар модельнең чын кулланудагы файдасын расламый. Дөрес тәҗрибәле тискәре тәкъдим уңайсы белән бер үк бәягә лаек.

API ачкычыннан башка хисап төзе

Jev карарлары лабораториясен ач. Төп автоном юл хисапларны һәм мәгълүмат агып чыгуын тикшерү өчен ачык билгеләнгән синтетик мисаллар куллана. Бу үлчәнгән Jev җавапларын яңадан уйнау түгел. Көтелгән gain ны яңадан исәплә, сорау гаиләләрен бүлүне сакла, ихтималлык вакыйгасын ранжирлау дәрәҗәсеннән аер һәм туңдырылган бинар контроллерны һәрвакыт рөхсәт итү һәм һәрвакыт кичектерү белән чагыштыр.

Өч аерым өлеш тапшыр: ранжирлау, ихтималлык сыйфаты һәм карар нәтиҗәләре. Бирелгән очраклардан ике хата төрен аңлат, шул исәптән ранжирлау метрикасы күрмәгән берсен. Синтетик йөртү нәрсәне раславын һәм нәрсәгә чын бенчмарк кирәклеген әйт. Челтәр юлы аерым, ачык бюджет һәм ачкыч таләп итә; ул мисалларны яшерен түләүле запросларга алыштырмасын. Тәкъдимең «бу нәтиҗәне кайсы бәйсез билге тикшерелә торган итә?» дигән сорауга җавап бирсен.

Модель бәяли, кагыйдә хәл итә

Баштагы тоташу соравына кайт. Эзләп алу кандидатлар китерә; рубрика файдалы дәлилне билгели; типлы бүленеш билгесезлекне күрсәтә; сайланган файда тәртип ясый. Аерым билгеләр ихтималлык шкаласын тикшерә. Аннары югалту матрицасы гамәлне билгели, ә бөтен контекстны тикшерү җитмәгән кушылмаларны һәм каршылыкларны тота. Һәр ук яңа фараз өсти; аңа хисапта урын кирәк.

Серёга Сэр Косинусның линейкасын калдыра, ләкин аңа җавап бәясен билгеләргә кушмый. Гудхарт уңайлы яшеренү урынын югалта: өч төрле мәсьәлә урынына бер матур бәя. Хәзер һәр Jev интеграциясенә өч соравың бар: нәрсәнең ихтималлыгы, нинди бәяле гамәл, кайсы бәйсез нәтиҗәләр буенча тикшерелгән? Төп дәрес башка модельләргә дә ярый: барлык саннарны бер API кайтарса да, тәртип, ихтималлык һәм гамәл аерым тикшерелә.
