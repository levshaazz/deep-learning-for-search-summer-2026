Лаборатор эшләр Lab 1

BM25’не кулдан яз, ике ранжлаучыны чагыштыр

Инверт индексы + TF-IDF + BM25’не чын бәяләнгән корпуста нульдән; TF-IDF белән BM25’не ныгытылган сорау җыелмасында nDCG@10 буенча чагыштыр.

Тәрҗемә бара — кайбер текст хәзергә башка телдә күрсәтелә.

Максат

Инверт индексы, TF-IDF һәм BM25’не чын бәяләнгән корпуста нульдән язып, аннары TF-IDF белән BM25’не ныгытылган сорау җыелмасында чагыштырып, кайда һәм нигә алар аерылганын — үз нәтиҗәңнән конкрет мисал белән — аңлат.

Биремнәр

  1. BEIR nfcorpus/test’ны йөклә һәм ныгытылган сорау җыелмасын төзе (query_id буенча беренче 30).
  2. Бер ныгытылган схема белән токенлаштыр: кече хәреф → пунктуацияне ал → буш урыннар буенча бүл. (Лаборатор эштә токенлаштыру ныгытылган; өй эшендә үзгәртелә.)
  3. Инверт индексны нульдән төзе: терм → postings [(doc_id, tf)]; шулай ук документ озынлыкларын һәм avgdl’ны яз.
  4. TF-IDF’ны кулдан яз: w(t,d) = tf · log(N/df). tf һәм idf вариантыңны күрсәт; скорлауны сорау термнары авырлыкларын кушу яки косинус белән башкар (үз сайлавың, күрсәт).
  5. BM25’не кулдан яз: k₁ = 1.5, b = 0.75, шомартылган idf ln(1 + (N−df+0.5)/(df+0.5)). Шул ук индексны куллан.
  6. Һәр сорау өчен TF-IDF буенча һәм BM25 буенча top-10’ны тап.
  7. nDCG@10’ны (кулдан, градуацияле gain 2^rel−1, log₂(i+1) дисконты) һәр сорау өчен ике ранжлаучыга да исәплә; һәрберсенең уртачасын бир һәм ранжлау аерылган бер сорауны күрсәт.
  8. Ярым бит анализ яз: BM25 TF-IDF’дан кайда аерыла һәм нигә? Үз конкрет мисалыңда терм ешлыгы туенуына һәм документ озынлыгын нормалаштыруга ишарә ит.

Нәрсә тапшырырга

Башыннан ахырына кадәр эшләп, чагыштыру таблицасын бастыручы lab.py (яки notebook), һәм 1 битлек отчёт: уртача nDCG@10 таблицасы, бер аерылган сорау таблицасы һәм анализ абзацы.

Автогрейдер Stepik — контрольные числа

На Stepik кодовая часть проверяется детерминированным автогрейдером (stepik/graders/grader_lab1_bm25.py): мини-корпус из 8 документов вшит в чекер (без интернета и моделей, допуск 1e-4). Определи в solution.py функции ниже; твоя реализация обязана воспроизвести эти числа точно. Полный прогон на nfcorpus идёт в отчёт (peer-review).

# solution.py — обязательные функции (Stepik: grader_lab1_bm25.py)
tokenize(text) -> list[str]                 # lower; не-алфанум -> пробел; split
build_index(docs) -> {term: {doc_id: tf}}
tfidf_search(docs, query, k) -> [(doc_id, score)]   # w = tf * ln(N/df)
bm25_search(docs, query, k, k1=1.5, b=0.75)         # idf = ln(1+(N-df+0.5)/(df+0.5))
ndcg_at_k(ranking, rels, k) -> float        # gain 2^rel-1, discount log2(i+1)

# Контрольные числа (мини-корпус, tie-break: score desc, doc_id asc):
tfidf_search(docs, 'cat on mat', 3) == [('d1', 3.3480), ('d5', 1.9617), ('d8', 1.3863)]
bm25_search(docs, 'cat on mat', 3)  == [('d1', 3.4834), ('d5', 1.5611), ('d8', 1.2436)]
bm25_search(docs, 'dog', 3)         == [('d2', 0.9170), ('d4', 0.8665), ('d5', 0.7805)]
mean nDCG@10: TF-IDF = 0.9660  ·  BM25 = 0.9685
