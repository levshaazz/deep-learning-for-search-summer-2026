Өй эшләре A1

Тирәнрәк экспериментлар + мәкалә буенча эссе

Дүрт ранжлаучы, өч метрика, параметрлар свибы, токенлаштыруны өйрәнү һәм мөһимлек тесты — аннары бер мәкаләне укып, аның төп рәсемен кулдан яңадан сыз.

Тәрҗемә бара — кайбер текст хәзергә башка телдә күрсәтелә.

Лаборатор эшкә нигезләнеп. 1 нче өлеш — киңәйтелгән эксперименталь тикшеренү; 2 нче өлеш — бер мәкаләне игътибар белән уку һәм аның төп рәсемен кулдан язылган яңа интерпретация.

1 нче өлеш — Код һәм экспериментлар (60%)

BEIR nfcorpus/test’ны тулы test-сорау җыелмасында куллан (опциональ рәвештә төп экспериментны scifact/test өстендә кабатла).

  1. Ранжлаучылар (кулдан): Boolean-OR базлайны, TF-IDF (косинус), BM25 һәм BM25 + TF-IDF’ның RRF-фьюжны (Σ 1/(k+rank), k=60).
  2. Метрикалар (кулдан): барлык сораулар буенча nDCG@10, MAP, MRR — уртачасын һәм һәр сорау буенча таралышын бир (box/violin яки гистограмма). Градуацияле gain 2^rel−1 һәм log₂(i+1) дисконтын куллан.
  3. BM25 параметрларын өйрәнү: k₁ ∈ {0.5,1.0,1.2,1.5,2.0,3.0} һәм b ∈ {0,0.25,0.5,0.75,1.0} буенча свип; nDCG@10’ны k₁’дан (b ныгытылган) һәм b’дан (k₁ ныгытылган) графикларын сыз; иң яхшы (k₁,b)’ны тап һәм формасын аңлат (туену; b=0/1 чикләре).
  4. Токенлаштыруны өйрәнү: шул ук BM25 өстендә ≥3 пайплайнны чагыштыр — (a) кече хәреф+буш урын, (b) + стоп-сүзләрне алу, (c) + Портер стеммингы, (опц. d) subword/BPE. Һәрберсе өчен nDCG@10 / MAP / MRR бир һәм һәр сайлавның нигә ярдәм иткәнен яки зыян иткәнен аңлат (сүзлек күләме, df күчешләре, конфляция). 02 һәм 03 лекцияләргә бәйлә.
  5. Статистик мөһимлек: синең иң яхшы системаң BM25 базлайныннан чыннан да яхшырак, әллә бу очраклымы? Һәр сорау буенча nDCG@10’да парлы тест (t-test һәм/яки Wilcoxon signed-rank) үткәр; уртача аерманы, 95% CI’ны һәм p-value’ны бир, аны аңлат (кирәкле-әмма-җитәрлек түгел; кечкенә n кисәтүе).
  6. Отчёт: графиклар + таблицалар + параметр свибын, токенлаштыруны өйрәнүне һәм мөһимлек тестын ранжлау сыйфатын чыннан да нәрсә хәрәкәтләндергәне турында бер хикәягә бәйләүче фикер алышу.

Автогрейдер Stepik — контрольные числа

Метрики и слияние «руками» проверяет детерминированный автогрейдер (stepik/graders/grader_a1_metrics.py): 3 запроса с градуированными qrels на 12 документах и замороженные ранжирования boolean/TF-IDF/BM25 вшиты в чекер (без интернета, допуск 1e-4). Полное исследование на nfcorpus, графики и тест значимости идут в отчёт (peer-review).

# solution.py — обязательные функции (Stepik: grader_a1_metrics.py)
ndcg_at_k(ranking, rels, k)        # gain 2^rel-1, discount log2(i+1)
average_precision(ranking, rels)   # бинарная rel>=1, знаменатель = все релевантные
reciprocal_rank(ranking, rels)
rrf_fuse(rankings, k=60)           # sum 1/(k+rank), rank с 1; desc, tie doc_id

2 нче өлеш — Мәкалә уку һәм кулдан язылган эссе (40%)

Түбәндәге биш мәкаләнең берсен сайла, аны игътибар белән укы һәм үз сүзләрең белән ике битлек A4 кулдан язылган эссе яз — синең интерпретация, кыскача эчтәлек түгел. Аннары төп рәсем подбиремен башкар.

Подбирем: төп рәсем. Мәкаләнең төп рәсемен — аның үзәк идеясен йөртүче бер диаграмманы — билгелә. Аны үзеңчә (кулдан сызу да ярый) яңадан эшлә, концепцияне оригиналга караганда тирәнрәк ачар өчен: кодлауны үзгәрт, җитмәгән күчәр яки аңлатма өст, ялгышу очрагын күрсәт, яки аны үз Лаборатор эш/өй эше саннарың белән яңадан сыз. Синең вариантың оригиналда күренмәгән нәрсәне ничек күрсәткәнен әйтүче кыска аңлатма өст.

Нәрсә тапшырырга

Ике битлек кулдан язылган эссенең фотосы/сканы, яңадан эшләнгән төп рәсем (кулдан яки санлы) һәм бер абзац — кайсы рәсемне сайлавың һәм нигә ул төп рәсем булуы турында.
