Лаборатор һәм өй эшләре

7 эш · 3–14 атналар · 3 лаборатор, 3 өй эше һәм финал проекты · кулдан эшлә, үлчә, чагыштыр

Тәрҗемә бара — кайбер текст хәзергә башка телдә күрсәтелә.

Бу биремнәр лекцияләрне эшләүче кодка әйләндерә. Һәр лаборатор эш — кечкенә, кулдан башкарыла торган җыелма; һәр өй эше — тирәнрәк эксперименталь тикшеренү һәм мәкалә уку буенча эссе. Барысында да эзләү һәм ранжлауның төп алгоритмнарын кулдан язасың — мәгънә шунда. Түбәндә бер бирем сайла.

Классик IR’дан (BM25, ранг берләштерү, ранжлау метрикалары) нейроэзләүгә — bi-/cross-энкодерлар һәм реранкинг каскады, ColBERT соңгы тәэсир итешүе, SPLADE өйрәнелгән сирәклеге, гибрид берләштерү һәм Learning to Rank — аннары масштабта индексләү (IVF, Product Quantization, HNSW) һәм retrieval-augmented generation аны бәяләү белән (чанклау, сорауны яңадан язу, RAGAS рухындагы метрикалар, LLM-хөкемче смещениеләре).

Гомуми setup (һәр бирем өчен)

Гомуми кагыйдәләр

  • Скорлау, берләштерү, реранкинг, индексләү һәм ранжлауның төп логикасын кулдан яз: инверт индексы, TF-IDF, BM25, RRF, ColBERT MaxSim, SPLADE sparse-dot, RankNet/LambdaRank, ANN индекс структуралары (IVF инверт исемлекләре + nprobe скан, PQ кодлары + ADC таблицасы, exact re-rank), RAG чанклау һәм яңадан язылган сорауларны берләштерү, һәм һәр метрика (nDCG, MAP, MRR, context precision/recall). Бәяләнә торган өлешләрдә rank_bm25, pytrec_eval, китапханә берләштерү/LTR скорерлары, faiss / hnswlib / scann / annoy һәм идарә ителә торган вектор МБ, RAGAS китапханәсеннән башка.
  • Рөхсәт ителгән ярдәмчеләр: мәгълүмат җыелмасын йөкләү (ir_datasets / beir / HuggingFace datasets), numpy, графиклар, токенизатор/стеммер, өйрәтелгән энкодерлар (sentence-transformers, cross-encoders, SPLADE, ColBERT), ANN coarse-квантизаторы һәм PQ кодбуклары өчен k-means (sklearn), һәм — бирем рөхсәт иткәндә — сорауларны яңадан язу / хөкем итү өчен кечкенә җирле генератор. Энкодерлар һәм генератор бары тик эмбеддинглар, логитлар яки текст бирә; син аларны өйрәтмисең, ә скорлау, берләштерү, реранкинг, индексләү, чанклау һәм метрика логикасын үзең язасың.
  • Кабатлап була торган бул: ныгытылган seed (20260605), биремдә күрсәтелгән ныгытылган сорау поднаборлары, детерминистик нәтиҗә. Тикшерүче синең саннарны яңадан җибәреп кабатлый алырга тиеш.
  • Башыннан ахырына кадәр эшләүче код һәм кыска отчёт (PDF) тапшыр. Сайлаган һәр формула вариантын күрсәт (tf схемасы, idf формасы, gain функциясе).

Мәгълүмат җыелмасы һәм керү

Активностьлар 1 һәм 2 BEIR куллана: Лаборатор эшләр — nfcorpus (≈3,6 мең документ, 323 test-сорау, градуацияле qrels); өй эшләрендә төп прогонны scifact өстендә кабатларга мөмкин. Лаб 3 һәм Өй эше 3 моның урынына EnterpriseRAG-Bench (onyx-dot-app, MIT) куллана — синтетик корпоратив корпус (Slack, Gmail, GitHub, Jira, Confluence, Drive, …), ground-truth документлар ҺӘМ һәр сорауга gold-җаваплар белән — ул шул ике активность эчендә йөкләнә һәм субсетлана. Нейро-биремнәр шулай ук кечкенә өйрәтелгән энкодерлар йөкли (биремдә күрсәтелгән, барысы да подвыборкада CPU-да эшләрлек). BEIR корпусын ir_datasets аша йөклә:

import ir_datasets
ds = ir_datasets.load("beir/nfcorpus/test")     # graded relevance (0..2)
docs    = {d.doc_id: d.text for d in ds.docs_iter()}
queries = {q.query_id: q.text for q in ds.queries_iter()}
qrels   = {}
for qr in ds.qrels_iter():
    qrels.setdefault(qr.query_id, {})[qr.doc_id] = qr.relevance

Ныгытылган сорау җыелмасы: Лаборатор эш өчен query_id буенча тәртипкә салынган беренче 30 test-сорау; өй эше өчен тулы test-сорау җыелмасы. Хәтер аз булса — корпусны берәр qrel’да очраган документлар һәм seed-20260605 очраклы үрнәк белән чикләп, бу подбюлүне яз.
