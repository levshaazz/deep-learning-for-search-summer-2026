Why the old metrics don't fit generation

recall@k graded a ranked list — but there is no key for free-text

What broke

  • No gold answer. For a real question there is rarely one canonical paragraph to diff against.
  • Many right answers. The same fact can be phrased a hundred valid ways — exact-match scores them all zero.
  • Two failure modes at once. An answer can drift off-topic and invent facts; one number can't separate them.

What we need instead

Metrics that grade a generated answer against the retrieved context and the question — not against a reference key. That is exactly the gap RAGAS fills: reference-free scores that decompose RAG quality into faithfulness, relevance, and both sides of retrieval.

problem-no-gold. Classic IR metrics (recall@k, MRR — L1/L9) graded a ranked list against a known relevant set. Generation has no gold answer, many valid phrasings, and two simultaneous failure modes — so exact-match/BLEU don't fit. Motivates reference-free metrics (RAGAS) next.
