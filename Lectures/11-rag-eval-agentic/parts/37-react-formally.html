ReAct, formally

interleave reasoning and acting in one trace
Definition · ReAct (arXiv:2210.03629)
Alternate Thought (reason) → Action (call a tool, e.g. lookup[entity]) → Observation (the result), looping until finish[answer].
  • ·Reasoning guides acting: the Thought picks the next retrieval; the Observation updates the next Thought. Reasoning-only can't fetch; acting-only can't plan multi-hop.
  • ·Retrieval is a tool the model calls when needed, not a fixed prelude. The loop is the agent (Yao et al., ICLR 2023).
  • ·Free-form: improvised in natural language, so it works on any LLM — but with no guarantee it grades its own retrievals. Self-RAG and CRAG fix that.
