Чередуй Мысль (рассуждение) → Действие (вызов инструмента, напр. lookup[entity]) → Наблюдение (результат), зацикливая до finish[answer].Alternate Thought (reason) → Action (call a tool, e.g. lookup[entity]) → Observation (the result), looping until finish[answer].
  • ·Рассуждение направляет действие: Мысль выбирает следующее извлечение; Наблюдение обновляет следующую Мысль. Только рассуждение не достанет; только действие не спланирует многопрыжковость.Reasoning guides acting: the Thought picks the next retrieval; the Observation updates the next Thought. Reasoning-only can't fetch; acting-only can't plan multi-hop.
  • ·Извлечение — инструмент, который модель вызывает при нужде, а не фиксированная прелюдия. Цикл и есть агент (Yao и др., ICLR 2023).Retrieval is a tool the model calls when needed, not a fixed prelude. The loop is the agent (Yao et al., ICLR 2023).
  • ·Свободная форма: импровизация на естественном языке, поэтому работает на любой LLM — но без гарантии, что она оценивает свои извлечения. Self-RAG и CRAG это чинят.Free-form: improvised in natural language, so it works on any LLM — but with no guarantee it grades its own retrievals. Self-RAG and CRAG fix that.
