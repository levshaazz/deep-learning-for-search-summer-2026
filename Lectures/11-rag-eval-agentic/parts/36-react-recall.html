Отслеживай, держит ли топ-1 извлечение ответ на каждом шаге. Первый lookup возвращает имя основателя — полезно, но не то, о чём спрашивали, поэтому recall@1 остаётся 0. Лишь после подачи этого имени во второй lookup появляется ответ: recall@1 прыгает к 1. Один выстрел останавливается на шаге 0 (recall@1 = 0); цикл замыкает цепь. Но цикл может и провалиться: неверный первый lookup отравляет каждый следующий прыжок, а без самооценки ReAct может зациклиться навсегда или галлюцинировать Наблюдение — ровно тот режим отказа, для ловли которого Self-RAG/CRAG добавляют оценщика.Track whether the top-1 retrieval holds the answer at each step. The first lookup returns the founder's name — useful, but not what was asked, so recall@1 stays 0. Only after feeding that name into the second lookup does the answer appear: recall@1 jumps to 1. A single shot stops at step 0 (recall 0); the loop closes the chain. But the loop can also fail: a wrong first lookup poisons every later hop, and with no self-grading ReAct can loop forever or hallucinate an Observation — exactly the failure mode Self-RAG/CRAG add a grader to catch.
