Why the loop works — recall@1, by hand

the bridging fact only arrives on hop 2
$$ \text{recall@1 by step} = [\,0,\ 0,\ 1\,] $$ $$ \text{step 0 (lookup founder): } 0 \quad\to\quad \text{step 1 (still no education): } 0 \quad\to\quad \text{step 2 (founder} \to \text{study): } \mathbf{1} $$

Track whether the top-1 retrieval holds the answer at each step. The first lookup returns the founder's name — useful, but not what was asked, so recall@1 stays 0. Only after feeding that name into the second lookup does the answer appear: recall@1 jumps to 1. A single shot stops at step 0 (recall 0); the loop closes the chain. But the loop can also fail: a wrong first lookup poisons every later hop, and with no self-grading ReAct can loop forever or hallucinate an Observation — exactly the failure mode Self-RAG/CRAG add a grader to catch.
