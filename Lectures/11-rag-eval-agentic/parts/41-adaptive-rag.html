Определение · Adaptive-RAG (arXiv:2403.14403)Definition · Adaptive-RAG (arXiv:2403.14403)
Лёгкий классификатор сложности направляет каждый запрос к самой дешёвой стратегии, что может на него ответить: без извлечения · одношаговый RAG · многошаговый (итеративный) агентный RAG.A lightweight complexity classifier routes each query to the cheapest strategy that can answer it: no retrieval · single-step RAG · multi-step (iterative) agentic RAG.
  • ·Простые / известные факты → отвечай сразу, без извлечения (не плати за то, что модель уже знает).Simple / known facts → answer directly, no retrieval (don't pay for what the model already knows).
  • ·Однопрыжковый → один проход «извлеки-затем-генерируй» — классический цикл.Single-hop → one retrieve-then-generate pass — the classic loop.
  • ·Многопрыжковый / композиционный → разверни полный цикл ReAct (разложи, извлеки, рассуждай, повтори). Маршрутизатор тратит вычисления агентного цикла лишь там, где вопрос это заслужил — Jeong и др. (NAACL 2024).Multi-hop / compositional → spin up the full ReAct loop (decompose, retrieve, reason, repeat). The router spends agent-loop compute only where the question earns it — Jeong et al. (NAACL 2024).
