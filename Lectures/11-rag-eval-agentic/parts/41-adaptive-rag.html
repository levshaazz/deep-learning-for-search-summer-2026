Adaptive-RAG

match the loop's effort to the question's complexity
Definition · Adaptive-RAG (arXiv:2403.14403)
A lightweight complexity classifier routes each query to the cheapest strategy that can answer it: no retrieval · single-step RAG · multi-step (iterative) agentic RAG.
  • ·Simple / known facts → answer directly, no retrieval (don't pay for what the model already knows).
  • ·Single-hop → one retrieve-then-generate pass — the classic loop.
  • ·Multi-hop / compositional → spin up the full ReAct loop (decompose, retrieve, reason, repeat). The router spends agent-loop compute only where the question earns it — Jeong et al. (NAACL 2024).

The meta-lesson: match loop effort to question complexity — don't run a multi-step agent on a one-hop fact. Pairs with the don't-over-engineer boundary slide.
