ReAct — универсальный вариант по умолчанию: без обучения, работает на любой модели. Self-RAG вшивает критику в веса; CRAG накладывает оценщика сверху; Adaptive-RAG выбирает, что запускать. Все четыре — одна идея: перестань доверять одному извлечению — зацикливай, оценивай, чини.ReAct is the universal default — no training, works on any model. Self-RAG bakes the critique into the weights; CRAG bolts a grader on after; Adaptive-RAG chooses which to run. All four are the same idea: stop trusting one retrieval — loop, grade, repair.
