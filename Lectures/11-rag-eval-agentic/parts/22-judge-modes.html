Pointwise vs pairwise · reference-free vs reference-based

two design choices, four corners
mode asks the judge strength weakness use when…
pointwise“score this answer 1–5”one absolute number per answer; cheapthe scale drifts run-to-runtracking one system over time
pairwise“which is better, A or B?”no shared scale to drift; more reliableO(n²) comparisons to rank manycomparing two candidate systems
reference-freejudge from question + answer (+ retrieved context)no gold answer needed; runs at scalecan't catch subtle factual gapsopen-ended generation, no key
reference-basedjudge against a gold answercatches missing/wrong factsneeds an expensive reference seta curated benchmark exists

Pairwise is usually the safer default — a relative verdict has no absolute scale to wander. And if you have gold answers, reference-based judging is stronger; if you don't (the RAG-in-production case), reference-free is what you've got. The choice is about what ground truth you can afford.
