Why a loop, not a single shot

multi-hop questions hide the answer behind a fact you don't have yet

The single-shot wall

  • Two-hop question: “What did the founder of Acme Corp study?” One retrieval can't reach it — you must first learn who the founder is.
  • Stuffing more chunks doesn't help: the bridging fact isn't phrased like the question, so it never ranks.
  • The answer lives behind an intermediate fact the first query can't name.

The agentic fix

Iterate: reason about what's missing → act (retrieve the next fact) → observe → repeat, and grade each result before trusting it. The loop turns a flat retriever into something that plans, checks its own work, and repairs bad retrievals — the same self-correction we built in L10, now driven by the model itself.
