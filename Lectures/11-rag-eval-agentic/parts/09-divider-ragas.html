RAGAS — four reference-free metrics

If you can't compare to a gold answer, compare to what you retrieved. RAGAS scores a RAG answer with four numbers, no reference required: faithfulness (is it grounded?), answer relevance (does it address the question?), context precision and context recall (did retrieval do its job?). Each is a fraction we can check by hand.

turn-ragas. RAGAS (Es et al., 2023, arXiv:2309.15217): four reference-free metrics. The trick is to grade against the question + retrieved context rather than a gold answer. Each metric is a hand-checkable fraction in data/l11-ragas.json.
