“RAGAS is objective truth”

applicability boundaries — the metrics lean on a model too
What students think

“RAGAS gives reference-free numbers, so the scores are objective ground truth — if faithfulness is 0.75, that is simply how faithful the answer is.”

Every RAGAS metric is computed by an LLM: a model decides which claims are “supported,” generates the reverse-engineered questions, and judges relevance. The fractions are crisp, but the judgments behind them inherit the model's mistakes and biases. RAGAS is a fast, cheap, repeatable proxy — excellent for tracking regressions and comparing systems — but it is not a reference. The score also depends on the decomposition: a different judge model (or temperature) splits the answer into different claims, so faithfulness is not comparable across judge backends — fix the judge model and version before tracking it over time. Calibrate it against human labels on a sample, and never report a single decimal as if it were measured with a ruler. The decomposition is the real gift; the absolute number is a proxy.

Reference-free does not mean judgment-free. The same caveat is about to bite much harder when we let a model grade whole answers head-to-head.
