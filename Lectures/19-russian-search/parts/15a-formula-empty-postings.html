Отсюда честная формулировка Акта 2. Золотой документ по формам не «на втором месте» — он не извлечён. Постинг-лист (postings list) терма «котята» пуст, и никакая настройка \(k_1\) и \(b\) этого не изменит: нормализация меняет не формулу, а словарь.Hence the honest wording of Act 2. On surface forms the gold document is not “second” — it is not retrieved. The postings list for “котята” is empty, and no tuning of \(k_1\) or \(b\) changes that: normalization changes not the formula but the dictionary.

The formal repair of a sloppy claim. Retrieval is a two-stage thing: candidate generation (union the postings lists of the query terms) then scoring. If df(t)=0 the postings list is empty, so a document containing only other forms is never a candidate — it has no rank at all. This matters because the surface-form run on our toy puts the gold document at "rank 2" only as a stable-sort artefact among four documents scoring exactly 0.0. The honest statement is "not retrieved", and it is a stronger story: zero beats second place. Normalization does not touch the BM25 formula; it changes which strings become dictionary terms.
