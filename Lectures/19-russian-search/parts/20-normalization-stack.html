Три ловушки, которых не видно в туториалах. pymorphy2 не поддерживается с 2020 года — ставь pymorphy3. Mystem — несвободный бинарник с запретом коммерческого использования: в прод его нельзя, как бы он ни был быстр. И лемматизатора русского в Elasticsearch из коробки нет — там только Snowball; лемма приезжает своим препроцессором либо hunspell.Three traps the tutorials skip. pymorphy2 has been unmaintained since 2020 — install pymorphy3. Mystem is a non-free binary whose licence forbids commercial use: it cannot go to production, however fast it is. And Elasticsearch ships no Russian lemmatizer — only Snowball; a lemma arrives via your own preprocessor or hunspell.

The toolbox, corrected. The previous version marked pymorphy2 as the recommended lemmatizer with a cell-good; pymorphy2's last release is 0.9.1 from September 2020 and its successor's README calls the project unmaintained, so the flagship is pymorphy3 (2.0.6, October 2025, MIT). Mystem was recommended with no licence note at all — it is a Yandex binary under a non-commercial agreement, which is a legal problem for anyone shipping. The "context" column is the honest version of slide 16's correction: only Mystem, spaCy, Stanza and Natasha look at neighbouring words; pymorphy returns a ranked parse list for an isolated token. Note also that spaCy's Russian lemmatizer IS pymorphy3 underneath, so it inherits that blindness for lemmas while adding context for morphological tags. Speeds are order-of-magnitude, measured on a single CPU core.
