JSON · settings.analysisindex
"char_filter": {
  "yo2e":   {"type":"mapping","mappings":["ё=>е","Ё=>Е"]},
  "confus": {"type":"mapping",
             "mappings":["a=>а","c=>с","e=>е","o=>о",
                         "p=>р","x=>х","y=>у"]}
},
"filter": {
  "ru_stop": {"type":"stop","stopwords":["и","в","на","что"]},
  "ru_stem": {"type":"stemmer","language":"russian"}
},
"analyzer": {
  "ru": {
    "char_filter": ["yo2e","confus"],
    "tokenizer":   "standard",
    "filter":      ["lowercase","ru_stop","ru_stem"]
  }
}

char_filter стоит перед стоп-фильтром — иначе «всё» переживёт удаление стоп-слов, а «все» нет. В ru_stop нет ни «не», ни «ни», ни «без». Все семь строчных двойников перечислены: без «e», «x», «y» слово вроде «сера» проскочит. Confusables вешай только на русское поле.The char_filter runs before the stop filter — otherwise “всё” survives stop-word removal and “все” does not. ru_stop contains no не, ни or без. All seven lowercase twins are listed: leave out e, x or y and a word like “сера” slips through. Hang confusables on the Russian field only.

Одно правило: тот же аналайзер в обоих плечах. One rule: the same analyzer in both arms.
Capstone — the take-away configuration. Left: an Elasticsearch analyzer that puts a ё→е mapping char_filter and a confusables mapping BEFORE the stop filter (order matters: the Lucene stop list has no ё forms, so «всё» survives removal while «все» does not), then standard tokenizer, lowercase, a stop list with the negations не/ни/без removed, and the russian stemmer, which is Snowball. The confusables mapping lists all SEVEN lowercase Cyrillic letters that have a Latin twin (а с е о р х у) — an earlier draft listed only four, which let a fully homoglyphable word such as «сера» through. Confusables should be attached to the Russian field only, or it will mangle English text. The mapping adds a keyword sub-field for entities, where case and ё must be preserved. Right: three lines of query preprocessing — layout restoration, NFC normalization, and the same "ru" analyzer at search time. The rule the whole slide exists for: the same analyzer in both arms; a one-sided fix is worse than none.
