Gotcha 3 — transliteration, with the standards named and one myth killed. The widely repeated claim that GOST 7.79-2000 gives щ → shch is false: system B gives shh (and ш→sh, ж→zh, ч→ch, х→x, ё→yo), system A — which is ISO 9:1995 — gives the diacritic ŝ (š, ž, h). So «щука» is ŝuka under ISO 9, shhuka under GOST system B, and shchuka under BGN and the Russian passport rules (FMS order No. 211 of 2014, following ICAO Doc 9303). System B's real sting is х→x: «хорошо» becomes xorosho, which no naive matcher recovers. Users obey none of these and code-switch inside a sentence, so the practical answer is not a single map but a variant dictionary for high-value entities plus a dense arm that spans both scripts.
