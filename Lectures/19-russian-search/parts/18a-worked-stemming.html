Хорошая новость: извлечено уже три документа из пяти вместо одного — ответ вернулся в выдачу. Плохая: впереди него встал «щенок играл с мячом», потому что документ короче, а совпал у обоих только общий глагол.

Good news: three of five documents are retrieved instead of one — the answer is back in the list. Bad news: “щенок играл с мячом” sits above it, because that document is shorter and the only shared term is the common verb.

Лекция рекомендует стемминг быстрым дефолтом — и на её собственном корпусе он задачу не решает. Причина ровно та, что на прошлом слайде: три стема на одну лексему.

The lecture calls stemming the fast default — and on its own corpus it does not solve the task. The reason is the previous slide’s: three stems for one lexeme.

Worked-by-hand part 2, the pass the deck never used to measure. Same five documents, same BM25, Snowball applied symmetrically. The query becomes "котят игра". df(котят)=0 — the gold document stems to "котенок", the shop document to "кот" — so the noun contributes nothing and only the verb "игра" (df=3, idf=0.539) scores. The gold gets 0.5291 but the puppy document gets 0.5827 purely on length normalisation (4 tokens vs 5), so it ranks first. Retrieval improves from 1/5 to 3/5, ranking does not. This is the honest picture the recommendation needs: stemming is cheap and it helps a lot on real corpora (Savoy 2009 measured +83.6 % MAP for Snowball on Russian CLEF collections) but it cannot repair a stem alternation, and on this corpus only lemmatization does.
