Пример 6 — каузальное внимание Example 6 — causal attention

Разбор · query = \(t_2\) Worked example · query = \(t_2\)

Три токена, query — \(t_2\), сырые оценки \((0,\,2,\,3)\) по \((t_1,t_2,t_3)\). Серёга завешивает правую половину полотна: сравним без маски и с causal-маской. Three tokens, query is \(t_2\), raw scores \((0,\,2,\,3)\) over \((t_1,t_2,t_3)\). Séréga curtains off the right half of the cloth: compare no-mask vs causal mask.

01
Без маски — будущее доминирует No mask — the future dominates
softmax(0, 2, 3) = (0.035, 0.259, 0.705). Токен \(t_3\) (будущее!) забирает 70% веса — это утечка. softmax(0, 2, 3) = (0.035, 0.259, 0.705). Token \(t_3\) (the future!) takes 70% of the weight — a leak.
(0.035, 0.259, 0.705)
02
Ставим causal-маску Apply the causal mask
Query \(t_2\) видит только \(t_1, t_2\). Скор \(t_3\) → \(-\infty\). Остаются \((0,\,2)\). Query \(t_2\) sees only \(t_1, t_2\). The \(t_3\) score → \(-\infty\). What remains is \((0,\,2)\).
(0, 2, −∞)
→
Softmax по разрешённым позициям Softmax over allowed positions
softmax(0, 2) = (0.119, 0.881), вес \(t_3 = 0\). Будущее исключено — авторегрессия сохранена. softmax(0, 2) = (0.119, 0.881), weight of \(t_3 = 0\). The future is excluded — autoregression preserved.
(0.119, 0.881, 0)
