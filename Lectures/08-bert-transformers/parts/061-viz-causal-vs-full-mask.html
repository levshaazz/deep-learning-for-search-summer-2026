✓ — разрешено (вес после softmax); \(-\infty\) — закрыто (вес 0). Маска применяется до softmax. ✓ — allowed (weight after softmax); \(-\infty\) — blocked (weight 0). The mask is applied before softmax.

Слева — каждый query видит все keys (полное внимание BERT). Справа — query \(q_i\) видит только \(k_j,\ j\le i\); будущее закрыто \(-\infty\). Left — every query sees all keys (BERT's full attention). Right — query \(q_i\) sees only \(k_j,\ j\le i\); the future is blocked with \(-\infty\).

Зелёные ячейки — разрешённые позиции (вес после softmax), красные с −∞ — запрещённые (вес 0). Полная матрица слева = BERT; верхнетреугольно-закрытая справа = decoder. Маска применяется до softmax.
