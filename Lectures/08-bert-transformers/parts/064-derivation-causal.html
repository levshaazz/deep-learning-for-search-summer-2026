Почему треугольная маска = авторегрессия Why a triangular mask = autoregression

Шаг за шагомStep by step

1. Хотим обучать модель на \(p(x_t \mid x_{<t})\) — каждый токен по строго прошлому контексту.

1. We want to train on \(p(x_t \mid x_{<t})\) — each token from its strictly past context.

2. Если в self-attention позиция \(i\) видит \(j>i\), то предсказание \(x_{i+1}\) уже «знает» ответ — обучение тривиально и неверно.

2. If position \(i\) attends to \(j>i\), the prediction of \(x_{i+1}\) already "knows" the answer — training is trivial and wrong.

3. Добавляем \(M_{ij}=-\infty\) при \(j>i\) до softmax → \(\mathrm{softmax}\) даёт вес \(0\) на все будущие позиции.

3. Add \(M_{ij}=-\infty\) for \(j>i\) before softmax → \(\mathrm{softmax}\) assigns weight \(0\) to all future positions.

4. Значит выход позиции \(i\) — функция только от \(x_{\le i}\). Все \(T\) предсказаний считаются параллельно за один проход, но каждое уважает \(x_{<t}\) — ровно авторегрессионная факторизация \(p(x)=\prod_t p(x_t\mid x_{<t})\). \(\square\)

4. So position \(i\)'s output is a function of only \(x_{\le i}\). All \(T\) predictions compute in parallel in one pass, yet each respects \(x_{<t}\) — exactly the autoregressive factorization \(p(x)=\prod_t p(x_t\mid x_{<t})\). \(\square\)
