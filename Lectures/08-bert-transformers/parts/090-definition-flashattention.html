Точное softmax-attention (та же формула, не аппроксимация; результат совпадает с обычным с точностью до порядка операций с плавающей точкой), но IO-aware: вычисляется блоками — тайлинг Q, K, V по SRAM и online softmax, так что матрица \(n\times n\) никогда не пишется в HBM.

Exact softmax attention (the same formula, not an approximation; the result matches standard up to floating-point operation order), but IO-aware: computed in blocks — tiling Q, K, V through SRAM with an online softmax, so the \(n\times n\) matrix is never written to HBM.

$$\text{память: } O(n^2)\ \longrightarrow\ O(n)$$

Выигрыш — по памяти и IO (меньше обращений к HBM), не по формуле. Это НЕ аппроксимация и НЕ линейное внимание. FlashAttention-2 — дальнейшая оптимизация. The gain is in memory and IO (fewer HBM accesses), not the formula. It is NOT an approximation and NOT linear attention. FlashAttention-2 optimizes further.

Ключевой факт: FlashAttention = ТОЧНОЕ внимание. Считается та же softmax-формула, не аппроксимация; тайлинг + online-softmax меняют порядок FP-суммирования, поэтому результат совпадает с обычным с точностью до порядка операций (не бит-в-бит). Экономия — память/IO, n×n не материализуется в HBM. Не путать с линейным/разреженным вниманием, которые приближают softmax.
