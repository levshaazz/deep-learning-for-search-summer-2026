BERT — encoder + fine-tune BERT — encoder + fine-tune

Encoder-only, bidirectional через MLM. Pretrain один раз, затем дообучаем лёгкую голову (и веса) под каждую задачу — обновляем параметры.

Encoder-only, bidirectional via MLM. Pretrain once, then fine-tune a light head (and weights) per task — parameters are updated.

КогдаWhen

Понимание / классификация / QA с размеченной выборкой. Understanding / classification / QA with a labelled set.

GPT — decoder + prompt GPT — decoder + prompt

Decoder-only, авторегрессия с causal-маской. Задачу задаём промптом (zero/few-shot); веса не трогаем — in-context conditioning.

Decoder-only, autoregressive with a causal mask. The task is set by a prompt (zero/few-shot); weights are untouched — in-context conditioning.

i
КогдаWhen

Открытая генерация, гибкое применение без разметки. Open-ended generation, flexible use without labels.

Контраст парадигм: BERT обновляет веса (fine-tune), GPT кондиционируется промптом (few-shot, без обновления весов). Не смешивать.
