Повтор Recap

Query — что токен ищет; Key — чем себя описывает; Value — что несёт. Все три — проекции одного входа \(X\): \(Q=XW_Q,\ K=XW_K,\ V=XW_V\).

Query — what a token looks for; Key — how it describes itself; Value — what it carries. All three are projections of the same input \(X\): \(Q=XW_Q,\ K=XW_K,\ V=XW_V\).

$$ \mathrm{Attention}(Q,K,V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V $$

Число с доски (Ex1, 3 токена, \(d_k=4\)): оценки \(E_1=(1,0,3)\) → веса \(A_1=(0{,}114,\,0.042,\,0.844)\) → выход \(Y_1=(0{,}958,\,0.886)\) — контекстный вектор, притянутый к \(V_3\). Полный вывод и разбор у доски — лекция 7, слайды 13–19 (Vaswani et al. 2017). Board number (Ex1, 3 tokens, \(d_k=4\)): scores \(E_1=(1,0,3)\) → weights \(A_1=(0.114,\,0.042,\,0.844)\) → output \(Y_1=(0.958,\,0.886)\) — a context vector pulled toward \(V_3\). Full derivation and worked walk-through — Lecture 7, slides 13–19 (Vaswani et al. 2017).

Recap-слайд, не вывод: Q/K/V-роли + формула + числа Ex1 (scores (1,0,3) → A=(0.114,0.042,0.844) → Y1=(0.958,0.886); те же числа гейтит facts-gate).
