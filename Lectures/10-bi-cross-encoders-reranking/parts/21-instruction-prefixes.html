Запрос короткий и недосказанный; документ длинный и утвердительный. Многие энкодеры обучены с префиксом роли, и без него качество падает:A query is short and under-specified; a passage is long and declarative. Many encoders are trained with a role prefix, and omitting it measurably hurts:

  • ·E5: к запросу —prepend "query: ", к документу —to queries, "passage: ". to passages.
  • ·BGE: к запросу —prepend "Represent this sentence…: "; документ — без префикса. to the query; the passage gets none.
  • ·Это наследник двух башен DPR: одна общая модель + токен роли вместо двух отдельных энкодеров.This is DPR’s two towers, collapsed: one shared model plus a role token instead of two separate encoders.

Симметричные задачи (STS, кластеризация) используют query: для обеих сторон.Symmetric tasks (STS, clustering) use query: on both sides.

A silent accuracy lever most people miss. The query and the passage live on different distributions — one short and vague, one long and declarative — so several modern encoders are trained to be told which role a text plays. E5 wants the literal strings query colon and passage colon; BGE wants a represent-this-sentence instruction on the query only. Forget the prefix and you lose points for free. Conceptually this is DPR's asymmetric two towers folded into one shared encoder with a role token — and for symmetric tasks you simply use the query prefix on both sides.
