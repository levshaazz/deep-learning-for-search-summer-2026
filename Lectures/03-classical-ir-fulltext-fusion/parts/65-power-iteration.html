overview
Exact from the pagerank JSON, edges A to B, B to C, C to A, C to B, damping 0.85. Out-degrees: A 1, B 1, C 2, so C splits its vote in half between A and B. Power iteration repeatedly applies the update to the rank vector. Start uniform at one third each. One node worked in full for iteration 1: PR1(B) = (1−0.85)/3 + 0.85·(PR0(A)/1 + PR0(C)/2) = 0.05 + 0.85·(0.3333 + 0.1667) = 0.05 + 0.425 = 0.475, because B's in-links are A's whole vote plus half of C's. Iterations 2–3 are omitted — the same update repeated. By iteration four the components converge toward their limits, over- and under-shooting by less each step, and after twenty-five iterations the vector settles to A 0.2148, B 0.3974, C 0.3878. B wins because it has two in-links, from A and from C, while A and C have one each. The result depends entirely on the edge set; these are the exact numbers for these edges, not the plan's old hint.
