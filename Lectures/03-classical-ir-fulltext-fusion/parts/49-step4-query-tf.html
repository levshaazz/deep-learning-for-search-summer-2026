Та же насыщающаяся форма, применённая к запросу: слово, повторённое в длинном запросе, весит больше, но с убывающей отдачей. Для коротких веб-запросов (\(f_q=1\)) эффекта нет.Same saturating shape, applied to the query: a word repeated in a long query counts more, but with diminishing returns. For short web queries (\(f_q=1\)) it has no effect.

The fourth factor mirrors step one on the query side. When queries are long — think a paragraph-length description in a TREC topic — a term repeated in the query should count for more, but again with saturation, so the same rational form is reused with its own constant K3. For the short keyword queries typical of web search, where every query term appears once, this factor is exactly one and quietly disappears. It matters historically because Okapi was evaluated on long TREC queries where it helped.
