Vector Space ModelVSM · Salton 1975

Represent both documents and queries as vectors in the same term space, and rank documents by their geometric closeness to the query vector.

A query is just a very short document. Relevance becomes a distance / angle, so retrieval reduces to "find the document vectors nearest the query vector" — the bridge from counts to a real ranking.

Salton's vector space model is the conceptual leap that makes ranking possible. Once documents and the query live in the same term space, "relevant" becomes "close", and we can sort by similarity. The query is treated as a tiny document. This reframing is what lets us replace yes/no boolean matching with a continuous score — and it is exactly the geometry we measured with cosine in Lecture 2, now put to work for retrieval.
