The retrieval problem

query → which of \(N\) documents?

Retrieval = given a query, return the small relevant subset out of \(N\). The relevant set is a handful; the corpus is billions. The whole game is finding the handful without inspecting the billions.

State the task cleanly. A query names a tiny relevant subset hidden in an enormous corpus. The naive approach scores every document and keeps the best — correct, but unaffordable. The art of classical IR is to reach the relevant handful while looking at as few documents as possible, which is exactly what an inverted index buys.
