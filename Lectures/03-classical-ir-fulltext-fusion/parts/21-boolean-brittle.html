Серёга · от булева поиска к ранжированному поискуSerega · from boolean retrieval to ranked retrieval
My pivot point. Boolean retrieval answers yes or no, and an empty result set is a real, common failure I keep hitting. Ranked retrieval scores every document that contains any query term and sorts them, so my best partial match still surfaces. That score is what TF-IDF and BM25 give me. The rest of the lecture is me learning to compute it well — starting with how I represent a document as something I can score.
