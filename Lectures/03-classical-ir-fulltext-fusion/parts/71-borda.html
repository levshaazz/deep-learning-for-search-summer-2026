Каждый ранкер присваивает \(m-1\) очков своему верхнему элементу, \(m-2\) следующему, и так далее. Суммируем по ранкерам. Ни оценок, ни нормализации — только позиции. Но очки падают линейно, поэтому глубокие ранги всё ещё значат немало.Each ranker awards \(m-1\) points to its top item, \(m-2\) to the next, and so on. Sum across rankers. No scores, no normalization — only positions. But points fall linearly, so deep ranks still matter a lot.

Есть и принципиальный вероятностный родственник — CPMF / Plackett–Luce, который моделирует каждый список как выборку из распределения над порядками — но на практике однострочная эвристика RRF (далее) обычно не уступает ему при куда меньшей стоимости.There is also a principled probabilistic cousin — CPMF / Plackett–Luce, which models each list as a draw from a distribution over orderings — but in practice the one-line RRF heuristic (next) usually matches it for far less cost.

Borda count borrows from voting theory: treat each ranker as a voter that awards points by position — top item gets m minus one, next gets m minus two, down to zero. Sum the points across rankers and re-sort. The key advantage over CombSUM is that it uses only positions, so no score normalisation is needed. The weakness is that points decay linearly with rank, so the difference between ranks one and two is the same as between ranks ninety-nine and one hundred — which does not match how users care overwhelmingly about the top. RRF fixes exactly that with a non-linear discount.
