ХодThe move

предвычисли один раз, не сканируй на каждый запросprecompute once, don't scan per query
Ключевая идеяKey idea
Индексируй, а не перебирайIndex, don't loopoffline build · online lookup

Заплати офлайн-цену один раз, чтобы построить структуру данных, и тогда каждый онлайн-запрос — это несколько дешёвых обращений вместо полного сканирования \(O(N)\).Pay an offline cost once to build a data structure, so that each online query is a few cheap lookups instead of a full \(O(N)\) scan.

Эта структура — инвертированный индекс: для каждого терма список документов, которые его содержат. Терм запроса превращается в обращение к словарю; множество кандидатов сжимается с миллиарда до нескольких тысяч ещё до любой оценки.The structure is the inverted index: for every term, the list of documents that contain it. A query term becomes a dictionary lookup; the candidate set shrinks from a billion to a few thousand before any scoring happens.

The conceptual pivot of Part 1. The corpus is mostly static; queries are endless. So move all the heavy work to build time and make query time trivial. The inverted index is precisely that trade: build it once, consult it forever. After this slide, every later idea — compression, skip pointers, BM25 scoring — is an optimisation on top of this structure.
