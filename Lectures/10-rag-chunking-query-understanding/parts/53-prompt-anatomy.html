Definition · the generation prompt
The prompt that turns retrieved chunks into a grounded answer has three parts: a system instruction, the retrieved context, and the question.
  • ·System: "Answer using ONLY the context below. If it isn't there, say you don't know. Cite the source of every claim." — the instruction that forces grounding.
  • ·Context: the reranked top-k chunks, each tagged with its source id — this is what fits in the token budget (recall \(k_{\max}\)).
  • ·Question: the user's query. The "use only the context" + "cite sources" clauses are what make the answer citeable and auditable — the cure for the bare-LLM failures we opened with.
