Определение · промпт генерацииDefinition · the generation prompt
Промпт, превращающий извлечённые чанки в заземлённый ответ, состоит из трёх частей: инструкция-система, извлечённый контекст и вопрос.The prompt that turns retrieved chunks into a grounded answer has three parts: a system instruction, the retrieved context, and the question.
  • ·Система: «Отвечай, используя ТОЛЬКО контекст ниже. Если его там нет — скажи, что не знаешь. Ссылайся на каждое утверждение». — инструкция, которая вынуждает заземление.System: "Answer using ONLY the context below. If it isn't there, say you don't know. Cite every claim." — the instruction that forces grounding.
  • ·Контекст: переранжированные top-k чанков, каждый помечен id источника — то, что влезает в бюджет токенов (вспомни \(k_{\max}\)).Context: the reranked top-k chunks, each tagged with its source id — what fits the token budget (recall \(k_{\max}\)).
  • ·Вопрос: запрос пользователя. «Используй только контекст» + «ссылайся на источники» делают ответ ссылаемым и проверяемым — лекарство от провалов голой LLM.Question: the user's query. "Use only the context" + "cite sources" make the answer citeable and auditable — the cure for the bare-LLM failures.
generation-prompt-anatomy definition. system + context + question. The "answer using ONLY the context" and "cite sources" clauses force grounding/citeability — the cure for the three bare-LLM failures (stale/unciteable/confident). Ties back to the anchor trace's prompt.
