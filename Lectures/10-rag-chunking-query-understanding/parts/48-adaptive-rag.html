Adaptive-RAG

match the effort to the question
Definition · arXiv:2403.14403
A lightweight complexity classifier routes each query to the cheapest strategy that can answer it: no retrieval · single-step RAG · multi-step (iterative) RAG.
  • ·Simple / known facts → answer directly, no retrieval (don't pay for what the model already knows).
  • ·Single-hop → one retrieve-then-generate pass — the classic loop.
  • ·Multi-hop / compositional → iterate (decompose, retrieve, reason, repeat). The router spends compute only where the question earns it — Jeong et al. (NAACL 2024).
