Лёгкий классификатор сложности направляет запрос к самой дешёвой стратегии, способной ответить: без поиска · одношаговый RAG · многошаговый (итеративный) RAG.A lightweight complexity classifier routes each query to the cheapest strategy that can answer it: no retrieval · single-step RAG · multi-step (iterative) RAG.
  • ·Простые / известные факты → отвечай напрямую, без поиска (модель это уже знает).Simple / known facts → answer directly, no retrieval (the model already knows it).
  • ·Одношаговые → один проход «искать-потом-генерировать» — классический цикл.Single-hop → one retrieve-then-generate pass — the classic loop.
  • ·Многошаговые / композиционные → итерируй (декомпозиция, поиск, рассуждение, повтор). Маршрутизатор тратит вычисления лишь там, где вопрос заслуживает — Jeong и др. (NAACL 2024).Multi-hop / compositional → iterate (decompose, retrieve, reason, repeat). The router spends compute only where the question earns it — Jeong et al. (NAACL 2024).
