Сначала кодируем весь документ; режем на чанки после трансформера, до mean-pooling токен-векторов каждого чанка.Encode the entire document first; cut into chunks after the transformer, before mean-pooling each chunk's token vectors.
  • ·Чинит: наивный чанкинг эмбеддит каждый чанк в одиночку → «оно» / «компания» теряет свой референт.Fixes: naïve chunking embeds each chunk alone → "it" / "the company" loses its referent.
  • ·Трюк: внимание видело весь документ, поэтому каждый токен-вектор контекстуализирован — пулинг это сохраняет. Нет компромисса «перекрытие против контекста».Trick: attention saw the whole document, so every token vector is contextualized — pooling keeps it. No overlap-vs-context tradeoff.
  • ·Без дообучения: переиспользует любой энкодер с длинным контекстом — просто переверни «резать-потом-эмбеддить» (Günther и др., 2024).Training-free: reuses any long-context embedder — just invert cut-then-embed (Günther et al., 2024).
  • ·Предел: компромисс исчезает лишь внутри контекстного окна энкодера — документ длиннее него всё равно нужно макро-делить (в статье «long late chunking» снова вводит ограниченное перекрытие между макро-окнами).Limit: the tradeoff vanishes only within the encoder's context window — a document longer than it must still be macro-split (the paper's "long late chunking" re-introduces a bounded overlap between macro-windows).
Late-Chunking frontier definition. arXiv:2409.04701 (Günther et al., Jina AI). Embed-then-chunk, training-free, fixes isolated-chunk context loss — the exact tension the sweep slide exposed (overlap buys recall but not context).
