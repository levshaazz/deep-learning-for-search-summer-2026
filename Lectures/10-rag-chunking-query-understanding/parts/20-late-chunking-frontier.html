Frontier · Late Chunking

embed the whole document, then chunk
Frontier idea · arXiv:2409.04701
Encode the entire document first; cut into chunks after the transformer, before mean-pooling each chunk's token vectors.
  • ·Fixes: naïve chunking embeds each chunk alone → "it" / "the company" loses its referent.
  • ·Trick: attention saw the whole document, so every token vector is contextualized — pooling keeps it. No overlap-vs-context tradeoff.
  • ·Training-free: reuses any long-context embedder — just invert cut-then-embed (Günther et al., 2024).
  • ·Limit: the tradeoff vanishes only within the encoder's context window — a document longer than it must still be macro-split (the paper's "long late chunking" re-introduces a bounded overlap between macro-windows).
Late-Chunking frontier definition. arXiv:2409.04701 (Günther et al., Jina AI). Embed-then-chunk, training-free, fixes isolated-chunk context loss — the exact tension the sweep slide exposed (overlap buys recall but not context).
