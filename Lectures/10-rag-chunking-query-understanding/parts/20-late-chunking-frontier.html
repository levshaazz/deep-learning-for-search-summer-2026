Frontier · Late Chunking

embed the whole document, then chunk
Frontier idea · arXiv:2409.04701
Run the long-context encoder over the entire document first; cut into chunks after the transformer, before mean-pooling each chunk's token vectors.
  • ·The problem it fixes: naïve chunking embeds each chunk in isolation, so "it" or "the company" loses its referent — the chunk forgets the document it came from.
  • ·The trick: because attention has already seen the whole document, every token vector is contextualized by the full text; pooling those into a chunk keeps that context. No overlap-vs-context tradeoff.
  • ·Training-free: it reuses any long-context embedding model as-is — only the order of cut-then-embed is inverted (Günther et al., Jina AI, 2024).
Late-Chunking frontier definition. arXiv:2409.04701 (Günther et al., Jina AI). Embed-then-chunk, training-free, fixes isolated-chunk context loss — the exact tension the sweep slide exposed (overlap buys recall but not context).
