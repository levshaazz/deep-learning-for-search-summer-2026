Определение · text-to-metadataDefinition · text-to-metadata
Переведи запрос на естественном языке в структурированную форму, которую хранилище исполнит — фильтр по метаданным, SQL или граф — вместо (или наряду с) векторного поиска.Translate the natural-language query into a structured form the store can execute — a metadata filter, SQL, or graph query — instead of (or alongside) vector search.
  • ·Зачем: «статьи по поиску, после 2020» прячут жёсткое ограничение (год > 2020), которое эмбеддинги приближают плохо. Фильтр даёт его точно; вектор ранжирует внутри.Why: "papers on retrieval published after 2020" hides a hard constraint (year > 2020) embeddings approximate poorly. A filter enforces it exactly; vector search ranks within it.
  • ·Две формы: self-query извлекает фильтр по метаданным (рядом с векторным поиском); text-to-SQL компилирует вопрос в запрос над структурированным хранилищем.Two forms: self-query extracts a metadata filter (applied beside vector search); text-to-SQL compiles the question into a query over a structured store.
  • ·Здесь неструктурированный поиск встречает структурированный мир — LLM это компилятор из намерения в запрос.This is where unstructured retrieval meets the structured world — the LLM is the compiler from intent to query.
