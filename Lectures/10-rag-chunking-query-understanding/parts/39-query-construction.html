Query construction

natural language → a structured retrieval
Definition · text-to-metadata
Translate the natural-language query into a structured form the store can execute — a metadata filter, a SQL query, or a graph query — instead of (or alongside) a vector search.
  • ·Why: "papers on retrieval published after 2020" hides a hard constraint (year > 2020) that embeddings approximate poorly. A filter enforces it exactly; the vector search ranks within it.
  • ·Two forms: self-query extracts a metadata filter from the question (applied next to vector search); text-to-SQL compiles the question into an executable query over a structured store.
  • ·Construction is where unstructured retrieval meets the structured world — the LLM is the compiler from intent to query.
