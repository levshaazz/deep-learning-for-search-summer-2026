Словарный разрывThe vocabulary gap

почему нужный документ может стоять низкоwhy the right doc can rank low
ОпределениеDefinition
Запрос и его истинный ответ часто используют разные слова для одной идеи — поэтому ретривер, оценивающий по сходству слов/эмбеддингов, ставит нужный документ ниже худших совпадений.A query and its true answer often use different words for the same idea — so a retriever scoring by word/embedding similarity ranks the right document below worse matches.
  • ·Пример: «Как сердце качает кровь?» против документа о «сердечном цикле, желудочковой систоле» — та же тема, почти нет общих слов.Example: "How does the heart pump blood?" vs a doc on "the cardiac cycle, ventricular systole" — same topic, almost no shared vocabulary.
  • ·Отсылка (L3): Furnas и др. обнаружили, что два человека выбирают одно слово для понятия менее чем в 20% случаев. Эмбеддинги сужают разрыв, но не закрывают его.Callback (L3): Furnas et al. found two people pick the same word for a concept under 20% of the time. Embeddings narrow the gap; they don't close it.
  • ·Ход: не строй ретривер получше — дай ему запрос получше, ближе по словам к ответу. Это и есть трансформация запроса.The move: don't build a better retriever — give it a better query, closer in vocabulary to the answer. That is query translation.
vocabulary-gap definition. The query and answer use different words → true doc ranks low. Callback L3 (Furnas et al., <20% agreement). Motivates query translation (the next moves: multi-query, HyDE, fusion, decomposition).
