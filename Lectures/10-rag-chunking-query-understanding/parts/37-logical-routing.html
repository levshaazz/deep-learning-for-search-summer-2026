Logical routing

let the LLM pick the data source
Definition
Give the LLM a menu of data sources (or indices, or tools) and have it classify which one the query belongs to — a function call with a constrained set of choices.
  • ·Example: a code question routes to the docs index; a billing question routes to the SQL database; a general question routes to the web. One classifier, several back-ends.
  • ·How: structured output (an enum / function-calling schema) so the route is a valid choice, not free text — the model returns a label, the system dispatches on it.
  • ·Logical vs semantic: logical routing reasons over an explicit menu; semantic routing (next) picks by embedding similarity to each option. Use logical when the choices are nameable, semantic when they're fuzzy.
logical-routing definition. LLM classifies the query into one of a named menu of sources/indices/tools (structured output / function call). Contrast with semantic routing (similarity-based). No gated numbers.
