Логическая маршрутизацияLogical routing

пусть LLM выбирает источник данныхlet the LLM pick the data source
ОпределениеDefinition
Дай LLM меню источников (индексы, инструменты) и пусть она классифицирует, к какому относится запрос — вызов функции над ограниченным набором.Give the LLM a menu of sources (indices, tools) and have it classify which the query belongs to — a function call over a constrained set.
  • ·Пример: вопрос по коду → документация; биллинг → SQL-база; общий → веб. Один классификатор, несколько бэкендов.Example: a code question → docs; billing → the SQL database; general → the web. One classifier, several back-ends.
  • ·Как: структурированный вывод (enum / схема вызова функции): маршрут — валидная метка для диспетчеризации, а не свободный текст.How: structured output (an enum / function-calling schema): the route is a valid label to dispatch on, not free text.
  • ·против семантической: логическая рассуждает над явным меню; семантическая (далее) — по сходству эмбеддингов. Логическая, когда варианты именуемы.vs semantic: logical reasons over an explicit menu; semantic (next) goes by embedding similarity. Logical when choices are nameable.
logical-routing definition. LLM classifies the query into one of a named menu of sources/indices/tools (structured output / function call). Contrast with semantic routing (similarity-based). No gated numbers.
