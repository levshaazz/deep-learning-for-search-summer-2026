Quick check — which router?

logical vs semantic vs construction
A user asks: "Show me reviews of the X200 laptop with a rating above 4 stars." Which technique enforces the "above 4 stars" part exactly?
ASemantic routing — embed the query and send it to the closest prompt template.
BQuery construction (self-query) — extract a metadata filter rating > 4 applied alongside the vector search.
CMulti-query — paraphrase "above 4 stars" several ways and take the union.
Reveal explanation
B. A numeric threshold is a hard constraint that embeddings only approximate — paraphrasing or routing won't enforce it. Self-query extracts the structured filter rating > 4 and applies it exactly, then the vector search ranks within the matches. Routing would pick a prompt, not enforce the constraint; multi-query would widen recall, not filter.
Quiz: hard numeric constraint → query construction (self-query metadata filter), not routing or multi-query. Answer B. Drives home that construction enforces constraints embeddings only approximate.
