The routing & construction menu

what to vary, and how the LLM decides
technique what it picks how it decides when
logical routingthe data source / index / toolLLM classifies into a named menu (structured output)choices are nameable & distinct
semantic routingthe prompt templatecosine of the query to each template centroid → argmaxchoices are fuzzy / many
self-querya metadata filter beside vector searchLLM extracts structured fields from the questionhard constraints (date, author, tag)
text-to-SQLan executable query over a DBLLM compiles NL into SQLthe answer lives in a structured store

Routing answers "where should this query go?"; construction answers "what shape should this query take?". Together they turn a single flat pipe into a small system that adapts to the question — without a hand-written rule engine.
