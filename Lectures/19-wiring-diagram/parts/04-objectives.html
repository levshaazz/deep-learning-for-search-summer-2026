прочитать схему · прочитать с неё счёт read the circuit · read the bill off it
  • ✓ Читать схему как вычисление, а не как картинку — провод — ось, чаша — стягивание (ось умирает), треугольник — softmax поперёк оси, но не вместо неё. Read a circuit as a computation, not a picture — a wire is an axis, a cup is a contraction (an axis dies), a triangle is a softmax across an axis, not instead of it.
  • ✓ Переводить схему \(\leftrightarrow\) einsum \(\leftrightarrow\) код — индекс, который есть слева от стрелки и нет справа, стянут: это одна и та же истина в трёх алфавитах. Translate circuit \(\leftrightarrow\) einsum \(\leftrightarrow\) code — an index on the left of the arrow and missing on the right has been contracted: one truth in three alphabets.
  • ✓ Считать счёт по глифам — одно правило: matmul \((a\times b)\cdot(b\times c)\) стоит \(2abc\) flops. Отсюда весь блок: линейная часть \(24nd^2\), ядро внимания \(4n^2d\). Count the bill off the glyphs — one rule: an \((a\times b)\cdot(b\times c)\) matmul costs \(2abc\) flops. The whole block follows: linear part \(24nd^2\), attention core \(4n^2d\).
  • ✓ Назвать, где квадрат начинает решать — \(4n^2d = 24nd^2 \iff n = 6d\); для BERT-base (\(d = 768\)) это \(n = 4608\) токенов, а не «всегда» и не «никогда». Say where the quadratic starts to matter — \(4n^2d = 24nd^2 \iff n = 6d\); for BERT-base (\(d = 768\)) that is \(n = 4608\) tokens — neither "always" nor "never".
  • ✓ Ловить баг, который сохраняет форму — softmax по не той оси не уронит программу: формы сойдутся, тесты позеленеют, а лосс выйдет на плато. Схема показывает такое глазом. Catch the bug that preserves the shape — a softmax over the wrong axis crashes nothing: the shapes match, the tests pass, and the loss just plateaus. The circuit shows it at a glance.
Пять проверяемых результатов. (1) Читать схему как вычисление: провод = ось, чаша = стягивание (ось умирает), треугольник = softmax поперёк оси. (2) Переводить схема ↔ einsum ↔ код: индекс слева от стрелки и не справа — стянут; это определение, а не мнемоника. (3) Считать счёт: правило 2·a·b·c на matmul, отсюда линейная часть блока 24nd² (Wq,Wk,Wv,L_O даёт 8nd², FFN — 16nd²) и ядро внимания 4n²d (две чаши по 2n²d). (4) Перелом: 4n²d = 24nd² ⟺ n = 6d; при d = 768 это 4608 токенов — конкретное число вместо страха перед «квадратичностью». (5) Баг, сохраняющий форму: softmax по не той оси — формы совпадают, ошибок нет, лосс на плато; на схеме треугольник просто стоит поперёк не того провода. Все числа — из data/l19-cost.json.
