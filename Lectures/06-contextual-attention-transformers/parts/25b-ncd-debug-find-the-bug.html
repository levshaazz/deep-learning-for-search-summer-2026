Проверка форм ловит две поломки из трёх. Третью — ничто: вошло \(n\times n\), вышло \(n\times n\), стектрейса не будет никогда. The only evidence is the orientation of the triangle.

This is an EXERCISE, not a lecture — run it that way. Put the slide up and say nothing for a good half minute: three circuits, all of them wrong, find the bugs. Let the room look. Only then step. The tenth slide of the notation interlude promised that a failure would be a missing or a turned glyph rather than a mystery; this is where that promise gets paid, and it is why the notation was worth its ten minutes. Step zero, bug one, the easy kind: Q is three by four and K is three by four, so the cup tries to contract an axis of size four against an axis of size three. A cup joins EQUAL axes or it joins nothing — the wires do not meet and the circuit comes apart on the page. A type checker catches this; so does a glance. In the formula QK-transpose the transpose is one character and easy to lose. Step one is the whole reason we are here, so slow right down. Both panels are the same circuit: the same n by n score grid, the same two wires — the query axis down the left, the key axis across the top. Ask them what differs. Exactly one thing does: the softmax triangle. On the right it opens along the key axis, so each ROW is a distribution over keys — correct. On the left it has been turned a quarter turn and opens down the query axis, so each COLUMN sums to one instead. Now make them look at the shapes: n by n before, n by n after, in both panels. Identical. Every shape assertion in the stack passes. Nothing crashes. No stack trace ever appears. The model quietly learns nonsense and you spend a week bisecting learning rates. The formula does not record which axis was normalised; the einsum string does not either. The turned triangle is the only thing in the entire pipeline that can tell you — which is precisely why this notation draws it across the axis it normalises. Step two, bug three, and this is the one that needed multi-head: the block splits the model dimension across twelve heads, sixty-four apiece, and then never puts the axis back — so it emits h by n by sixty-four where the next block wants n by seven sixty-eight. Blocks compose end to end for exactly one reason: every sublayer preserves the n by m shape. The concat hexagon is not glue for convenience — it is the inverse of the split, twelve times sixty-four is seven sixty-eight, and the output projection follows. Land it: from here on we USE the notation and never explain it again. Homework three asks them to draw their own model this way and name the axis whose square is their memory bill.
