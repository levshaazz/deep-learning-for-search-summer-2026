Идея внимания: запрос, ключ, значениеThe attention idea: query, key, value

«кого слушать» и «что взять»“who to heed” and “what to take”
МетафораMetaphor
Запрос · Ключ · ЗначениеQuery · Key · Value\(Q,\ K,\ V\)

Каждый токен излучает запрос \(Q\) («что мне нужно?»), и предъявляет ключ \(K\) («что я предлагаю?») и значение \(V\) («что я отдам, если меня выберут»). Похожесть \(Q\) с каждым \(K\) задаёт вес; выход — взвешенная сумма \(V\).Each token emits a query \(Q\) (“what do I need?”), and presents a key \(K\) (“what do I offer?”) and a value \(V\) (“what I contribute if chosen”). The match of \(Q\) to each \(K\) sets a weight; the output is a weighted sum of \(V\).

Аналогия — поиск: запрос сравнивается с ключами документов; лучшие совпадения отдают свои значения. Это soft-retrieval внутри одного предложения.Search analogy: a query is matched against document keys; the best matches return their values. It is soft retrieval inside a single sentence.

The three roles, with the search analogy you already know. Every token produces three vectors. The query is what this token is looking for. The key is what each token advertises about itself. The value is what a token actually contributes if it is attended to. The attention weight between two tokens is the similarity of one's query to the other's key, so a token with a matching key gets a high weight. The output for a token is the weighted sum of all the values, using those weights. It is exactly soft retrieval, but inside one sentence: the query matches keys, and the matching values are blended in. The picture shows one token's query lighting up its most relevant neighbours.
