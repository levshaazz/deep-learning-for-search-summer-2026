Остаток и LayerNormResidual & LayerNorm\(\mathrm{LayerNorm}(x+\mathrm{Sublayer}(x))\)

Остаточная связь прибавляет вход подслоя к его выходу: \(x+\mathrm{Sublayer}(x)\) — градиент течёт «в обход», и глубокий стек обучается (He 2015). LayerNorm нормирует каждый токен по его признакам (среднее \(0\), дисперсия \(1\)), стабилизируя активации.The residual connection adds a sublayer’s input to its output: \(x+\mathrm{Sublayer}(x)\) — gradients get a shortcut, so a deep stack trains (He 2015). LayerNorm normalises each token across its features (mean \(0\), variance \(1\)), stabilising activations.

Каждый подслой блока (внимание и FFN) обёрнут одинаково: \(\mathrm{LayerNorm}\big(x+\mathrm{Sublayer}(x)\big)\). Без остатков стек из 12+ слоёв почти не обучается.Every sublayer in the block (attention and FFN) is wrapped the same way: \(\mathrm{LayerNorm}\big(x+\mathrm{Sublayer}(x)\big)\). Without residuals a 12+-layer stack barely trains.

Two tricks that make depth possible. First, the residual connection: instead of replacing the input, each sublayer adds its output to its input — x plus sublayer of x. This gives gradients a direct path around the sublayer, the same idea as ResNet from He and colleagues in 2015, and it is the single reason a twelve- or twenty-four-layer stack trains instead of vanishing. Second, layer normalisation: it rescales each token's feature vector to zero mean and unit variance, keeping activations in a stable range layer after layer. Every sublayer in the block — both the attention and the feed-forward network — is wrapped identically as LayerNorm of input plus sublayer of input. Remember these wrappers; they appear twice in the block.
