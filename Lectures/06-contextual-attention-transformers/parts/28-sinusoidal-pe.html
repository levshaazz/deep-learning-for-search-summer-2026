Каждое измерение — синусоида своей частоты: чётные индексы — \(\sin\), нечётные — \(\cos\). Низкие измерения колеблются быстро (локальный порядок), высокие — медленно (глобальная позиция). Вектор прибавляется к эмбеддингу токена: \(X' = X + \mathrm{PE}\).Each dimension is a sinusoid of its own frequency: even indices use \(\sin\), odd use \(\cos\). Low dimensions oscillate fast (local order), high dimensions slowly (global position). The vector is added to the token embedding: \(X' = X + \mathrm{PE}\).

The exact positional encoding from the original Transformer. For a token at position pos, dimension number two i gets the sine, and two i plus one gets the cosine, of pos divided by ten thousand to the power two i over d. The effect is that each embedding dimension is a sinusoid with its own wavelength: the lowest dimensions cycle quickly, encoding fine local order, while the highest cycle very slowly, encoding coarse absolute position. A beautiful property falls out — because sine and cosine of a shifted angle are linear combinations of the unshifted ones, the encoding lets the model express relative offsets as linear functions, so it can generalise to relative positions. This vector is simply added to each token's embedding before the first layer.

Кривая — измерение \(i=0\), самая быстрая синусоида: длина волны \(2\pi\!\cdot\!10000^{0}=2\pi\approx 6.28\) позиции. Высокое измерение медленнее в \(10000^{2i/d}\) раз: при \(i=3,d=8\) длина волны \(\approx 6283\) — почти плоско. Низкие измерения кодируют локальный порядок, высокие — глобальную позицию; вектор прибавляется к токену \(X' = X + \mathrm{PE}\).The curve is dimension \(i=0\), the fastest sinusoid: wavelength \(2\pi\!\cdot\!10000^{0}=2\pi\approx 6.28\) positions. A high dimension is \(10000^{2i/d}\) times slower: at \(i=3,d=8\) the wavelength is \(\approx 6283\) — nearly flat. Low dimensions encode local order, high ones global position; the vector is added to the token, \(X' = X + \mathrm{PE}\).

Make the frequency sweep tactile. The plotted curve is the lowest, fastest dimension, i equals zero, which is simply sine of the position because ten thousand to the zero is one. Drag the position slider and watch the marker ride the wave: this dimension completes a full cycle every two pi, about six positions, so neighbouring tokens get clearly different values — that is how the encoding carries fine local order. Now imagine the same plot for a high dimension, say i equals three with d equals eight: the divisor is ten thousand to the three-quarters, about a thousand, so the wavelength stretches to roughly six thousand positions and the curve would look almost flat over this window — that dimension barely moves, encoding only coarse global position. The mix of fast and slow dimensions gives every position a unique fingerprint, and the whole vector is just added to the token embedding before the first layer.
