«bank»: один вектор, два смысла“bank”: one vector, two meanings

полисемия · усреднённая точкаpolysemy · the averaged point

«river bank» и «bank account» делят один статический вектор из L5 — его координаты усредняют оба смысла. Контекста в нём нет.“river bank” and “bank account” share one static L5 vector — its coordinates average both senses. There is no context in it.

State the problem with the canonical example. In the static map of Lecture 5, the word bank has exactly one vector, fixed before we ever see a sentence. But river bank and bank account are different things. The single point is forced to sit somewhere between the two senses, averaging them, which is wrong for both. No amount of training a static embedding fixes this — the limitation is structural, one word, one vector. What is missing is context: the vector should depend on the sentence the word appears in. That is the whole motivation for contextual embeddings, and attention is how we build them.
