Что думают студентыWhat students think

«Self-attention сам понимает порядок слов».“Self-attention understands word order on its own.”

Нет. Перестановка входных строк \(X\) просто переставляет выходные строки — значения внимания те же. Слой видит множество токенов, а не последовательность. RNN несла порядок в самой рекуррентности; в Transformer его приходится добавить на вход как позиционный вектор.No. Permuting the input rows of \(X\) just permutes the output rows — the attention values are the same. The layer sees a set of tokens, not a sequence. An RNN carried order in its recurrence; a Transformer must add it to the input as a positional vector.

Урок.Lesson. Позиция не возникает сама собой — её добавляют явно: \(X' = X + \text{PE}\) до первого слоя.Position is not emergent, it is injected: \(X' = X + \text{PE}\) before the first layer.

Make the invariance explicit, because it surprises people. Attention computes, for each token, a weighted sum over all tokens; permute the rows of the input and the set of pairwise scores is unchanged, so the outputs simply permute along. Formally the layer is equivariant to permutation and carries no inherent notion of first, second, third. Recurrent networks got order for free because they processed tokens one at a time; a Transformer processes them all at once, in parallel, which is exactly why it is fast but also why it is order-blind. The remedy is to add a positional encoding to each input token before the stack — position is injected, not emergent.
