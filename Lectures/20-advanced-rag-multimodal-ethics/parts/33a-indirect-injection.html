Attack 1 — the security turn of the ethics act. Indirect prompt injection (Greshake et al. 2023, arXiv:2302.12173; OWASP LLM Top-10 #1): RAG's defining feature — bringing third-party text into the prompt — is exactly the attack channel. The model has no type system separating data from instructions, so a retrieved passage containing imperative text can be executed. Indirect because the attacker rides the retrieval channel: poison a page, wait for it to rank. Dangerous because assistants hold tools and user context. First-line mitigation is instruction isolation (marked data blocks, spotlighting); the defence stack slide completes it.
