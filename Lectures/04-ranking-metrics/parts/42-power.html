Power: how many queries do you need?

minimum detectable difference

The four knobs

  • ·Effect size — the true gap you want to catch (e.g. \(+0.01\) nDCG).
  • ·Variance — per-query spread (\(\mathrm{sd}=0.0676\) here).
  • ·\(\alpha\) — false-positive rate (usually \(0.05\)).
  • ·Power \(1-\beta\) — chance of catching a real effect (aim \(0.8\)).

The consequence

!
Small effects need many queries

To reliably detect a \(+0.01\) nDCG gain at this variance, you need hundreds of queries, not 15. Under-powered tests miss real wins (Type II).

\(n \approx \left(\dfrac{(z_\alpha + z_\beta)\,\mathrm{sd}}{\text{MDD}}\right)^2\). Halve the detectable difference → quadruple the queries.

Significance and power are two failure modes. Significance controls false positives — saying B won when it didn't. Power controls false negatives — missing a real win because the test was too small. The required query count grows with variance and shrinks with the effect you're willing to call meaningful; crucially, it scales with the inverse square of the minimum detectable difference, so chasing a tiny improvement costs a lot of queries. Fifteen queries can catch a 0.04 gap but would routinely miss a real 0.01 gap. Decide the smallest gain you care about before you size the test.
