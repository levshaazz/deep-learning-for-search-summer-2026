Вопрос аудиторииAudience question
Новый плотный ретривер возвращает релевантные документы, которые ни одна пулинговая система никогда не выдавала. При оценке простым \(\mathrm{P}@k\) на старых qrels, что произойдёт?A new dense retriever returns relevant docs that no pooled system ever surfaced. Scored with plain \(\mathrm{P}@k\) on the old qrels, what happens?
AОна несправедливо штрафуется — её неоценённые-но-релевантные попадания считаются нерелевантными.It is unfairly penalised — its unjudged-but-relevant hits count as non-relevant.
BНичего — пулинговые qrels всегда полны.Nothing — pooled qrels are always complete.
CОна получает искусственно высокий балл, потому что новые документы по умолчанию релевантны.It scores artificially high because new docs default to relevant.
Показать объяснениеReveal explanation
A. Пул был построен из топ-\(k\) старых систем; документ, который ни одна из них не выдала, неоценён, и конвенция «неоценённый = нерелевантный» помечает настоящие находки новой системы как промахи. Это предел переиспользуемости пулинговых коллекций — используйте bpref или condensed-метрики для честной оценки.A. The pool was built from the old systems' top-\(k\); a document none of them retrieved is unjudged, and the "unjudged = non-relevant" convention marks the new system's genuine finds as misses. This is the reusability limit of pooled collections — use bpref or condensed metrics to evaluate fairly.
Consolidates Part 2. The point: a test collection is only as reusable as its pool is complete relative to the system you're testing. If your new system retrieves in a genuinely different way, its best documents may be invisible to the qrels and you'll under-credit it. The defensive move is to know your pool depth and prefer robust measures when evaluating off-pool systems.
