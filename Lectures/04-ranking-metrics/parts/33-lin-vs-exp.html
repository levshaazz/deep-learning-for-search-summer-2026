Gains \([0,7,0,7,0,1,0,1]\), same discounts \(1/\log_2(i{+}1)\):

\(\mathrm{DCG} = 7{\cdot}0.6309 + 7{\cdot}0.4307 + 1{\cdot}0.3562 + 1{\cdot}0.3155 = 8.1029\)

\(\mathrm{IDCG} = 7{\cdot}1.0 + 7{\cdot}0.6309 + 1{\cdot}0.5 + 1{\cdot}0.4307 = 12.3472\)

\(\mathrm{nDCG} = 8.1029 / 12.3472 = 0.6563\)

Exponential gain inflates the grade-3 docs (\(3\to 7\)), so both \(\mathrm{DCG}\) and \(\mathrm{IDCG}\) grow — but the ratio barely moves (\(0.6622 \to 0.6563\)). The gain function changes the scale, rarely the verdict.

Two gain functions on the identical ranking. Linear keeps grades as 0,3,1; exponential maps them to 0,7,1, amplifying the strong hits. Both numerator (DCG) and denominator (IDCG) inflate, so the normalized score moves only slightly: 0.6622 to 0.6563. The lesson: report which gain you used because absolute numbers differ, but the relative ordering of systems is usually robust to the choice. Web search defaults to exponential precisely because it sharpens the reward for perfect results, which matters when grade-4 documents are rare and precious.
