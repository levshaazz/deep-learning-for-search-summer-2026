Функция выигрыша меняет масштаб, но редко — вердикт.Exponential gain inflates the grade-3 docs (\(3\to 7\)), so both \(\mathrm{DCG}\) and \(\mathrm{IDCG}\) grow — but the ratio barely moves (\(0.6622 \to 0.6563\)). The gain function changes the scale, rarely the verdict.

Two gain functions on the identical ranking. Linear keeps grades as 0,3,1; exponential maps them to 0,7,1, amplifying the strong hits. Both numerator (DCG) and denominator (IDCG) inflate, so the normalised score moves only slightly: 0.6622 to 0.6563. The lesson: report which gain you used because absolute numbers differ, but the relative ordering of systems is usually robust to the choice. Web search defaults to exponential precisely because it sharpens the reward for perfect results, which matters when grade-4 documents are rare and precious.
