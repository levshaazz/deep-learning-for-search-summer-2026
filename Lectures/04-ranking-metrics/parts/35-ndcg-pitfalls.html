Ничьи и пропущенные меткиTies & missing labels

Документы с равным баллом → порядок произволен; рандомизируйте или усредняйте. Неоценённый документ, принятый за выигрыш \(0\), занижает DCG (снова смещение из Части 2).Equal-score docs → order is arbitrary; randomise or average. An unjudged doc treated as gain \(0\) deflates DCG (the Part-2 bias again).

Две системы с разными отсечками, функциями выигрыша или полнотой разметки не сопоставимы — сначала зафиксируйте протокол.Two systems with different cutoffs, gain functions, or label completeness are not comparable — fix the protocol first.

nDCG is the right metric but it has sharp edges. Always state the cutoff — nDCG@10 is the web standard — and make sure IDCG is computed at the same k. When a query has very few relevant docs, IDCG is tiny and the score swings wildly, so per-query nDCG can be noisy. Ties in score make the order arbitrary, which can quietly change the number; average over random tie-breaks. And the unjudged-document bias from Part 2 returns: an unlabelled relevant doc scored as gain 0 understates your DCG. The meta-lesson: comparisons are only valid under an identical protocol.
