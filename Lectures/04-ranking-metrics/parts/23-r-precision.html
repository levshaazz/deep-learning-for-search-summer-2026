ОпределениеDefinition
R-precision\(\mathrm{P}@R\)

Точность на отсечке \(k=R\), где \(R\) — это число релевантных документов для данного запроса. При \(k=R\) точность и полнота совпадают.Precision at cutoff \(k=R\), where \(R\) is the number of relevant documents for that query. At \(k=R\), precision and recall coincide.

У нашего запроса \(R=4\), поэтому R-precision \(=\mathrm{P}@4\). Топ-4 содержит релевантные документы на позициях \(2,4\) → \(2/4 = 0{,}5\). Метрика авто-адаптируется: запрос со 100 релевантными документами оценивается при \(k=100\), а не при фиксированном 10.Our query has \(R=4\), so R-precision \(=\mathrm{P}@4\). Top-4 contains relevant docs at ranks \(2,4\) → \(2/4 = 0.5\). It auto-adapts: a query with 100 relevant docs is judged at \(k=100\), not a fixed 10.

A fixed cutoff like P@10 is unfair across queries: a query with three relevant docs can never exceed 0.3, while one with fifty is judged on a tiny window. R-precision fixes this by setting the cutoff to R, the number of relevant docs for that query. A neat property falls out: at k = R, precision equals recall, because the denominators k and R are the same. For our query R = 4, so it's P@4 = 0.5. It's a single, query-adaptive number that correlates strongly with MAP in practice.
