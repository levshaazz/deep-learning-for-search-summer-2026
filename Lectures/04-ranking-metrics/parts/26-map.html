Mean Average Precision (MAP)

precision, sampled at every hit · \(\approx\) area under PR
$$ \mathrm{AP} = \frac{1}{R}\sum_{k\,:\,\mathrm{rel}_k=1} \mathrm{Precision}@k, \qquad \mathrm{MAP} = \frac{1}{|Q|}\sum_{q\in Q}\mathrm{AP}(q) $$
\(R\)
Relevant total
for the query (here \(R=4\))
\(\mathrm{rel}_k=1\)
Hit ranks
sum \(\mathrm{Precision}@k\) only where a relevant doc lands
\(\mathrm{AP}\)
Average precision
\(\approx\) area under the PR curve; MAP averages it

AP looks at every rank where a relevant doc appears, so it rewards ranking relevant docs higher. GMAP uses the geometric mean — emphasising hard queries.

MAP is the workhorse of binary-relevance IR. Average Precision evaluates Precision@k at each rank where a relevant document actually sits, then averages those values over the number of relevant docs — which is, to a good approximation, the area under the precision-recall curve. Because precision is higher when hits are near the top, AP rewards surfacing relevant docs early. MAP is AP averaged over queries arithmetically; GMAP uses the geometric mean, which weights improvements on already-hard queries more heavily.
