Оценки релевантностиRelevance judgmentsqrels

Метка релевантности, привязанная к каждой паре (запрос, документ): является ли этот документ правильным ответом на данный запрос?A relevance label attached to each (query, document) pair: is this document a correct answer for this query?

Наши — бинарные и достаются бесплатно из корпуса: документ релевантен, если разделяет категорию 20 Newsgroups запроса. У текущего запроса интент space, поэтому релевантный означает категорию sci.space — та же конвенция «метки как истина», что мы использовали в Лекциях 1–3.Ours are binary and come for free from the corpus: a document is relevant if it shares the query's 20 Newsgroups category. The running query has intent space, so relevant means category sci.space — the same labels-as-truth convention we used in Lectures 1–3.

Qrels are the answer key. In a production system humans annotate them; here we reuse the 20 Newsgroups category labels as ground truth, so a document about space (category sci.space) is relevant to a space query and anything else is not. Binary relevance for the counting metrics; we add graded relevance later for nDCG. This continuity with L1–L3 is deliberate: we grade the very catalog we already built.
