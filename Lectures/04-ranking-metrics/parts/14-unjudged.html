Common misconception

the unjudged-document problem
What people assume

“If a document wasn't judged relevant, it's safe to count it as non-relevant.”

Only safe inside the pool. A new system can retrieve genuinely relevant docs that no pooled system found — these are unjudged, and "unjudged = non-relevant" unfairly penalises it. The deeper your retrieval differs from the pool, the worse the bias.

The fix. Use measures robust to incomplete judgments: bpref (counts only judged docs) or condensed-list metrics (delete unjudged docs, then score). They evaluate on judged evidence only, so an innovative ranker isn't punished for finding relevant docs the pool missed.

This is the subtle trap of reusing a test collection. Within the pool, "unjudged = non-relevant" is fine. But a brand-new system — say, a dense retriever that ranks documents nobody pooled — surfaces relevant docs that were never judged, and the standard convention scores them as wrong. The system gets punished precisely for being different and good. bpref and condensed-list metrics restrict scoring to judged documents, removing the penalty. Buckley and Voorhees introduced bpref for exactly this reason.
