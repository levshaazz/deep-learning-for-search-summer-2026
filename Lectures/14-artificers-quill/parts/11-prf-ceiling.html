  • ·Самоусиление — оно подаёт свой первый проход обратно себе; неверный top-k (ловушка) усиливается, а не исправляется.Self-reinforcing — it feeds its own first pass back to itself; a wrong top-k (the trap) gets amplified, not corrected.

Корпус не может дать слово, которое корпус ни разу не всплыл. Чтобы изобрести лексику, нужен источник, прочитавший больше, чем top-k. →The corpus cannot supply a word the corpus never surfaced. To invent vocabulary, we need a source that read more than the top-k. →

The classical quill's ceiling: RM3 can only add words already in its own top docs, has no world knowledge, and self-reinforces its first pass, so a wrong top-k gets amplified and it drifts to the trap. Free (0 LLM calls) but fragile — the lift holds on only 65% of seeds. This is exactly what motivates reaching for an LLM that has read the web.
