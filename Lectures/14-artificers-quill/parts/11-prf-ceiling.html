The ceiling · why PRF stalls
RM3 can only add words that already appear in its own top docs — it has no world knowledge to draw new vocabulary from.
  • ·Self-reinforcing — it feeds its own first pass back to itself; a wrong top-k (the trap) gets amplified, not corrected.
  • ×Drifts — on the toy it pulls in the trap’s {candy, citric, sweet} and still cannot say under-extraction.
  • ·Cost — 0 LLM calls, classical and free.
  • !Fragile — the lift holds on only 65% of seeds; on the rest the drift wins.

The corpus cannot supply a word the corpus never surfaced. To invent vocabulary, we need a source that read more than the top-k. →

The classical quill's ceiling: RM3 can only add words already in its own top docs, has no world knowledge, and self-reinforces its first pass, so a wrong top-k gets amplified and it drifts to the trap. Free (0 LLM calls) but fragile — the lift holds on only 65% of seeds. This is exactly what motivates reaching for an LLM that has read the web.
