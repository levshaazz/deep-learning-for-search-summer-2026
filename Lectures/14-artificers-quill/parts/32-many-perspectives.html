a single phrasing samples one corner of the answer
The move · multi-query

Prompt the LLM to paraphrase the query into N variants, each hitting a different facet or vocabulary — not N copies of the same words.

Every paraphrase hedges the Lexical Gremlin: where one phrasing misses the shelf, another lands on it.

  • ·“why is my espresso sour and watery?” → the raw complaint
  • ·“causes of under-extraction in espresso” → the archive's term
  • ·“fix weak sour shot — grind, dose, channeling” → the mechanism facet

Three aims at the same target — each covers a corner the others miss.

Multi-query = paraphrase one query into N variants across different facets/vocabulary, so each hedges the Lexical Gremlin's word-matching. The value is DIVERSITY of coverage, not repetition. This sets up the union (S33) and the fusion tool that recombines them (RRF, S34+).
