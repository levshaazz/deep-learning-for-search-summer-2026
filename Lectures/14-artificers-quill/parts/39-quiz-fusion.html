Audience question

Quick check · diagnose the flat recall
You added 5 paraphrases and fused with RRF — but recall didn't move. What is the most likely cause?
A RRF's \(k=60\) is too large — lower it to make top hits count
B The paraphrases were redundant — same facet, so they retrieved the same passages
C Five is too few — add twenty more of the same kind
Reveal explanation
B. Recall rises only when a paraphrase reaches a passage the others miss. Five near-identical rewrites cover one facet and re-fetch the same hits — diversity, not count, drives coverage. C makes it worse (more cost, no new hits); A rescores the same set and cannot add a missing passage.
Answer B: flat recall after 5 paraphrases means they were redundant — same facet, same retrieved passages. Diversity matters more than count. Distractor C adds cost without coverage; A only rescores the existing set, so it can never surface a passage no paraphrase reached.
