Вопрос аудиторииAudience question

Быстрая проверка · диагностируй плоскую полнотуQuick check · diagnose the flat recall
Вы добавили 5 парафразов и слили через RRF — но полнота не сдвинулась. Какова наиболее вероятная причина?You added 5 paraphrases and fused with RRF — but recall didn't move. What is the most likely cause?
A \(k=60\) у RRF слишком велик — понизь его, чтобы топовые попадания весили большеRRF's \(k=60\) is too large — lower it to make top hits count
B Парафразы были избыточны — та же грань, поэтому они достали те же пассажиThe paraphrases were redundant — same facet, so they retrieved the same passages
C Пять — слишком мало, добавь ещё двадцать того же родаFive is too few — add twenty more of the same kind
Показать объяснениеReveal explanation
B. Полнота растёт лишь тогда, когда парафраз достаёт пассаж, который упускают другие. Пять почти одинаковых переписываний покрывают одну грань и заново тянут те же попадания — покрытие движет разнообразие, а не количество. C делает хуже (больше стоимость, ноль новых попаданий); A переоценивает тот же набор и не может добавить недостающий пассаж.B. Recall rises only when a paraphrase reaches a passage the others miss. Five near-identical rewrites cover one facet and re-fetch the same hits — diversity, not count, drives coverage. C makes it worse (more cost, no new hits); A rescores the same set and cannot add a missing passage.
Answer B: flat recall after 5 paraphrases means they were redundant — same facet, same retrieved passages. Diversity matters more than count. Distractor C adds cost without coverage; A only rescores the existing set, so it can never surface a passage no paraphrase reached.
