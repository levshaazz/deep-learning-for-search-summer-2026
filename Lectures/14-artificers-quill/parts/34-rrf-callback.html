In L3 you met Reciprocal Rank Fusion to merge BM25 and dense lists into one — two retrievers, one ranking.

Today the lists come from one retriever over many paraphrases. Same rule, different source of the lists.

RRF fuses lists that differ by…where
retriever — BM25 vs denseL3 hybrid
query — N paraphrases, one retrieverL14 multi-query

The tool is rank-based, so it does not care why the lists differ.

Explicit L3 callback: RRF was introduced there to fuse BM25 + dense (differing retrievers). The identical rule now fuses N paraphrase lists from one retriever (differing queries). Because RRF works on RANKS, not scores, it is indifferent to the source of the lists — the same tool, a new job.
