The union lifts recall — but loses the ranking

coverage is easy; a single ordered list is the hard part
  • 1Retrieve each paraphrase separately. Each returns its own ranked list of hits.
  • 2Take the union. A passage missed by one phrasing is caught by another — coverage (recall) goes up.
  • 3Now what order? A naive union throws away every per-query rank — you have a bag of hits, not a ranking.

The gap: concatenating N lists recovers recall but destroys the one thing the user reads — a single, sensible order. We need a fusion rule that merges ranks, not one that discards them.

Retrieve each paraphrase, union the hits: recall climbs because different phrasings catch different passages. But a naive union has no coherent ordering — every per-query rank is lost. That missing merge rule is exactly the job RRF does next.
