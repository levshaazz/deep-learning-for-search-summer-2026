  • 4Reward. Оцени ответ — \(R = 1\), если верный.Reward. Score the answer — \(R = 1\) if correct.

The RRR loop: rewrite → retrieve → read → reward → policy-gradient update, with the reward flowing back only to the small rewriter while retriever and reader stay frozen. Contrast: the prompted LLM is a fixed, generic spell; the trained rewriter closes the loop and adapts to this specific pipeline.
