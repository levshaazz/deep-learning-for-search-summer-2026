сгенерировать → эмбеддить → усреднить → косинус-поискgenerate → embed → average → cosine-search
Определение · эмбеддинг HyDEDefinition · the HyDE embedding
$$ e = \frac{1}{k}\sum_{i=1}^{k} f(d_i) \quad\big(\text{optionally } +\, f(q)\big) $$

where e = query embedding for retrieval, k = number of drafts, di = i-th hypothetical doc, f = encoder, f(q) = optional raw-query anchor.

  • 1Сгенерировать \(k\) гипотетических документов \(d_i\) из LLM по \(q\).Generate \(k\) hypothetical docs \(d_i\) from an LLM given \(q\).
  • 2Эмбеддить каждый энкодером без учителя \(f\) (Contriever).Embed each with an unsupervised encoder \(f\) (Contriever).
  • 3Искать по \(\cos(e,\,\text{corpus})\).Retrieve by \(\cos(e,\,\text{corpus})\).

HyDE formally: e = (1/k) Σ f(dᵢ), optionally + f(q); generate k drafts from an instruction-tuned LLM, embed each with the unsupervised Contriever, retrieve by cos(e, corpus). Precision on the label: zero-shot means no relevance labels, but it still needs an instruction-tuned generator plus an unsupervised encoder — never call the whole pipeline "unsupervised."
