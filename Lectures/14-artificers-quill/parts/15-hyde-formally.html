HyDE, formally — average k drafts, then retrieve

generate → embed → average → cosine-search
Definition · the HyDE embedding
$$ e = \frac{1}{k}\sum_{i=1}^{k} f(d_i) \quad\big(\text{optionally } +\, f(q)\big) $$
  • 1Generate \(k\) hypothetical docs \(d_i\) from an LLM given \(q\).
  • 2Embed each with an unsupervised encoder \(f\) (Contriever).
  • 3Retrieve by \(\cos(e,\,\text{corpus})\).
Read the label carefully
Zero-shot — no relevance labels. But not “unsupervised.”
  • ✓No query–doc relevance labels are used.
  • ×It needs an instruction-tuned generator to draft \(d_i\)…
  • ×…plus an unsupervised encoder for \(f\). So: zero-shot ≠ unsupervised.
HyDE formally: e = (1/k) Σ f(dᵢ), optionally + f(q); generate k drafts from an instruction-tuned LLM, embed each with the unsupervised Contriever, retrieve by cos(e, corpus). Precision on the label: zero-shot means no relevance labels, but it still needs an instruction-tuned generator plus an unsupervised encoder — never call the whole pipeline "unsupervised."
