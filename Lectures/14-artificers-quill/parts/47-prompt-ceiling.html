The ceiling · frozen weights
HyDE, step-back, decomposition — all frozen: the same prompt writes the same rewrite, whether it helped or not.
  • ·The rewriter is generic — it was never told what this retriever’s index actually rewards.
  • ·No feedback loop: a rewrite that hurt the answer leaves the quill unchanged.

The question that opens the act:

“Can the quill learn from whether its rewrite actually led to a good answer?”

Every move so far was enchantment — a fixed spell. Next: apprenticeship — a rewriter that gets better at your pipeline by watching the downstream reward.

The prompt ceiling: a prompted LLM rewriter is frozen and generic — it never learns what this retriever's index rewards, and a rewrite that hurt the answer leaves it unchanged. Frame the pivot: enchantment (fixed spell) → apprenticeship (a rewriter trained on downstream reward). This motivates RRR.
