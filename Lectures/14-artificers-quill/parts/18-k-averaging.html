Averaging k drafts cancels noise — not bias

why generate more than one · and what averaging cannot fix
The averaging argument
$$ e = \frac{1}{k}\sum_{i=1}^{k} f(d_i) \;\big(+\, f(q)\big) $$

where e = the retrieval embedding, k = number of drafts averaged, di = the i-th draft, f = the encoder, f(q) = the optional raw-query anchor.

  • ✓Independent noise cancels. One draft phrases things oddly; average \(k\) and that idiosyncrasy washes out.
  • ×Systematic drift does NOT cancel. If every draft leans the same wrong way, averaging only reinforces it — boundary #1, next.
  • ·The optional \(+f(q)\) anchor keeps a thread back to the real question, so a fanciful draft can’t drag \(e\) too far.

Averaging is a variance cure, not a bias cure — it smooths independent wobble, never a shared lean.

k-averaging: e = (1/k) Σ f(dᵢ) (+ f(q)). Averaging cancels each draft's INDEPENDENT noise (odd phrasing washes out) but NOT systematic topical drift — if every draft leans the same wrong way, the mean reinforces it (boundary #1, next). The optional f(q) anchor tethers e to the real question so a fanciful draft can't pull too far.
