Prompted expansion — and its doc-side mirror

expand the query at query time · expand the doc at index time
Query side · Jagerman 2023
Query-Expansion-by-Prompting — prompt the LLM, then add terms to \(q\).
  • ·Q2D — ask for a document (the HyDE-style prompt).
  • ·Chain-of-thought — reason, then harvest the terms.
  • ·Few-shot — guide with examples. All at query time.
Doc side · the mirror (Nogueira 2019)
Document expansion — Doc2Query — predict the queries a doc answers.
  • ·Append predicted queries to each doc — done once, at index time.
  • ✓Zero query-time latency; the vocabulary bridge is baked into the index.

Same vocabulary bridge, two ends: grow the query (query time) or grow the document (index time).

Two faces of prompted expansion. Query side (Jagerman 2023): prompt-variant expansion — Q2D (HyDE-style), chain-of-thought, few-shot — all growing q at query time. Doc side mirror (Doc2Query, Nogueira 2019): predict the queries a doc answers and append them at INDEX time, so there's zero query-time latency. Same vocabulary bridge, built from opposite ends.
