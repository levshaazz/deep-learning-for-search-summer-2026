enc = tok(text, return_offsets_mapping=True,
          return_tensors="pt")
H = model(input_ids=enc.input_ids).last_hidden_state[0]

offs = enc.offset_mapping[0].tolist()      # (start, end) per token
real = lambda s, e: e > s                  # <- (0,0) = [CLS]/[SEP], skip them
def span(a, b):                            # chars -> token span
    i = next(k for k, (s, e) in enumerate(offs) if real(s, e) and e > a)
    j = max(k for k, (s, e) in enumerate(offs) if real(s, e) and s < b)
    return i, j

vecs = []
for n, (a, b) in enumerate(char_spans):    # from YOUR chunker
    i, j = span(a, b)
    if n == 0:            i = 0            # <- [CLS] + task prefix: chunk 0
    if n == len(char_spans) - 1: j = len(offs) - 1   # <- [SEP]: last chunk
    v = H[i:j + 1].mean(dim=0)             # <- pool AFTER attention
    vecs.append(F.normalize(v, dim=-1))    # <- L2 AFTER the mean
Три места, где ошибаются Three places people get it wrong
  • 1L2-нормировка — после усреднения, не до. Нормируешь токены до — получаешь среднее направлений, а не центр масс.L2-normalise after the mean, not before. Normalise the tokens first and you get a mean of directions, not a centre of mass.
  • 2Служебные токены и ловушка (0, 0). HF-токенизаторы дают [CLS] и [SEP] спан (0, 0) — без фильтра e > s условие s < b у хвостового [SEP] истинно всегда, и каждый чанк дотягивается до конца документа. Отфильтруй их, а потом верни руками: по §4.1 [CLS] и инструкционный префикс идут в пулинг первого чанка, [SEP] — последнего.Special tokens and the (0, 0) trap. HF tokenizers give [CLS] and [SEP] the span (0, 0) — without the e > s guard the test s < b is true for the trailing [SEP] every time, and every chunk silently pools to the end of the document. Filter them out, then put them back by hand: per §4.1 [CLS] and the instruction prefix go into the first chunk’s pooling, [SEP] into the last.
  • 3Один forward-pass на документ, а не на чанк. Если ты вызываешь модель в цикле по чанкам — ты снова написал наивный метод.One forward pass per document, not per chunk. Call the model inside the chunk loop and you have re-implemented the naive method.

У jina-embeddings-v3 и nomic-embed-text-v1 есть ещё префикс задачи (query/document) — он тоже токены, и он тоже попадает в первый чанк.Both jina-embeddings-v3 and nomic-embed-text-v1 also carry a task prefix (query/document) — those are tokens too, and they land in the first chunk.
