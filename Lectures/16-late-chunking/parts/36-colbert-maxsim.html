Каждый токен запроса берёт свой лучший токен документа, и совпадения суммируются:

Each query token takes its best-matching document token, then the matches are summed:

$$ S(q,d)=\sum_{i\in q}\max_{j\in d} E_{q_i}^{\top} E_{d_j} $$

Каждый токен запроса сканирует все токены документа → тяжело на запросе, огромный индекс (вектор на токен). Богатая точность — по цене каждого запроса. Every query token scans all document tokens → heavy at query time, huge index (a vector per token). Rich precision — paid per query.

Держите это в уме: у late chunking счёт зеркальный — один раз при индексации. Hold that thought: late chunking's bill is the mirror image — once, at index time.
