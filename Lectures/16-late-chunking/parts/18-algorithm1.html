Алгоритм 1 — от документа к чанк-векторам Algorithm 1 — from document to chunk vectors

Günther et al. 2024 · Algorithm 1
  • 1Токенизировать весь документ → одна длинная последовательность токенов.Tokenize the whole document → one long token sequence.
  • 2Прогнать трансформер один раз по всей последовательности → контекстные эмбеддинги токенов \(\vartheta\).Run the transformer once over the full sequence → contextual token embeddings \(\vartheta\).
  • 3Перевести символьные границы чанков в токенные подсказки — спаны \([\mathrm{start}_i,\mathrm{end}_i]\).Translate character-level chunk boundaries into token cues — spans \([\mathrm{start}_i,\mathrm{end}_i]\).
  • 4Усреднить каждый сегмент → эмбеддинг чанка \(e_i\).Mean-pool each segment → chunk embedding \(e_i\).
Единственное отличие The only difference

От обычного эмбеддинга документа алгоритм отличается ровно одной строкой: усреднять по сегментам, а не по всей последовательности.The algorithm differs from a plain document embedding by exactly one line: pool per segment, not over the whole sequence.

Веса модели не трогаем — приём без обучения.No weights change — the method is training-free.

Алгоритм 1 целиком: токенизировать документ → один проход трансформера по всей последовательности → перевести символьные границы чанков в токенные спаны → усреднить каждый спан. Единственное изменение против обычного эмбеддинга — усреднение по сегменту. Без дообучения.
