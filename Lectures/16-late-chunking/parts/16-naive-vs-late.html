Два конвейера — различает лишь порядок Two pipelines — only the order differs

chunk-then-embed vs embed-then-chunk
Наивно · сначала режем Naive · cut first
chunk \(\;\rightarrow\;\) embed
  • ·Разрезать документ на чанки.Split the document into chunks.
  • ·Закодировать каждый чанк отдельно — внимание живёт только внутри чанка.Embed each chunk on its own — attention stays inside the chunk.
  • ×Один вектор на чанк. Контекст соседей потерян.One vector per chunk. Neighbouring context is lost.
Поздно · сначала внимание Late · attend first
embed \(\;\rightarrow\;\) chunk
  • ·Закодировать весь документ разом — внимание по всем токенам.Embed the whole document at once — attention over all tokens.
  • ·Те же границы — но резать уже контекстные векторы токенов.Same boundaries — but now cut the already-contextual token vectors.
  • ✓Усреднить внутри чанка → один вектор на чанк.Mean-pool within each chunk → one vector per chunk.

Одна и та же модель, те же границы, столько же векторов на выходе — различается лишь порядок операций {резать, внимание}.Same model, same boundaries, same number of output vectors — only the order of {cut, attend} differs.

Ключ слайда: поздний конвейер — это наивный с переставленными шагами. Наивный режет ДО внимания (каждый чанк варится в собственном соку), поздний режет ПОСЛЕ (векторы токенов уже впитали весь документ). Выход одинаков по форме — один вектор на чанк.
