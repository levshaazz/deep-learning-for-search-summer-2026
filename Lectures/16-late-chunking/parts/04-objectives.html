  • ✓ Назвать разрыв кореференции — почему «нарезать-потом-кодировать» рвёт дальний контекст, и чанк, чей субъект — местоимение или «the city», теряет свой референт. Name the coreference gap — why chunk-then-embed severs long-distance context, so a chunk whose subject is a pronoun or “the city” loses its referent.
  • ✓ Записать идею позднего разбиения и её формулу — закодировать весь документ один раз, затем усреднить токены внутри каждой границы: \(e_i = \tfrac{1}{\text{end}-\text{start}+1}\sum_{j=\text{start}}^{\text{end}} \vartheta_j\). State the late-chunking idea and its formula — embed the whole document once, then mean-pool the tokens inside each boundary: \(e_i = \tfrac{1}{\text{end}-\text{start}+1}\sum_{j=\text{start}}^{\text{end}} \vartheta_j\).
  • ✓ Объяснить, почему это работает — внимание по всему документу разрешает «Its»/«the city» → Berlin в токенные векторы до пулинга, поэтому каждый вектор чанка контекстно-обусловлен, а не i.i.d. Explain why it works — full-document attention resolves “Its”/“the city” → Berlin into the token vectors before pooling, so each chunk vector is context-conditional, not i.i.d.
  • ✓ Прочитать доказательства и различить два «поздних» — BeIR nDCG@10 растёт на \(\approx 1.5\text{–}1.9\) пункта бесплатно; late-INTERACTION (ColBERT) платит на запросе, late-CHUNKING — один раз на индексе. Read the evidence and tell the two lates apart — BeIR nDCG@10 lifts \(\approx 1.5\text{–}1.9\) points for free; late-INTERACTION (ColBERT) pays at query time, late-CHUNKING pays once at index time.
  • ✓ Назвать границы применимости — когда оно ломается (Needle/Passkey размывает «иголку»), какая модель нужна (длинный контекст + mean-pool) и почему цена растёт только на индексе, а не на запросе. Name the boundaries — when it fails (Needle/Passkey dilutes the needle), what model it needs (long-context + mean-pool) and why the cost rises only at index time, never at query time.
