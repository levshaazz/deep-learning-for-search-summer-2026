Перекрытие нужно, чтобы токен увидел контекст, а не чтобы попасть в индекс дважды. Строка 14 Алгоритма 2 выбрасывает эмбеддинги перекрытия — без неё ты положишь один токен в два чанка. Налог: ω за шов.The overlap exists so a token can see its context, not so it can enter the index twice. Line 14 of Algorithm 2 discards the overlap embeddings — skip it and you file one token in two chunks. The tax: ω per seam.

long-late-window widget (W3). Draws a 20 000-token document to scale against the 8192-token window from data/l16-chunk.json → longLate, then walks three strategies: truncate (the answer-chunk is never indexed), cut naively (the seam severs the dependency again), long late with ω = 512 (stride 7 680, starts 0 / 7 680 / 15 360, the arc holds). The last step is the one the slides used to omit entirely: line 14 DISCARDS the overlap embeddings, so 21 024 tokens are encoded but every token is indexed exactly once, at a cost of ω per seam. l_max and ω are OUR example values — the paper publishes none and the repository ships two different defaults.
