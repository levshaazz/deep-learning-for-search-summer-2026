Соберём attention-слой по шагам. Жмите →.Let's assemble the attention layer step by step. Press →.

ВходыInputs
$$X \in \mathbb{R}^{T \times d}$$

Сырой вход (картинка/текст) → T токенов, каждый — вектор размерности d.Raw input (image/text) → T tokens, each a vector of dimension d.

ПроекцииProjections
$$Q=XW_Q,\ \ K=XW_K,\ \ V=XW_V$$

Три обучаемые матрицы дают запросы, ключи и значения.Three learned matrices give queries, keys and values.

Скоры вниманияAttention scores
$$E_{ij}=\dfrac{Q_i\cdot K_j}{\sqrt{d_k}}$$

Каждая ячейка \(E_{ij}\) — похожесть запроса \(i\) с ключом \(j\) (scaled dot-product). Матрица \(T\times T\).Each cell \(E_{ij}\) — similarity of query \(i\) with key \(j\) (scaled dot-product). A \(T\times T\) matrix.

Веса вниманияAttention weights
$$A_{ij}=\dfrac{e^{E_{ij}}}{\sum_{k} e^{E_{ik}}}$$

Softmax по строкам: каждая строка \(E\) → распределение внимания, \(\sum_j A_{ij}=1\) (подсвечена строка 1).Softmax over rows: each row of \(E\) → an attention distribution, \(\sum_j A_{ij}=1\) (row 1 highlighted).

ВыходOutput
$$Y_i=\sum_j A_{ij}\,V_j$$

Каждый выход \(Y_i\) — взвешенная сумма значений \(V_j\) по весам строки \(A_{i\cdot}\).Each output \(Y_i\) — a weighted sum of values \(V_j\) using row \(A_{i\cdot}\).
