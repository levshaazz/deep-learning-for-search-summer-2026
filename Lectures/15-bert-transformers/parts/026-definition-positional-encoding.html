Зачем нужна позиция Why we need position

Definition
Определение Definition
Positional encoding Positional encoding positional encoding · PE

Self-attention перестановочно-инвариантно: переставьте токены — выходы лишь переставятся так же, порядок теряется. Attention сам по себе не знает, какой токен первый, а какой последний.

Self-attention is permutation-invariant: permute the tokens and the outputs just permute the same way — order is lost. Attention by itself does not know which token is first or last.

Решение — добавить к эмбеддингам сигнал о позиции: \(\tilde{x}_t = x_t + PE_t\). В оригинальном Transformer \(PE\) — синусоидальное (фиксированное); в BERT — обучаемое. Fix: add a position signal to the embeddings: \(\tilde{x}_t = x_t + PE_t\). In the original Transformer \(PE\) is sinusoidal (fixed); in BERT it is learned.

Мотивация PE: self-attention перестановочно-инвариантно, поэтому без позиционного сигнала «кот укусил собаку» = «собаку укусил кот». Добавляем PE_t к эмбеддингу. Vaswani — синусоидальное, BERT — обучаемое (раскроем на слайде 29).
