KV-cache — ускорение генерации KV-cache — faster generation

Speed ↔ memory
Определение Definition
KV-cache KV-cache key/value cache

На генерации \(K\) и \(V\) прошлых позиций не меняются между шагами — кэшируем их. На каждом новом шаге считаем \(Q,K,V\) только для одного нового токена.

During generation, \(K\) and \(V\) of past positions don't change between steps — we cache them. Each new step computes \(Q,K,V\) for just one new token.

Без кэша — пересчёт всего префикса, \(\approx O(n^2 d)\) на токен; с кэшем — \(O(n d)\). Цена: память на хранение \(K,V\). Ускоряет инференс, не обучение. Without cache — recompute the whole prefix, \(\approx O(n^2 d)\) per token; with cache — \(O(n d)\). Cost: memory to store \(K,V\). Speeds up inference, not training.

Кэшируем именно K,V прошлых позиций (Q нового токена считается каждый раз). Trade-off: экономим вычисления, тратим память. Только инференс — на обучении (teacher forcing) весь префикс и так считается за один проход.
