За границей поиска — контекст для общей культуры. Мост к современным LLM: base LM → SFT → RLHF / DPO → chat-модель. Выравнивание поведения, а не знаний. Поиску это не нужно напрямую — но LLM-судьи (L11) и генераторы RAG (L10) сделаны именно так. Beyond the border of search — context for general culture. The bridge to modern LLMs: base LM → SFT → RLHF / DPO → chat model. Aligning behavior, not knowledge. Search does not need this directly — but the LLM judges (L11) and RAG generators (L10) are built exactly this way.

Явный дивайдер-граница: отсюда и до практики — контекст для общей культуры, за пределами собственно поиска (не вырезаем: LLM-судьи из L11 и генераторы RAG из L10 стоят на этих механизмах). Раздел про выравнивание. Главное: RLHF = 3 стадии (SFT → Reward Model → RL/PPO с KL-штрафом); промптинг и in-context ≠ RLHF; DPO без RM/RL; RLHF не добавляет знаний.
