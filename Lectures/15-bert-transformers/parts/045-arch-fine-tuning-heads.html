Классификация: вектор \([CLS]\) → линейный слой → softmax по классам (SST-2, MNLI…). QA (SQuAD): две span-головы предсказывают позиции начала и конца ответа над токенами контекста. База обычно дообучается целиком вместе с головой. Classification: the \([CLS]\) vector → linear layer → softmax over classes (SST-2, MNLI…). QA (SQuAD): two span heads predict the start and end positions of the answer over the context tokens. The base is usually fine-tuned end-to-end with the head.

Главный приём: поверх замороженного или (чаще) дообучаемого BERT добавляется минимальная голова. \([CLS]\)-голова — один линейный слой для классификации; span-головы для SQuAD — два линейных классификатора по позициям (start/end). Метрики SQuAD — Exact Match и F1; их детально на слайде 46.
