Query \(Q\) — что токен ищет; Key \(K\) — чем токен себя описывает; Value \(V\) — что токен несёт. Все три — линейные проекции входа \(X\):

Query \(Q\) — what a token looks for; Key \(K\) — how a token describes itself; Value \(V\) — what a token carries. All three are linear projections of the input \(X\):

$$Q = X W_Q,\quad K = X W_K,\quad V = X W_V$$

где \(W_Q, W_K, W_V\) — обучаемые матрицы. Сходство \(Q_i\) с \(K_j\) задаёт, сколько токен \(i\) берёт из \(V_j\). where \(W_Q, W_K, W_V\) are learned matrices. Similarity of \(Q_i\) with \(K_j\) sets how much token \(i\) takes from \(V_j\).

Три проекции дают токенам асимметричные роли. Без них attention был бы симметричен. Этот трёхролевой взгляд — фундамент всего раздела.
