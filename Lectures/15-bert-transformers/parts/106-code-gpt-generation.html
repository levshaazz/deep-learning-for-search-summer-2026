from transformers import AutoTokenizer, AutoModelForCausalLM

name = "gpt2"
tokenizer = AutoTokenizer.from_pretrained(name)             # byte-level BPE
model = AutoModelForCausalLM.from_pretrained(name)          # decoder-only, causal mask

prompt = "In a distant galaxy,"
inputs = tokenizer(prompt, return_tensors="pt")

out = model.generate(
    **inputs,
    max_new_tokens=60,
    do_sample=True,        # stochastic decoding (off -> greedy/beam)
    temperature=0.8,       # T<1 sharper, T>1 softer
    top_k=50,              # keep 50 most likely tokens
    top_p=0.95,            # nucleus: smallest set with mass >= 0.95
    num_beams=1,           # >1 -> beam search (deterministic)
)
print(tokenizer.decode(out[0], skip_special_tokens=True))

Декодер-only с causal-маской; токенизация — byte-level BPE (не WordPiece). KV-cache включён по умолчанию; для длинного контекста — attn_implementation="flash_attention_2". Decoder-only with a causal mask; tokenization is byte-level BPE (not WordPiece). KV-cache is on by default; for long context use attn_implementation="flash_attention_2".

Code GPT: AutoModelForCausalLM + model.generate(do_sample, temperature, top_k, top_p, num_beams, max_new_tokens). BPE-токенизация, causal-маска, KV-cache по умолчанию, FlashAttention через attn_implementation.
