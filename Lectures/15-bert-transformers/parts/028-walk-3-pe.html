Разбор · \(d=4\) Worked example · \(d=4\)

Возьмём \(d=4\), измерения \((2i,2i{+}1)\) с \(i=0,1\). Посчитаем \(PE\) для позиций \(pos=0\) и \(pos=1\). Take \(d=4\), dimensions \((2i,2i{+}1)\) with \(i=0,1\). Compute \(PE\) for positions \(pos=0\) and \(pos=1\).

01
Частоты по измерениям Per-dimension frequencies
При \(i=0\): \(10000^{0}=1\) → частота \(1\). При \(i=1\): \(10000^{2/4}=100\) → частота \(1/100=0.01\). For \(i=0\): \(10000^{0}=1\) → frequency \(1\). For \(i=1\): \(10000^{2/4}=100\) → frequency \(1/100=0.01\).
\(1,\ 0.01\)
02
Позиция \(pos=0\) Position \(pos=0\)
\(\sin 0 = 0,\ \cos 0 = 1\) для обеих частот → вектор \((0,\,1,\,0,\,1)\). Нулевая позиция всегда такая. \(\sin 0 = 0,\ \cos 0 = 1\) for both frequencies → vector \((0,\,1,\,0,\,1)\). Position zero is always this.
\((0,1,0,1)\)
→
Позиция \(pos=1\) Position \(pos=1\)
\(\sin 1 = 0.841,\ \cos 1 = 0.540\) (частота 1); \(\sin 0.01 = 0.010,\ \cos 0.01 = 1.000\) (частота 0.01) → \((0.841,\,0.540,\,0.010,\,1.000)\). \(\sin 1 = 0.841,\ \cos 1 = 0.540\) (freq 1); \(\sin 0.01 = 0.010,\ \cos 0.01 = 1.000\) (freq 0.01) → \((0.841,\,0.540,\,0.010,\,1.000)\).
\((0.841,0.540,0.010,1.000)\)

Пример 3 — конкретные значения PE при d=4. pos0 = (0,1,0,1); pos1 = (0.841,0.540,0.010,1.000). Обратите внимание: высокочастотное измерение (i=0) быстро меняется между позициями, низкочастотное (i=1) — почти не меняется (0→0.010), что и кодирует позицию на разных масштабах.
