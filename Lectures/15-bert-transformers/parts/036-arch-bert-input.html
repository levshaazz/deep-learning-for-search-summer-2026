Для каждой позиции: вход = token + segment + position. Спецтокены: \([CLS]\) в начале (агрегат для классификации), \([SEP]\) — разделитель сегментов. Позиционные эмбеддинги — обучаемые (в отличие от синусоидальных у Vaswani 2017). Per position: input = token + segment + position. Special tokens: \([CLS]\) at the start (classification aggregate), \([SEP]\) the segment separator. Position embeddings are learned (unlike Vaswani 2017's sinusoidal ones).

Три эмбеддинга складываются поэлементно в один вектор \(x_i\in\mathbb{R}^d\) на каждую позицию. Сегментный эмбеддинг (\(E_A/E_B\)) различает пару предложений — он нужен для NSP (слайд 41) и для пар-задач (например, QQP, MNLI). Подчеркните: позиционные эмбеддинги обучаемые, контекст ограничен 512 токенами.
