Авторегрессия Autoregression next-token language modeling

Совместную вероятность последовательности раскладываем по цепному правилу — каждый токен зависит только от прошлого:

We factor the joint probability of a sequence by the chain rule — each token depends only on the past:

$$p(x) \;=\; \prod_{t=1}^{T} p\!\left(x_t \mid x_{<t}\right)$$

Objective обучения — next-token cross-entropy: \(\mathcal{L} = -\sum_t \log p(x_t \mid x_{<t})\). Это не MLM. The training objective is next-token cross-entropy: \(\mathcal{L} = -\sum_t \log p(x_t \mid x_{<t})\). This is not MLM.

Цепное правило точно, без приближений. Контраст с MLM: там предсказываем замаскированные токены по обе стороны; здесь — только следующий по левому контексту. Objective — обычная CE на следующий токен.
