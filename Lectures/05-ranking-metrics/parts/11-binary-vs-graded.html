Наши градуированные меткиOur graded labels

Оценки \(0/1/3\): не по теме \(=0\), маргинально релевантно \(=1\), сильные space-попадания \(=3\). В порядке рангов: \([0,3,0,3,0,1,0,1]\).Grades \(0/1/3\): off-topic \(=0\), marginally relevant \(=1\), strong space hits \(=3\). In rank order: \([0,3,0,3,0,1,0,1]\).

Правило оценивания (чтобы оценки не были выдуманы): документ, прямо по теме запроса — сфокусированная статья sci.space — получает \(3\); тот, который задевает её лишь вскользь (упоминает запуск внутри не по теме поста), получает \(1\); всё не по теме получает \(0\). Та же рубрика, которую используют асессоры TREC, масштабированная до трёх уровней.Grading rule (so the grades aren't invented): a doc squarely on the query topic — a focused sci.space article — scores \(3\); one that only touches it in passing (mentions a launch inside an off-topic post) scores \(1\); anything off-topic scores \(0\). Same rubric TREC assessors use, scaled to three levels.

Бинарная выбрасывает «насколько релевантно». Градуированная сохраняет это — и идеальное попадание на ранге 1 должно превосходить маргинальное на ранге 1. Часть 04 построена на градуированной шкале.Binary throws away "how relevant". Graded keeps it — and a rank-1 perfect hit should out-score a rank-1 marginal one. Part 04 is built on the graded scale.

The label scale decides which metrics you can even compute. Binary is yes/no — cheap and the foundation of the counting family. Graded — TREC uses 0 through 4, we use 0/1/3 — captures that some relevant docs are far better than others, which is exactly what nDCG needs. We carry both scales for the same running ranking, so you'll see the very same eight documents scored binary in Part 3 and graded in Part 4.
