Две ветки, по 10000 сессий каждая. Метрика = кликабельность.Two arms, 10000 sessions each. Metric = click-through rate.

$$\bar p = \frac{1200+1320}{10000+10000} = \frac{2520}{20000} = 0.126$$

Объединённая доля. \(\mathrm{CTR}_C=0{,}12\), \(\mathrm{CTR}_T=0{,}132\), абсолютный прирост \(\Delta=0{,}012\).Pooled rate. \(\mathrm{CTR}_C=0.12\), \(\mathrm{CTR}_T=0.132\), absolute lift \(\Delta=0.012\).

$$\mathrm{SE} = \sqrt{0.126{\cdot}0.874\!\left(\tfrac{1}{10000}+\tfrac{1}{10000}\right)} = 0.00469$$

Стандартная ошибка разности долей, с использованием \(\bar p\).Standard error of the difference in proportions, using \(\bar p\).

$$z = \frac{0.132-0.120}{0.00469} = 2.557 \;\Rightarrow\; p = 0.01056$$

overview
The canonical online experiment. Split traffic: control sees the old ranking, treatment sees the new one — here 10000 sessions each. The metric is click-through rate: 1200 clicks gives 0.12 for control, 1320 gives 0.132 for treatment. To test the 0.012 difference, pool the rates (0.126), compute the standard error of the difference in proportions (0.00469), and form z = 0.012 / 0.00469 = 2.557, two-sided p = 0.01056 — significant. The relative lift is 0.012 / 0.12 = 10%. Significant and sizeable, so ship treatment. Note the same logic as the paired t-test, just for proportions.
