«Если мы оптимизируем метрику, система наверняка становится лучше».“If we optimise the metric, the system must be getting better.”

Закон Гудхарта: когда мера становится целью, она перестаёт быть хорошей мерой. Оптимизируй прокси (клики, популярность) — и ранжирование может выглядеть оживлённее, тогда как настоящая релевантность падает. Метрика, на которой ты обучался, тихо перестаёт измерять то, что тебе важно.Goodhart's law: when a measure becomes a target, it stops being a good measure. Optimise a proxy (clicks, popularity) and the ranking can look busier while genuine relevance falls. The metric you trained on quietly stops measuring what you cared about.

Разбор — nDCG с бинарным выигрышем.Worked example — binary-gain nDCG. Релевантность бинарна (4 документа sci.space), поэтому у всех один и тот же идеал:Relevance is binary (4 sci.space docs), so all use the same ideal:
\(\mathrm{IDCG} = 1.0 + 0.6309 + 0.5 + 0.4307 = 2.5616\).
НакрученныйGamed порядокorder [D6,D7,D5,D4,D3,D2,D0,D1] хоронит 4 релевантных документа на позициях 5–8:buries the 4 relevant docs at ranks 5–8:
\(\mathrm{DCG} = 0.3869 + 0.3562 + 0.3333 + 0.3155 = 1.3919 \Rightarrow \mathrm{nDCG} = 1.3919/2.5616 = 0.5434\).
ЧестныйHonest порядок BM25:BM25 order: \(\mathrm{DCG} = 0.6309 + 0.4307 + 0.3562 + 0.3155 = 1.7333 \Rightarrow 1.7333/2.5616 = 0.6766\).
Трюк с популярностью набирает меньше, а не больше: nDCG сравнивает с идеалом по размеченной релевантности и потому накрутку ловит.

Гудхарт бьёт там, где разметки нет и оптимизируют прокси: клики, длину, «полноту» по мнению судьи-модели. Переворот — оценка растёт, ответы портятся — ты увидишь на L16.The popularity hack scores lower, not higher: nDCG grades against an ideal built from labelled relevance, so it catches the hack.

Goodhart bites where there are no labels and you optimise a proxy: clicks, length, a judge model's “completeness”. You will watch that flip — score up, answers worse — in L16.

Goodhart the Trickster returns — first met in Lecture 1, now in his home territory of Measure. The trap: teams chase an easy proxy like click-through or popularity, assuming it tracks relevance. It does not. The gamed ranking here stuffs popular hockey docs at the top; it looks engaging but pushes every space doc downward, so binary-gain nDCG drops from 0.6766 to 0.5434 (shared binary IDCG = 2.5616; gamed DCG = 1.3919, honest DCG = 1.7333). Note this is the binary-gain nDCG; the same honest ranking scored 0.6622 in the Part 04 graded nDCG worked example under graded 0/1/3 gains. The lesson: a metric is only honest while it is not the thing being gamed — which is exactly why we evaluate against held-out relevance judgments and confirm online, not against the signal we optimised.
