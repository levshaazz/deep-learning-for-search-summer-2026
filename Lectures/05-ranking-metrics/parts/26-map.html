AP смотрит на каждую позицию, где появляется релевантный документ, поэтому вознаграждает более высокое ранжирование релевантных документов. AP равна площади под PR-кривой, если точность интерполирована; вычисляемое нами усреднение по попаданиям — это стандартная дискретизация этой площади. GMAP использует среднее геометрическое — подчёркивая трудные запросы.AP looks at every rank where a relevant doc appears, so it rewards ranking relevant docs higher. AP equals the area under the PR curve once precision is interpolated; the hit-average we compute is the standard discretisation of that area. GMAP uses the geometric mean — emphasising hard queries.

MAP is the workhorse of binary-relevance IR. Average Precision evaluates Precision@k at each rank where a relevant document actually sits, then averages those values over the number of relevant docs — which is, to a good approximation, the area under the precision-recall curve. Because precision is higher when hits are near the top, AP rewards surfacing relevant docs early. MAP is AP averaged over queries arithmetically; GMAP uses the geometric mean, which weights improvements on already-hard queries more heavily.
