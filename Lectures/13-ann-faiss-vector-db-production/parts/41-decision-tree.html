Как выбрать одинHow to pick one

три оси: граф · разбиение · сжатиеthree axes: graph · partition · compression

Каждый коридор отвечает на свой вопрос. Иди по дереву сверху вниз.Each lane answers a different question. Walk the tree top-down.

01
Помещается ли без сжатия в RAM?Does it fit in RAM uncompressed?
Да → PQ не нужен. Нет → нужно сжатие (PQ): IVF-PQ или HNSW-PQ. Память — первая жёсткая стена на миллиардном масштабе.Yes → no PQ needed. No → you need compression (PQ): IVF-PQ or HNSW-PQ. Memory is the first hard wall at billion scale.

02
Приоритет — наименьшая задержка?Is lowest latency the priority?
Да → граф (HNSW): прогулка \(O(\log N)\), полнота настраивается вживую. Сочетай с PQ (HNSW-PQ), если его тоже нужно сжать.Yes → a graph (HNSW): \(O(\log N)\) walk, recall tuned live. Pair with PQ (HNSW-PQ) if it also must be compressed.
графgraph
03
Приоритет — дешёвое обучение / лёгкие обновления?Is cheap training / easy updates the priority?
Да → разбиение (IVF): просто \(k\)-means, дешёвые вставки, nprobe перенастраивается. Добавь PQ (IVF-PQ) ради RAM — рабочая лошадка миллиардного масштаба.Yes → a partition (IVF): just \(k\)-means, cheap inserts, nprobe retunable. Add PQ (IVF-PQ) for RAM — the billion-scale workhorse.

Крошечный корпус или нужен эталонный базовый вариант?Tiny corpus or need a ground-truth baseline?
Используй flat — точный, \(O(N\!\cdot\!D)\), нулевое построение. Всегда держи его как мерило полноты, с которым сравнивают ANN-индекс.Use flat — exact, \(O(N\!\cdot\!D)\), zero build. Always keep it as the recall yardstick the ANN index is measured against.

Decision-tree walkthrough on three axes. (1) Fits RAM? No → PQ. (2) Lowest latency? → graph (HNSW), HNSW-PQ if also compressed. (3) Cheap training / easy updates? → partition (IVF), IVF-PQ for RAM. (4) Tiny / baseline → flat (exact ground truth). Maps the three primitives to the five indexes of the matrix; complexities reference l9-compare.
