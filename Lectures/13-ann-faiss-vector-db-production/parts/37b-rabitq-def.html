Три шага, и ни одного обучения. Первый: нормируй вектор — все данные ложатся на единичную сферу. Второй: возьми готовую кодовую книгу — это \(2^{D}\) вершин гиперкуба с координатами \(\pm 1/\sqrt{D}\); они уже разложены по сфере равномерно. Третий: поверни их одной случайной ортогональной матрицей \(P\) — это преобразование Джонсона—Линденштрауса.Three steps, no training anywhere. One: normalise the vector — all data lands on the unit sphere. Two: take the codebook off the shelf — the \(2^{D}\) hypercube vertices with coordinates \(\pm 1/\sqrt{D}\), already spread evenly over that sphere. Three: rotate them by one random orthogonal matrix \(P\) — a Johnson–Lindenstrauss transform.

Код вектора — ближайшая вершина, то есть строка из \(D\) бит: один бит на измерение. Оценка скалярного произведения по этому коду несмещённая, и её отклонение ограничено величиной порядка \(1/\sqrt{D-1}\) — граница, которой у PQ нет.A vector's code is the nearest vertex — a string of \(D\) bits: one bit per dimension. The inner-product estimate read off that code is unbiased, and its deviation is bounded on the order of \(1/\sqrt{D-1}\) — the bound PQ does not have.

Обрати внимание, что здесь исчезло: обучение k-средних, зависимость от корпуса, переобучение книги при дрейфе данных. Случайность взяли не из данных, а из поворота — поэтому обещание держится на любом корпусе, включая тот, который ты ещё не видел. Notice what disappeared: the k-means training, the dependence on your corpus, the re-training when data drifts. The randomness comes from the rotation, not from the data — which is why the promise holds on any corpus, including one you have not seen yet.

Определение RaBitQ (Gao & Long, SIGMOD 2024, §3.1). Ключевой контраст с PQ, который стоит проговорить вслух: у PQ кодовая книга ВЫУЧЕНА по данным (k-средних), у RaBitQ она ФИКСИРОВАНА — вершины гиперкуба ±1/√D, — и данные к ней приводит случайный поворот. Отсюда и граница ошибки: она следует из свойств JL-преобразования, а не из того, насколько повезло с корпусом. Формально: нормировка на единичную сферу (§3.1.1), кодовая книга как вершины куба (§3.1.2), случайное вращение P, код = ближайшая вершина = D бит.
