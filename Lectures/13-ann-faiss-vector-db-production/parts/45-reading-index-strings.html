Третья строка — вся лекция в одну строку: OPQ предвращает, чтобы PQ сжимал лучше, IVF разбивает пространство, граф HNSW индексирует центроиды, так что даже поиск грубого квантователя — \(O(\log \textrm{nlist})\), а PQ сворачивает каждый вектор до 64 байт. Граф + разбиение + сжатие, скомпонованные.The third string is the whole lecture in one line: OPQ pre-rotates so PQ compresses better, IVF partitions space, an HNSW graph indexes the centroids so even the coarse-quantizer lookup is \(O(\log \textrm{nlist})\), and PQ folds each vector to 64 bytes. Graph + partition + compression, composed.

Reading-index-strings cmp-table. HNSW32 = pure graph (M=32), uncompressed. IVF4096,PQ96 = 4096 cells + 96-byte PQ = IVF-PQ. OPQ64,IVF16384_HNSW32,PQ64 = OPQ rotation + IVF (16384 cells, HNSW coarse quantizer) + 64-byte PQ = the full production stack composing all three lanes. The closing note ties the grammar back to the three primitives. Strings are illustrative API recipes (same as the code slide), not gated decimals.
