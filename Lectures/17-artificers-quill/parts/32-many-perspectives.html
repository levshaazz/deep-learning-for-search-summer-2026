Приём · мульти-запросThe move · multi-query

Промпти LLM перефразировать запрос в N вариантов, каждый бьёт в иную грань или лексику — не N копий тех же слов.Prompt the LLM to paraphrase the query into N variants, each hitting a different facet or vocabulary — not N copies of the same words.

Каждый парафраз хеджирует Лексического Гремлина: там, где одна формулировка промахивается мимо полки, другая на неё попадает.Every paraphrase hedges the Lexical Gremlin: where one phrasing misses the shelf, another lands on it.

  • ·«почему мой эспрессо кислый и водянистый?» → сырая жалоба“why is my espresso sour and watery?” → the raw complaint
  • ·«причины недоэкстракции в эспрессо» → термин архива“causes of under-extraction in espresso” → the archive's term
  • ·«исправить слабый кислый шот — помол, доза, channeling» → грань механизма“fix weak sour shot — grind, dose, channeling” → the mechanism facet

Три прицела в одну и ту же цель — каждый покрывает угол, который упускают другие.Three aims at the same target — each covers a corner the others miss.

Multi-query = paraphrase one query into N variants across different facets/vocabulary, so each hedges the Lexical Gremlin's word-matching. The value is DIVERSITY of coverage, not repetition. This sets up the union (S33) and the fusion tool that recombines them (RRF, S34+).
