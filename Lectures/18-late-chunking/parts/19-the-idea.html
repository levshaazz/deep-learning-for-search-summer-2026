Механика · позднее чанкование The mechanics · late chunking
Закодируй весь документ, потом усредни по границам чанков. Embed the whole document, then mean-pool per chunk boundary.
  • 1Прогнать трансформер по всему документу один раз → контекстные эмбеддинги токенов.Run the transformer over the whole document once → contextual token embeddings.
  • 2Расставить границы чанков — те же, что и в наивном методе.Place chunk boundaries — the same ones the naive method uses.
  • 3Усреднить токены внутри каждого чанка → один вектор на чанк.Mean-pool the tokens inside each chunk → one vector per chunk.
Метафора · сначала книга, потом страницы The metaphor · book first, pages after

Наивно — «вырвать страницы, потом читать каждую в одиночку»: страница, где сказано лишь «его жители…», забыла, чей это город.Naive — “tear the pages out, then read each alone”: a page that only says “its residents…” has forgotten whose city it is.

Поздно — прочитать книгу целиком, затем отметить границы: каждый чанк помнит подлежащее.Late — read the book whole, then mark the boundaries: every chunk keeps its subject.

Единственное отличие от обычного эмбеддинга документа: усредняем по сегментам, а не по всем токенам.The only change from an ordinary document embedding: pool over segments, not over all tokens.

Меняется только момент, когда режем — границы те же, что у наивного метода.Only the moment of cutting changes — the boundaries are the same as the naive method’s.
