Почему старые метрики не подходят генерацииWhy the old metrics don't fit generation

recall@k оценивал ранжированный список — но для свободного текста ключа нетrecall@k graded a ranked list — but there is no key for free-text

Что сломалосьWhat broke

  • Нет золотого ответа. У реального вопроса редко есть один канонический абзац для сравнения.No gold answer. For a real question there is rarely one canonical paragraph to diff against.
  • Много верных ответов. Один факт можно сформулировать сотней допустимых способов — точное совпадение оценит их все нулём.Many right answers. The same fact can be phrased a hundred valid ways — exact-match scores them all zero.
  • Два режима отказа сразу. Ответ может уйти от темы и выдумать факты; одно число их не разделит.Two failure modes at once. An answer can drift off-topic and invent facts; one number can't separate them.

Что нужно вместо этогоWhat we need instead

Метрики, что оценивают сгенерированный ответ против извлечённого контекста и вопроса — а не против эталонного ключа. Именно этот пробел закрывает RAGAS: оценки без эталона, раскладывающие качество RAG на верность, релевантность и обе стороны извлечения.Metrics that grade a generated answer against the retrieved context and the question — not against a reference key. That is exactly the gap RAGAS fills: reference-free scores that decompose RAG quality into faithfulness, relevance, and both sides of retrieval.

problem-no-gold. Classic IR metrics (recall@k, MRR — L1/L5) graded a ranked list against a known relevant set. Generation has no gold answer, many valid phrasings, and two simultaneous failure modes — so exact-match/BLEU don't fit. Motivates reference-free metrics (RAGAS) next.
