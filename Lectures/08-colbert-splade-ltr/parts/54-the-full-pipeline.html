разрежённый + плотный + ColBERT → гибрид → LTR → (L9 держит быстро)sparse + dense + ColBERT → hybrid → LTR → (L9 keeps it fast)

Три армии добывают кандидатов, гибрид (RRF) сливает их в один набор, капитан (LambdaMART) переупорядочивает верх. Сублинейную скорость каждой армии обеспечивает ANN — это L9; готовый ответ генерирует RAG — это L10. (Фиолетовый — не четвёртый сигнал, а стадия слияния: синий — разрежённый, оранжевый — плотный, фиолетовый — где они сходятся.)Three armies retrieve candidates, hybrid (RRF) fuses them into one set, the captain (LambdaMART) reranks the top. ANN makes each army sublinear — that's L9; RAG turns the result into an answer — that's L10. (Violet is not a fourth signal but the fused stage: blue = sparse, orange = dense, violet = where they merge.)

Full pipeline: sparse+dense+ColBERT → hybrid fuse → LTR rerank → (L9 ANN). Bridges to L9/L10. No gated numbers.
