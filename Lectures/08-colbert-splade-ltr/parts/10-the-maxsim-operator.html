Оператор MaxSimThe MaxSim operator

для каждого токена запроса — максимум по токенам документа, затем суммаper query token, the max over doc tokens, then the sum
$$ S_{q,d} \;=\; \sum_{i \in q} \max_{j \in d} \; E_{q_i} \cdot E_{d_j} $$

Векторы L2-нормированы, поэтому скалярное произведение — это косинус. Каждый токен запроса «салютует» одному токену документа, с которым совпадает лучше всего (\(\max_j\)); оценка — сумма этих лучших салютов. Не средний по всем парам — именно максимум, затем сумма (отсылка L2: косинус как линейка).Vectors are L2-normalized, so the dot product is a cosine. Each query token "salutes" the one document token it matches best (\(\max_j\)); the score is the sum of those best salutes. Not an average over all pairs — a max, then a sum (callback L2: cosine as a ruler).

MaxSim operator. L2-norm → dot = cosine. Max-then-sum is the key: reward matching many query tokens, each to its best partner.
