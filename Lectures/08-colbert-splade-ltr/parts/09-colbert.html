ColBERT

эмбеддинг на токен; документы — заранее; взаимодействие на запросеan embedding per token; docs precomputed; interact at query time

Каждый токен запроса и документа получает свой 128-мерный вектор (\(E_q \in \mathbb{R}^{|q|\times128}\)). Векторы документа считаются офлайн и кэшируются — взаимодействие происходит дёшево, на запросе (отсылка L2: всё — последовательность токенов).Each query and document token gets its own 128-dim vector (\(E_q \in \mathbb{R}^{|q|\times128}\)). The document vectors are computed offline and cached — interaction happens cheaply, at query time (callback L2: everything is a sequence of tokens).

Architecture: per-token embeddings, doc precomputed, MaxSim at query time. Shapes E_q ∈ ℝ^(|q|×128).
