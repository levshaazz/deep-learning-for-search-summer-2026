Маршрут сквозь гиперпространствоThe route through hyperspace

приближённый поиск ближайших соседей, а затем — в продакшнapproximate nearest neighbour, then ship it
  1. Смерть линейного перебора — стоимость \(O(N\cdot d)\) и концентрация расстояний в высокой размерности (Призрак). Почему точный kNN не может облететь галактику.The death of linear scan — \(O(N\cdot d)\) cost and high-dimensional distance concentration (the Wraith). Why exact kNN can't fly the galaxy.
  2. Метрики — L2 против косинуса против скалярного произведения на одних и тех же векторах; одна пара — три разных top-1. Выбор метрики и есть моделирующее решение.Metrics — L2 vs cosine vs inner product on the same vectors; the same pair, three different top-1. The metric choice is a modeling choice.
  3. HNSW — навигируемый граф малого мира, по которому ты идёшь к запросу (жадный спуск; выигрыш \(O(\log N)\); ручки ef / M).HNSW — a navigable small-world graph you walk to the query (greedy descent; the \(O(\log N)\) win; the ef / M knobs).
  4. IVF — разрезать пространство на ячейки Вороного; зондировать только ближайшие (полнота против nprobe).IVF — carve space into Voronoi cells; probe only the nearest (recall vs nprobe).
  5. PQ — свернуть каждый вектор в горстку байтов кодовой книги (32 → 4; ADC; регулятор память↔полнота).PQ — fold each vector to a handful of codebook bytes (32 → 4; ADC; the memory↔recall dial).
  6. Сравнение — flat / HNSW / IVF / IVF-PQ / HNSW-PQ бок о бок и дерево решений для выбора одного.The comparison — flat / HNSW / IVF / IVF-PQ / HNSW-PQ side by side, and a decision tree for picking one.
  7. Продакшн — FAISS против векторных БД, грамматика index-factory, бюджет задержки против SLA по \(p_{99}\), кэширование и Айсберг под демонстрацией.Production — FAISS vs vector DBs, the index-factory grammar, the latency budget against a \(p_{99}\) SLA, caching, and the Iceberg below the demo.
Seven stops: linear-scan death → metrics → the three ANN lanes (HNSW / IVF / PQ) → the comparison → production. Each lane fronted by a light turn. Closes by bridging to L10 (find → answer).
