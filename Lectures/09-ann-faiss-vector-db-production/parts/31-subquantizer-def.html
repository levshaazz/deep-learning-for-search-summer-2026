where m = subvectors, k = centroids per sub-codebook, d = vector dim; each subvector has d/m dims.

Раздели каждый вектор на \(m\) подвекторов, каждый квантуется независимо своей кодовой книгой на \(k\) центроидов. Код — это кортеж из \(m\) подкодов — одна точка в их декартовом произведении.Split each vector into \(m\) subvectors, each quantized independently with its own \(k\)-centroid codebook. The code is the tuple of \(m\) sub-codes — one point in their Cartesian product.

Комбинаторный выигрыш: храни лишь \(m\cdot k\) центроидов, но код представляет \(k^m\) реконструкций. При \(m=8,\ k=256\): храни \(8\times 256 = 2048\) центроидов, адресуй \(256^{8}\approx 1{,}8\times 10^{19}\) точек.Combinatorial payoff: store only \(m\cdot k\) centroids, but the code represents \(k^m\) reconstructions. With \(m=8,\ k=256\): store \(8\times 256 = 2048\) centroids, address \(256^{8}\approx 1.8\times 10^{19}\) points.

Subquantizer decomposition def-card. PQ splits a vector into m subvectors, each quantized with its own k-centroid codebook; the code is the tuple = a point in the Cartesian product. Store m·k centroids (8·256=2048) but represent k^m reconstructions (256^8 ≈ 1.8e19). A flat codebook of k^m is infeasible — the product structure is the trick. Sets up the climb + memory math + ADC.
