The FAISS index-factory grammar

Python · faiss · one string builds the whole index
Python · build_index.pyfaiss
import faiss

# A comma-separated recipe: [transform,] coarse-quantizer , encoding
d = 768

# IVF with 4096 cells, each vector PQ-encoded to 96 bytes
idx = faiss.index_factory(d, "IVF4096,PQ96")

# A pure HNSW graph, M = 32 edges per node (no compression)
idx = faiss.index_factory(d, "HNSW32")

# OPQ rotation → IVF (16384 cells, HNSW coarse quantizer) → PQ 64 bytes
idx = faiss.index_factory(d, "OPQ64,IVF16384_HNSW32,PQ64")

idx.train(xb)          # learn centroids + codebooks (offline)
idx.add(xb)            # file every vector under its cell / code
idx.nprobe = 16        # the recall<->work dial, set at query time

Read it left to right: an optional transform (OPQ64), then the coarse quantizer (IVF4096, or IVF16384_HNSW32 = an HNSW-indexed quantizer), then the encoding (PQ96, Flat, …). The whole index from one string.

Index-factory code slide. The grammar: [transform,] quantizer, encoding. "IVF4096,PQ96" = 4096 cells, 96-byte PQ codes. "HNSW32" = HNSW graph, M=32, uncompressed. "OPQ64,IVF16384_HNSW32,PQ64" = OPQ rotation → IVF with an HNSW coarse quantizer (16384 cells) → PQ 64 bytes. train/add/nprobe are the lifecycle. nprobe set at query time is the recall↔work dial. Code is illustrative API shape, not gated numbers.
