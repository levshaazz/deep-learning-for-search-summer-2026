Многослойный граф близости, по которому ты жадно идёшь к запросу. Он складывает три идеи:A multi-layer proximity graph that you greedily walk toward the query. It stacks three ideas:

Skip-list — отсортированный список с экспресс-полосами, поэтому поиск перепрыгивает длинные участки за \(O(\log N)\). NSW (Navigable Small World) — соедини каждую точку с близкими соседями плюс дальнодействующими связями, чтобы любой узел был коротким жадным путём от любого другого. HNSW — расслои граф малого мира: разреженные дальнодействующие хабы наверху, плотные окрестности у основания.Skip-list — a sorted list with express lanes, so search skips long stretches in \(O(\log N)\). NSW (Navigable Small World) — connect each point to near neighbours plus long-range links, so any node is a short greedy walk from any other. HNSW — layer the small-world graph: sparse long-range hubs on top, dense neighbourhoods at the base.

Входи наверху, спускайся слой за слоем, уточняй на плотном основании — без обучения, инкрементальные вставки.Enter at the top, descend layer by layer, refine on the dense base — no training, incremental inserts.

HNSW definition def-card. The lineage: skip-list (layered express lanes, O(log N)) + NSW (near links + long-range links → short greedy paths) → HNSW (layer the small-world graph). Entry at the sparse top, descend to the dense base. Sets up the O(log N) theorem next and the two-layer climb after.
