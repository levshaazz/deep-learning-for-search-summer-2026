FAISS против векторной базы данныхFAISS vs a vector database

FAISS — библиотекаFAISS — a library

Построй индекс в своём процессе и вызывай его: IndexFlat (точный), IndexIVFPQ, IndexHNSWFlat. Используй, когда индекс помещается в один процесс, который ты контролируешь.Build an index in your own process and call it: IndexFlat (exact), IndexIVFPQ, IndexHNSWFlat. Use it when the index fits one process you control.

Векторная БД — сервисVector DB — a service

Индекс плюс хранилище, фильтрация по метаданным, обновления, репликация и API — запрашивается по сети. Используй, когда нужно, чтобы это было управляемым, фильтруемым и общим.The index plus storage, metadata filtering, updates, replication, and an API — queried over the network. Use it when you need it managed, filtered, and shared.

Правило большого пальца: FAISS, когда помещается на одной машине, которой ты владеешь; векторная БД, когда её нужно эксплуатировать, фильтровать и делить.Rule of thumb: FAISS when it fits one box you own; a vector DB when it must be operated, filtered, and shared.

turn-production detail. Library vs service. Both consume the same ANN structures.
