The 90% below the waterline

what keeps the lanes open in production
  • Serve under the SLA — budget every hop; alert on \(p_{99}\), not \(p_{50}\) (here \(p_{99}=180\)ms vs the \(200\)ms ceiling).
  • Monitor recall and latency — recall silently decays as data drifts; a flat dashboard is not a healthy one.
  • Rebuild the index as documents are added, changed, deleted — stale graphs and lists lose neighbours.
  • Retrain quantizers on drift — IVF centroids and PQ codebooks were trained on old data; refresh them.
  • Cache the hot tail — repeats return in \(\approx 5\)ms; cache invalidation tracks index rebuilds.
  • Budget the RAM — the compressed index still has to fit; size it against \(N\times\) bytes/vector.
  • Filter + ANN together — metadata filters and freshness windows interact with the cells/graph; test them as one path.
  • Keep a flat baseline — the exact ground truth you measure recall against, forever.

The notebook that finds neighbours is the easy 10%. This list is the 90% — and it is where L11 (evaluation & monitoring) picks up.
