ADC — расстояние по табличному поискуADC — distance from a table lookup

прослеживайте по одному коду на подпространство (←/→): ADC 35 против точного 37trace one code per subspace (←/→): ADC 35 vs exact 37

Раздели запрос на \(m=4\) подзапроса и предвычисли \(m\times k\) таблицу квадратов подрасстояний. Вектор базы, хранимый как коды \([2,0,3,1]\), стоит \(\hat d^2=\sum_j \textrm{table}[j][\textrm{code}_j]=2+0+20+13=\mathbf{35}\) — четыре обращения, никакой арифметики полного вектора. Точное расстояние — \(37\); разрыв в \(2\) — это ошибка квантования. ADC асимметрична и смещена: она измеряет расстояние до реконструкции по каждому подпространству, поэтому эти ошибки накапливаются по \(m\) подпространствам — именно это накопление ограничивает полноту около \(0.7\) и именно его снижает OPQ (вращение в продакшн-строке фабрики).Split the query into \(m=4\) subqueries and precompute an \(m\times k\) table of squared sub-distances. A database vector stored as codes \([2,0,3,1]\) costs \(\hat d^2=\sum_j \textrm{table}[j][\textrm{code}_j]=2+0+20+13=\mathbf{35}\) — four lookups, no full-vector math. The exact distance is \(37\); the gap of \(2\) is the quantization error. ADC is asymmetric and biased: it measures distance to the per-subspace reconstruction, so these errors accumulate across the \(m\) subspaces — that accumulation is exactly what caps recall near \(0.7\) and what OPQ (the rotation in the production factory string) reduces.

pq-quantize variant 'adc', maxStep 3 (one subspace row traced per step). ADC formula d̂²=Σ_j d(q_j, c_{j,code_j})².
