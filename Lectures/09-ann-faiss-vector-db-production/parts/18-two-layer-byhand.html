Ловушка и выход из неё, вручнуюThe trap and the escape, by hand

12 узлов · вход по базе \(b_0\) · вход по хабу \(b_2\)12 nodes · base entry \(b_0\) · hub entry \(b_2\)
$$ \text{base-only: } b_0 \to b_1 \to b_2 \to b_4,\quad d(b_4,q)=\mathbf{12.0};\ \text{all base neighbours farther} \;\Longrightarrow\; \text{recall@1}=\mathbf{0.0} $$ $$ \text{hub layer: } b_2 \to b_7,\quad d(b_2,q)=13.0 \to d(b_7,q)=\mathbf{2.0} \;\Longrightarrow\; \text{long-range edge crosses the gap} $$ $$ \text{descend: } b_7 \to b_9,\quad d(b_9,q)=\mathbf{1.4142}=\text{brute-force NN} \;\Longrightarrow\; \text{recall@1}=\mathbf{1.0} $$

Жадный поиск только по базе застревает в \(b_4\), потому что ни одно базовое ребро не достаёт до правого кластера — полнота 0,0. Войдя в разреженный хаб \(b_2\), один переход \(13{,}0\to 2{,}0\) перепрыгивает разрыв, затем плотная база уточняет до \(b_9\) на \(1{,}4142\) — полнота 1,0. Именно верхний слой заставляет жадный спуск работать на масштабе.Base-only greedy traps at \(b_4\) because no base edge reaches the right-hand cluster — recall 0.0. Entering at the sparse hub \(b_2\), one \(13.0\to 2.0\) hop leaps the gap, then the dense base refines to \(b_9\) at \(1.4142\) — recall 1.0. The upper layer is what makes greedy descent work at scale.

Two-layer descent by hand. base-only path b0→b1→b2→b4, trapped at b4 (d=12.0), recall 0.0; hub hop b2→b7 (13.0→2.0); base descent b7→b9 (1.4142 = brute-force NN), recall 1.0.
