Total 89ms — comfortably under 200. The cache + log hop is fire-and-forget (async), so its +2ms is off the user-facing critical path and is shown here only for completeness; the response returns after step 4. An exact scan of 10⁶×768-d would cost ~520ms for the search hop alone. ANN turns that 520 into 12; quantization keeps the index in RAM; caching makes repeats nearly free.
