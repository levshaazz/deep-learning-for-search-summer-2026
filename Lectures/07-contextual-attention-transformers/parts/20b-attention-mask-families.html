Self-attention lets every token see every other token — but should it always? That single question, answered by the mask placed before the softmax, splits the Transformer world into three architecture families. Encoder-only models like BERT use a bidirectional mask — a full square — so each token reads the whole input both ways; this is what you want for understanding and search, and it is exactly why dense retrievers are BERT-style encoders. Decoder-only models like GPT and Llama wear a causal mask: every score from a token to a later token is set to minus infinity before the softmax, so a token may attend only to itself and the past — never the future it has not generated yet — which is what makes one-token-at-a-time generation honest. Encoder-decoder models like T5 do both: a bidirectional encoder reads the full source, and a causal decoder generates the target while cross-attending back to the encoder — the cross-attention we forward-referenced on the previous slide. One triangular mask is the whole difference between reading and writing; search lives firmly in the encoder camp.
