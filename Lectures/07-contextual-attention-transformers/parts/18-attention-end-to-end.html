The mechanical companion to the geometric pull — scaled dot-product attention assembled one matrix at a time, in the same archflow style as the Transformer-block slide, every number exact from the data file. Step zero, the wrapper formula: softmax of Q K-transpose over root d-k, times V. Step one, the inputs — Q is three-by-four, K-transpose is four-by-three, with d-k equal to four. Step two, multiply to get the three-by-three score matrix Q K-transpose; the cat-on-cat diagonal entry, four, is the largest. Step three, divide every score by root d-k, which is two, so the variance does not blow up with dimension. Step four, row-softmax turns each row into attention weights that sum to one — the cat row is point-zero-nine, point-six-seven, point-two-five. Step five, bring in the value matrix V, the content to be mixed. Step six, multiply the weights by V to get the three-by-four output; each row is a weighted sum of value rows, and the cat row, point-five-eight, two, point-nine-one, point-four-three, is cat's contextual vector — exactly the row the next slide draws as a geometric pull.
