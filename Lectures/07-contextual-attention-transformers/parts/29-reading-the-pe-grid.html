Read the grid like a table of real numbers. Step one: row pos zero is all sines-of-zero and cosines-of-zero, so it alternates zero, one, zero, one across the eight dimensions. Step two: column d zero is the sine of the position, which runs zero, zero point eight four one, zero point nine zero nine, zero point one four one, minus zero point seven five seven — a fast wave that clearly distinguishes adjacent positions. Step three: column d six is a very low-frequency sine, barely moving — zero, zero point zero zero one, zero point zero zero two — it encodes coarse global position. Step four: the combination of fast and slow dimensions gives every position a unique fingerprint, and because it is built from sinusoids, nearby positions have similar fingerprints. It is fixed, computed once, never trained — though learned positional embeddings are a common alternative.
