Make the contrast concrete, as a side-by-side. A static embedding, like word2vec or GloVe, is a lookup table — you index in with the word string and read out a fixed vector, so bank gets one point for both senses, depending only on the word. A contextual embedding, as in ELMo in early 2018 and then BERT, is the output of a neural network that has read the whole sentence, so river bank and bank account get different vectors — it depends on the word and its context. The price is computation: a lookup is instant, but a contextual vector requires running the sentence through a stack of attention layers. The rest of this lecture builds that stack, one mechanism at a time.
