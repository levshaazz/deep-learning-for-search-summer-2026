A Vector per Context

Не координата на слово — координата на употребление:Not a coordinate per word — a coordinate per use: одно слово, разные точки в разных предложениях.the same word, different points in different sentences.

The turn. We are moving from a static map to a dynamic one. In the static world each word was a fixed star; in the contextual world a word's position is computed fresh for each sentence. The same token can land in two different places depending on what surrounds it. This single change is what splits the two banks apart, and it is also what makes a sentence vector finally meaningful — because the parts now know about each other. The mechanism that computes those context-aware positions is attention.
