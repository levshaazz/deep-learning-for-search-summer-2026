Матрица эмбеддингов — это таблица выбора строкThe embedding matrix is a row-lookup table

шаг (←/→): one-hot вход → выбор строки W → скалярные произведения → softmaxstep (←/→): the one-hot input → selecting a row of W → the dot products → softmax

Схема с прошлого слайда — теперь с настоящими числами внутри. Умножение на one-hot не вычисляет ничего хитрого: оно просто достаёт одну строку матрицы, и эта строка и есть эмбеддинг слова. Дальше та же матрица работает в обратную сторону, и softmax превращает сырые счёты в распределение по контексту.The diagram from the previous slide — now with real numbers inside. Multiplying by a one-hot computes nothing clever: it simply pulls out one row of the matrix, and that row IS the word’s embedding. Then the same matrix works in reverse, and softmax turns the raw scores into a distribution over context words.

The climb of the word2vec act, mounted after the network walkthrough so the architecture is already on the table — this slide’s job is to demystify it with real numbers from data/l5-skipgram.json. Steps: (0) the centre word as a bare index — a one-hot column, not a vector of meaning yet; (1) the multiplication that is actually a row SELECTION — DWELL, this kills the “the network computes the embedding” misconception: the embedding is stored, training only moves it; (2) the tied reuse of the matrix for scoring — the usual stumbling point, take it slowly; (3) softmax into a proper distribution. Land the takeaway verbatim: after training you throw the task away and KEEP THE TABLE — that table is what every later lecture calls “the embeddings”.
