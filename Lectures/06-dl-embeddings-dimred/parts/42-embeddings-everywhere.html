Рецепт неизменен: последовательность, в которой соседство несёт смысл, \(\Rightarrow\) тот же приём «предсказать по соседям» (skip-gram или masked-LM) \(\Rightarrow\) карта, по которой ищут косинусом. «Всё — последовательность токенов в выученном пространстве».The recipe never changes: a sequence whose adjacency carries meaning \(\Rightarrow\) the same predict-from-neighbours recipe (skip-gram or masked-LM) \(\Rightarrow\) a map you search with cosine. “Everything is a sequence of tokens in a learned space.”

The cross-domain table — the headline of this lecture's second half. Row one, graphs: node2vec and DeepWalk run random walks over a network, treat each walk as a sentence and each visited node as a word, and feed that straight into skip-gram; the result is a node embedding where neighbours in the graph land near each other. Row two, recommendations: item2vec and prod2vec treat a shopping session or basket as the sentence and each product as the token, so "customers who bought this also bought that" becomes cosine nearness. Row three, proteins: language models like ESM and ProtBERT read an amino-acid chain as the sentence and each residue as the token, and the embedding lets you search for functionally similar proteins by vector, increasingly replacing alignment tools like BLAST. Row four, biosignals: an EEG trace or a DNA sequence is cut into time-windows or k-mers as tokens — DNABERT does exactly this for genomics — and the positional grid we will meet in Lecture 7 is already a time axis. One recipe, many fields: any sequence whose adjacency carries meaning yields a searchable map.

A word, a patch, a spectrogram frame, a residue — all become points on the same map.

The point: the recipe never changes — thing, tokens, vectors, one shared space — which is exactly why a single search index can hold all of them and why CLIP-style joint spaces work at all.
