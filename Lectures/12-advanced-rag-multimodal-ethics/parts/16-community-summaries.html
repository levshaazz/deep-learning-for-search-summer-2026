Кластеризуй граф на сообщества, предсуммируй каждое, затем направляй запрос в локальный обход или глобальный map-reduce.Cluster the graph into communities, pre-summarise each, then route a query to a local walk or a global map-reduce.
  • ·Локальный поиск — обход окрестности сущностей запроса (наш двухшаговый обход). Лучше всего для конкретных вопросов.Local search — walk the query entities' neighbourhood (our 2-hop traversal). Best for specific questions.
  • ·Глобальный поиск — map: каждая сводка сообщества даёт частичный ответ плюс самооценку релевантности; reduce: отбросить низкооценённые частичные, объединить остальные. Этот проход LLM по каждому сообществу — та цена, которую глобальный поиск платит за охват вопросов «главные темы?» по всему корпусу.Global search — map: each community summary yields a partial answer plus a self-rated relevance score; reduce: drop the low-scored partials, combine the rest. That per-community LLM pass is the cost global search pays for corpus-wide “main themes?” coverage.
  • ·From Local to Global — заголовок статьи и есть идея: близкий обход и взгляд с высоты птичьего полёта.From Local to Global — the paper's title is the idea: the close walk and the bird's-eye view.
