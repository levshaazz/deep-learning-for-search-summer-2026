How the shared space is learned

the contrastive objective — pull matched together, push the rest apart
$$ \mathcal{L} = -\frac{1}{N}\sum_{i=1}^{N} \log \frac{\exp\!\big(\cos(\mathbf{e}_{\text{img}}^{(i)},\,\mathbf{e}_{\text{txt}}^{(i)})/\tau\big)}{\sum_{j=1}^{N} \exp\!\big(\cos(\mathbf{e}_{\text{img}}^{(i)},\,\mathbf{e}_{\text{txt}}^{(j)})/\tau\big)} $$ $$ \text{maximise the diagonal } \cos(\text{img}_i,\text{txt}_i), \quad \text{minimise the off-diagonal } \cos(\text{img}_i,\text{txt}_{j\neq i}) $$

For a batch of \(N\) image–caption pairs, the loss is a softmax over the row of the cosine matrix: the correct caption (the diagonal cell) should win. This is the same family as L6's in-batch contrastive loss — the off-diagonal pairs are the negatives. CLIP additionally symmetrises, averaging this row-wise (image→text) loss with the matching column-wise (text→image) loss — the symmetric InfoNCE. Minimising it is what carved the 0.6153 gap we measured.

Contrastive objective. CLIP InfoNCE over the batch cosine matrix: softmax per row, diagonal = positive, off-diagonal = in-batch negatives. Identical to L6 in-batch contrastive loss. Temperature τ.
