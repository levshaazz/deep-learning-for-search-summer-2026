Hallucination is the harm; grounding is the control

a fluent, confident answer about something that does not exist

The harm

  • Ask a model about the “Quasar-9 vector database” — a fictional entity that does not exist.
  • Closed-book, llama3.1:8b does not abstain — it confabulates concrete features: “a collection of 9000 vectors… large-scale dataset…”
  • Fluent and confident and entirely invented. A user cannot tell this apart from a true answer.

The control

  • Ground the same question in a retrieved context that says no such database exists.
  • Now the model abstains: “I cannot answer this question. The context does not provide any information…”
  • Same model, same question — grounding plus the freedom to say “I don't know” turns a confident fabrication into an honest refusal.
