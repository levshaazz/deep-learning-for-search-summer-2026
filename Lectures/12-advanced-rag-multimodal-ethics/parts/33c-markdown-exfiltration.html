Risk 6 — the exfiltration channel that makes injection profitable. The classic zero-click leak (documented against multiple production assistants, 2023-2024): an injection instructs the model to emit a Markdown image whose URL query-string carries the conversation's secrets; the client auto-loads the image and the attacker's server logs the GET. It composes the whole act: poisoning plants the passage, injection issues the command, rendering ships the data. Outbound tool calls and webhooks are the same class of egress. Defence is output-side and network-side, not model-side: render only allow-listed hosts, never auto-fetch external resources, sanitize the emitted Markdown, and pin a Content-Security-Policy so the browser refuses the outbound request.
