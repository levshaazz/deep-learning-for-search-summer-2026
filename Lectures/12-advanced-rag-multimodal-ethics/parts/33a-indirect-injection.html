Риск · корпус говорит с модельюRisk · the corpus talks to the model
RAG сам приносит модели чужой текст — и модель не отличает данные от инструкций. Пассаж со строкой «игнорируй предыдущие указания и…» может быть исполнен, а не процитирован.RAG hands the model someone else’s text by design — and the model cannot tell data from instructions. A passage saying “ignore previous instructions and…” may get executed, not quoted.
  • ·Где входит — любой источник, который пишет не ты: веб-страницы, письма, тикеты, README, комментарии. Атакующему не нужен доступ к системе — достаточно, чтобы его текст нашёлся.Where it enters — any source you did not write: web pages, e-mails, tickets, READMEs, comments. The attacker needs no system access — only for their text to get retrieved.
  • ·Чем опасно — у ассистента есть инструменты и контекст пользователя: инъекция может звать инструменты, менять ответ, тихо переписывать выводы. Это косвенная инъекция: команду принесла выдача поиска, а не пользователь.Why it bites — the assistant holds tools and the user’s context: an injection can call tools, steer the answer, silently rewrite conclusions. It is indirect: the command arrived via retrieval, not from the user.
  • ✓Мера — изоляция инструкций: найденное — в отдельный, явно помеченный блок данных; системный промпт — отдельно; модель инструктирована не исполнять содержимое блока. Полный стек защит — через два слайда.Mitigation — instruction isolation: retrieved text goes into a separate, explicitly-marked data block; the system prompt stays apart; the model is told never to execute block contents. The full defence stack is two slides ahead.
Risk 4 — the security turn of the ethics act. Indirect prompt injection (Greshake et al. 2023, arXiv:2302.12173; OWASP LLM Top-10 #1): RAG's defining feature — bringing third-party text into the prompt — is exactly the attack channel. The model has no type system separating data from instructions, so a retrieved passage containing imperative text can be executed. Indirect because the attacker rides the retrieval channel: poison a page, wait for it to rank. Dangerous because assistants hold tools and user context. First-line mitigation is instruction isolation (marked data blocks, spotlighting); the defence stack slide completes it.
