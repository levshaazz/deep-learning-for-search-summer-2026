Frontier · ColPali — retrieve over the page, as an image

skip the OCR pipeline; embed the document picture directly
Frontier idea · arXiv:2407.01449
Render each document page as an image, embed it with a vision-language model into patch-level vectors, and retrieve with late interaction — ColBERT's MaxSim (L8), now over image patches.
  • ·Fixes: the classic pipeline is OCR → layout parse → chunk → embed — brittle on tables and scans. ColPali skips it: the page is the input.
  • ·Trick: a query token attends to the most similar image patch (MaxSim). The figure, the table cell, the stamp — all retrievable without transcription.
  • ·Callback: L8's late-interaction fused with L12's shared image–text space — the two frontiers meet.
  • ·Cost: one vector per image patch (hundreds–thousands per page) → the index is one–two orders of magnitude larger than a single CLIP vector — ColBERT's multi-vector tax, now per page.
