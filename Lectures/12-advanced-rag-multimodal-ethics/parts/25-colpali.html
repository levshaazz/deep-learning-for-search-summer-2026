Идея рубежа · arXiv:2407,01449Frontier idea · arXiv:2407.01449
Отрисуй каждую страницу как изображение, закодируй её визуально-языковой моделью в векторы уровня патчей и ищи через позднее взаимодействие — MaxSim из ColBERT (L8), по патчам изображения.Render each page as an image, embed it with a vision-language model into patch-level vectors, and retrieve with late interaction — ColBERT's MaxSim (L8), over image patches.
  • ·Чинит: конвейер OCR → разбор вёрстки → чанки → эмбеддинг хрупок на таблицах и сканах. ColPali его пропускает: страница и есть вход.Fixes: the OCR → layout parse → chunk → embed pipeline is brittle on tables and scans. ColPali skips it: the page is the input.
  • ·Трюк: токен запроса смотрит на самый похожий патч (MaxSim). Рисунок, ячейка таблицы, штамп — всё находимо без транскрипции.Trick: a query token attends to its most similar patch (MaxSim). Figure, table cell, stamp — all retrievable without transcription.
  • ·Отсылка: позднее взаимодействие L8 в общем пространстве изображение–текст L12 — два рубежа встречаются.Callback: L8's late-interaction in L12's shared image–text space — two frontiers meet.
  • ·Цена: один вектор на патч (сотни–тысячи на страницу) → индекс на один–два порядка больше вектора CLIP — много-векторный налог ColBERT, теперь на страницу.Cost: one vector per patch (hundreds–thousands per page) → index one–two orders larger than a single CLIP vector — ColBERT's multi-vector tax, now per page.
ColPali frontier. arXiv:2407.01449 (Faysse et al.). Render the page as an image; embed patch-level with a VLM; retrieve with late interaction (ColBERT MaxSim, L8) over patches. Skips the brittle OCR→parse→chunk pipeline. Fuses L8 late-interaction with L12 shared image-text space.
