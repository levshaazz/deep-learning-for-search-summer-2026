кросс-модальный поиск — это argmax косинусаcross-modal retrieval is argmax cosine
Определение · контрастивное предобучение изображение–текст (Radford et al., 2021)Definition · contrastive image–text pretraining (Radford et al., 2021)
$$ \text{retrieve}(\text{image}) = \operatorname*{arg\,max}_{j}\ \cos\!\big(\mathbf{e}_{\text{img}},\, \mathbf{e}_{\text{txt}}^{(j)}\big) $$

where eimg = the query image's embedding, etxt(j) = candidate caption j's embedding, cos = cosine similarity in the shared space, arg maxj = the caption index that scores highest.

  • ·Два энкодера, одно пространство — энкодер изображений \(f_{\text{img}}\) и энкодер текста \(f_{\text{txt}}\) отображают в одну и ту же систему координат, так что изображение и подпись сравнимы по косинусу.Two encoders, one space — an image encoder \(f_{\text{img}}\) and a text encoder \(f_{\text{txt}}\) map into the same coordinate system, so an image and a caption are comparable by cosine.
  • ·Поиск = argmax косинуса — вложи оба, возьми ближайшего соседа: тот же NN-поиск, что в L9 (argmax косинуса), который на масштабе идёт по ANN-индексу из L9 — теперь кросс-модальный.Retrieval = argmax cosine — embed both, take the nearest neighbour: the same NN search as L9 (argmax cosine), which at scale runs over L9's ANN index — now cross-modal.
  • ·Одна картинка говорит всё — косинусная матрица изображений против подписей; диагональ должна побеждать в каждой строке. Давай вычислим её.One figure says it all — a cosine matrix of images vs captions; the diagonal should win every row. Let's compute it.
