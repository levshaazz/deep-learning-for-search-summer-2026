Which single change is most likely to make it stop fabricating and refuse instead?
AВзять базовую модель побольше — больше параметров значит больше знаний о мире, так что она поймёт, что Quasar-9 нереален.Use a larger base model — more parameters means more world knowledge, so it will know Quasar-9 isn't real.
BЗаземлить его — найти контекст и велеть отвечать только по нему, с разрешением воздержаться, когда контекст молчит.Ground it — retrieve context and instruct it to answer only from that context, with permission to abstain when the context is silent.
CПоднять температуру сэмплирования, чтобы ответ был менее детерминированным и модель больше осторожничала.Raise the sampling temperature so the answer is less deterministic and the model hedges more.

B. Масштабирование модели не чинит выдумывание — модель побольше так же складно изобретает признаки (а сущность вымышлена, так что никакой объём обучающих данных её не содержит). Температура меняет стиль, а не заземление. Настоящее демо это показало: та же llama3.1:8b выдумывала без источника, но воздержалась, будучи заземлённой в контексте, где сказано, что базы не существует. Заземление + свобода сказать «я не знаю» и есть предохранитель — не масштаб.Scaling the model does not fix confabulation — a bigger model is just as fluent inventing features (and the entity is fictional, so no amount of training data contains it). Temperature changes style, not grounding. The real demo showed it: the same llama3.1:8b confabulated closed-book but abstained once grounded in a context that said the database does not exist. Grounding + the freedom to say “I don't know” is the control — not scale.
