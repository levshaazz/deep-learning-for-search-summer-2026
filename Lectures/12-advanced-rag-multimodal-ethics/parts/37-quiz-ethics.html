Quick check — which control?

a model confabulates features of a product that does not exist
Closed-book, your assistant invents detailed specs for the fictional “Quasar-9” database. Which single change is most likely to make it stop fabricating and refuse instead?
AUse a larger base model — more parameters means more world knowledge, so it will know Quasar-9 isn't real.
BGround it — retrieve context and instruct it to answer only from that context, with permission to abstain when the context is silent.
CRaise the sampling temperature so the answer is less deterministic and the model hedges more.
Reveal explanation
B. Scaling the model does not fix confabulation — a bigger model is just as fluent inventing features (and the entity is fictional, so no amount of training data contains it). Temperature changes style, not grounding. The real demo showed it: the same llama3.1:8b confabulated closed-book but abstained once grounded in a context that said the database does not exist. Grounding + the freedom to say “I don't know” is the control — not scale.
