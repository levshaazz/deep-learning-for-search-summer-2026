Search ≈ recommendation

PULL vs PUSH — a continuum

Search — PULL

An explicit query; an active need right now. The signal of intent is loud.

i
Drive file search

You know what you want; you type it.

Recommendation — PUSH

No query. Intent is inferred from implicit signals: watch time, dwell, clicks, history.

i
TikTok "For You"

The system guesses the query you never typed.

One continuum: explicit → implicit, with "you may also like" in the middle. Architecturally they converge — both run a candidate-generation → ranking cascade; recsys just swaps the query embedding for a user-context embedding.

Old-deck line: "all of that is search plus a little recsys — which are almost the same." The deep point is architectural convergence: the same cascade serves both, so everything you learn about ranking transfers. Recsys is search where the query is implicit. This is why the production blueprint later in the deck is drawn for "search/recsys" interchangeably.
