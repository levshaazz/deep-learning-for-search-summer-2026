Система угадывает запрос, который ты так и не набираешь.The system guesses the query you never typed.

Единый спектр: явное → неявное, с «вам также может понравиться» посередине. Архитектурно они сходятся — оба гоняют каскад генерация кандидатов → ранжирование; рекомендации просто меняют эмбеддинг запроса на эмбеддинг пользовательского контекста.One continuum: explicit → implicit, with "you may also like" in the middle. Architecturally they converge — both run a candidate-generation → ranking cascade; recsys just swaps the query embedding for a user-context embedding.

Old-deck line: "all of that is search plus a little recsys — which are almost the same." The deep point is architectural convergence: the same cascade serves both, so everything you learn about ranking transfers. Recsys is search where the query is implicit. This is why the production blueprint later in the deck is drawn for "search/recsys" interchangeably.
