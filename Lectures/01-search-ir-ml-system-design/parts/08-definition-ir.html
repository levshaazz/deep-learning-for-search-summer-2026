Definition
Information Retrieval IR · Manning, Raghavan & Schütze, 2008

Finding material — usually unstructured (text) — that satisfies an information need from within large collections.

The system stores documents; the user holds a need; the only bridge between them is a short, lossy query. IR is the discipline of building that bridge well.

Read the definition slowly. Three nouns matter: documents (what we have), need (what the user actually wants — which we never directly observe), and query (the few words they typed). The whole subject lives in the gap between need and query. "Unstructured" is doing work too: contrast with a database, where the data is typed and the query is exact — that contrast is two slides away.
