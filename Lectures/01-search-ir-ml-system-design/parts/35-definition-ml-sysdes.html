ML System Design the engineering around the model

The discipline of designing the end-to-end system in which a model lives: how the problem is framed, how data flows in, how predictions are served under a latency budget, and how the whole thing is monitored and improved over time.

The model is one component. The design question is everything around it — and that is what determines whether the system works in production and keeps working.

Define the term cleanly before the framework. The emphasis: end-to-end and over time. A static, one-shot model is not the unit of design — the lifecycle is. This sets up the six-step walkthrough next.
