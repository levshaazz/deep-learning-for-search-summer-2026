Search is not a database lookup

Two very different machines
Database (SQL) Search (IR)
Query type exact, structured predicate fuzzy, ~2–3 free words
Data typed, structured rows unstructured text
Result a set (order irrelevant) a ranked list
Correctness exact & verifiable graded & subjective
Failure mode wrong rows / error silently bad ranking

A database asks "which rows match?"; search asks "which document best answers a need it can only guess at?"

Engineers often arrive thinking search is `WHERE text LIKE '%query%'`. The killer differences: the result is an ordered list, correctness is graded and subjective, and failure is silent — a bad ranking still returns ten plausible-looking results, so nothing throws an exception. That silent-failure property is the bridge to monitoring in Part 03.
