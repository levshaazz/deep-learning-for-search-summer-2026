Поиск — это не запрос к базе данныхSearch is not a database lookup

База данных спрашивает «какие строки подходят?»; поиск спрашивает «какой документ лучше всего отвечает на потребность, о которой он может лишь догадываться?»A database asks "which rows match?"; search asks "which document best answers a need it can only guess at?"

Engineers often arrive thinking search is `WHERE text LIKE '%query%'`. The killer differences: the result is an ordered list, correctness is graded and subjective, and failure is silent — a bad ranking still returns ten plausible-looking results, so nothing throws an exception. That silent-failure property is the bridge to monitoring in Part 03.
