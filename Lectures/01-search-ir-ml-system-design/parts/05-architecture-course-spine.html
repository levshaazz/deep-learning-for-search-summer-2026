Every arrow hides one word: How? The whole course is the set of answers — classical IR, embeddings, neural retrieval, ANN, RAG.

This is the spine ported from the old Lecture 1: Get Data → Measure Similarity → Rank, with a "How?" floating over every box and arrow. Keep returning to it. When a student is lost in week 7, point at this slide and ask "which box are we in?" Acquire = crawl/index (Lecture 02); Represent = tokenisation and embeddings; Measure similarity = distance metrics and dense retrieval; Rank = learning-to-rank and re-ranking. ML System Design wraps all four boxes in a lifecycle.
