Запросы неряшливыQueries are messy

Короткие: 2–3 слова, почти без контекста. С опечатками: опечатки повсюду. Неоднозначные: python = язык или змея?Short: 2–3 words, almost no context. Misspelled: typos everywhere. Ambiguous: python = language or snake?

Запросы без результатовZero-result queries

10–20% поисков на сайтах e-commerce не возвращают ничего — обычно из-за несовпадения словаря (joggers против каталожного sweatpants), а не из-за отсутствия товара.10–20% of on-site e-commerce searches return nothing — usually vocabulary mismatch (joggers vs catalog sweatpants), not missing stock.

Релевантность движетсяRelevance moves

Свежесть: после землетрясения репортаж часовой давности бьёт идеальную страницу пятилетней давности. Персонализация: python означает разное для программиста и для герпетолога; coffee near me зависит от того, где ты стоишь.Freshness: after an earthquake, a 1-hour-old report beats a perfect 5-year-old page. Personalization: python means different things to a programmer and a herpetologist; coffee near me depends on where you stand.
