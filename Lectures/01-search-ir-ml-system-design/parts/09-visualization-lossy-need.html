потребность → запрос — это сжатие с потерямиneed → query is lossy compression

Средний веб-запрос ≈ 2.3–2.9 словаAverage web query ≈ 2.3–2.9 words

Система никогда не видит потребность — только два слова. Ранжирование — это попытка восстановить потребность из сигнала с потерями.The system never sees the need — only the two words. Ranking is the attempt to reconstruct the need from a lossy signal.

This is the single most important framing of the IR half. The user compresses a rich, context-laden need into ~2.5 words and throws away deadline, intent, reading level, language. Search must reconstruct all of that. Ask the room: "if you only had the two words, which of those five documents would you put first?" — there is no objectively correct answer, which is exactly why relevance is hard.
