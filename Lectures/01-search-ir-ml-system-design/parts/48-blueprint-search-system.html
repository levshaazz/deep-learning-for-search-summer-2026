Два мираTwo worlds

Продакшн-система поиска = офлайн (индекс и обучение) + онлайн (выдача), связанные через Feature / Index Store и петлю обратной связи. Нажмите A production search system = offline (index & train) + online (serve), linked by a Feature / Index Store and a feedback loop. Press →..

Офлайн (пакетно)Offline (batch)

Логи запросов и кликов → пайплайн признаков и индекса → обучить ранкер → реестр моделей. Работает по расписанию, вне пути запроса.Query & click logs → feature & index pipeline → train the ranker → model registry. Runs on a schedule, off the request path.

Feature / Index Store

Мост: офлайн пишет индекс и признаки пакетно; онлайн читает их с низкой задержкой. Единый источник истины убивает train/serving skew.The bridge: offline writes the index and features in batch; online reads them at low latency. One source of truth kills train/serving skew.

Онлайн (на каждый запрос)Online (per request)

Каскад: извлечение → ранжирование → переранжирование, сужая ~1000 → 100 → 10; признаки и индекс читаются из хранилища в реальном времени.The cascade: retrieval → ranking → re-rank, narrowing ~1000 → 100 → 10; features and the index are read from the store in real time.

Деплой моделиModel deploy

Обученный ранкер выкатывается из реестра в выдачу: shadow → canary → full.The trained ranker rolls out from the registry into serving: shadow → canary → full.

Маховик данныхThe data flywheel

Клики и выданные списки логируются асинхронно → возвращаются в логи → следующий цикл обучения. Система улучшает сама себя.Clicks and served lists are logged asynchronously → flow back into the logs → next training cycle. The system improves itself.
