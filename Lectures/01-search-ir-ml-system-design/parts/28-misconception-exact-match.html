Развенчиваем мифBust the myth
Что думают студентыWhat students think

«Если документ содержит все слова запроса, он обязан быть релевантным — а если хоть одного нет, релевантным быть не может»."If a document contains all the query words, it must be relevant — and if it's missing one, it can't be."

Лексическое совпадение ни необходимо, ни достаточно. Спам, набитый ключевыми словами, содержит каждое слово запроса и бесполезен (все слова есть, но нерелевантно). Лучший документ может делить с запросом ноль слов из-за синонимии (слов нет, но ответ идеальный). Пересечение термов — слабый, смещённый прокси релевантности, — вот почему мы переходим к обучаемым представлениям.Lexical match is neither necessary nor sufficient. Keyword-stuffed spam contains every query word and is useless (has all words, irrelevant). The best document may share zero words with the query because of synonymy (missing words, perfect answer). Term overlap is a weak, biased proxy for relevance — which is why we move to learned representations.

Конкретные случаи.Concrete cases.
(a) Запрос (a) Query "comfortable couch" · документ говорит · doc says "plush sofa, sleeps two" · пересечение = 0 слов · явно верный ответ (синонимия → потеря полноты). · overlap = 0 words · clearly the right answer (synonymy → recall loss).
(b) Запрос (b) Query "java" · документ · doc "java java coffee java cup java" · пересечение = идеальное (каждое слово запроса присутствует) · явно спам (переспам термами → потеря точности). · overlap = perfect (every query word present) · clearly spam (term-stuffing → precision loss).
Furnas et al. (1987) измерили согласие: двое пользователей выбирают одно и то же слово для одного понятия менее чем в 20% случаев.Furnas et al. (1987) measured agreement: two users pick the same word for the same concept under 20% of the time.

Use this right after the lexical-gap slide to drive the point home. The two failure directions: (1) spam proves overlap is not sufficient; (2) synonymy proves overlap is not necessary. Once students accept that exact match is a leaky proxy, dense retrieval stops feeling like magic and starts feeling like the obvious fix.
