Common misconception

Bust the myth
What students think

"If a document contains all the query words, it must be relevant — and if it's missing one, it can't be."

Lexical match is neither necessary nor sufficient. Keyword-stuffed spam contains every query word and is useless (has all words, irrelevant). The best document may share zero words with the query because of synonymy (missing words, perfect answer). Term overlap is a weak, biased proxy for relevance — which is why we move to learned representations.

Concrete cases.
(a) Query "comfortable couch" · doc says "plush sofa, sleeps two" · overlap = 0 words · clearly the right answer (synonymy → recall loss).
(b) Query "java" · doc "java java coffee java cup java" · overlap = perfect (every query word present) · clearly spam (term-stuffing → precision loss).
Furnas et al. (1987) measured agreement: two users pick the same word for the same concept under 20% of the time.

Use this right after the lexical-gap slide to drive the point home. The two failure directions: (1) spam proves overlap is not sufficient; (2) synonymy proves overlap is not necessary. Once students accept that exact match is a leaky proxy, dense retrieval stops feeling like magic and starts feeling like the obvious fix.
