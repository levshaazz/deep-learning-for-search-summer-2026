Building the machine

A model in a notebook is a demo. A model in production is a system — and systems rot unless you design for it.

Part 03 switches from "what is search" to "how do we ship and keep it alive." The ML System Design framework: frame → data → model → evaluate → serve → monitor. Throughout, the running example stays search/ranking, so every abstract beat has a concrete search instance.
