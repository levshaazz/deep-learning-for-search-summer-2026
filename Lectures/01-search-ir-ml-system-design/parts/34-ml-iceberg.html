The ML iceberg

Sculley et al., NeurIPS 2015

The model is just the tip.

Everything below the waterline is where systems quietly rot:

  • ·configuration · data collection
  • ·feature extraction · data verification
  • ·serving infrastructure · resource management
  • ·monitoring · process & tooling

"Only a small fraction of real-world ML systems is ML code."

The canonical Sculley 2015 figure. The famous tiny "ML code" box surrounded by huge boxes for everything else. The teaching beat: your course so far has been about the tip; this part is about the iceberg. Every box below the waterline is a place a search system fails silently — a stale config, an unverified data feed, a cold cache after deploy.
