Смещённая монета \(p=0{,}25\), Хаффман по блокам из \(n\) бросков. Один бросок целочисленным кодом стоит ровно 1 бит — тут возразить нечего. Свяжи броски по два — и средняя цена падает до 0,8438; по восемь — до 0,8158. Это ровно теорема \(H \le \bar L_n/n < H + 1/n\), увиденная глазами: пол не достигается, но к нему можно подойти как угодно близко. Слайд про смещённую монету обещал это показать — вот показано. посчитано вручную. The biased coin \(p=0.25\), Huffman over blocks of \(n\) flips. One flip in an integer code costs exactly 1 bit — no argument there. Tie the flips in pairs and the average falls to 0.8438; in eights, to 0.8158. This is exactly \(H \le \bar L_n/n < H + 1/n\) seen with the eyes: the floor is never reached, and can be approached arbitrarily closely. The biased-coin slide promised to show this — here it is. computed by hand.

Closes gap G5 and the promise made on the biased-coin slide ("block coding is what approaches 0.811 bits/symbol"), which the old deck made and never kept. Every row is a real Huffman code over the 2^n-symbol product distribution of n iid flips at p=0.25, built by gen_l17.py (data/l17-entropy.json huffman.blocks). The sequence 1.0000 → 0.8438 → 0.8229 → 0.8184 → 0.8178 → 0.8158 against the floor 0.8113 IS the source coding theorem H ≤ L̄n/n < H + 1/n. Say aloud that the price of the last few hundredths is exponential: n=8 already means a 256-symbol codebook. That cost is precisely why arithmetic coding — which behaves like n → ∞ without a codebook — won in practice.
