Worked by hand on the dyadic source (data/l17-entropy.json → source4): A=1/2, B=1/4, C=1/8, D=1/8. Entropy H = ½·1 + ¼·2 + ⅛·3 + ⅛·3 = 1.75 bits. The optimal prefix code A=0, B=10, C=110, D=111 gives average length L̄ = ½·1 + ¼·2 + ⅛·3 + ⅛·3 = 1.75 bits — EXACTLY the entropy. Why: each codeword's length equals the symbol's self-information −log2 p (1,2,3,3 bits), which happens because the probabilities are dyadic. This is the source coding theorem made concrete: the code sits on the floor. ⚠️ ЭТО СЧАСТЛИВОЕ ИСКЛЮЧЕНИЕ, а не общий случай — следующие слайды строят дерево Хаффмана на НЕдиадическом источнике, где L̄ = 2,2000 промахивается мимо H = 2,1531.
