Ответ в корпусе — а поиск проходит мимо The answer is in the corpus — and search walks past it

запрос и документ говорят об одном… в разных формах query and document say the same thing… in different forms
Тот же смысл, ноль общих строк Same meaning, zero shared strings

Пользователь ищет котята играют. В корпусе лежит ответ: котёнок играет с клубком… — тот же смысл. Но ни одна строка не совпадает: «котята»≠«котёнок», «играют»≠«играет».

A user searches котята играют (kittens play). The corpus holds the answer котёнок играет с клубком… (a kitten plays…) — the same meaning. Yet no surface string matches: “котята”≠“котёнок”, “играют”≠“играет”.

Для BM25 по формам эти два текста — чужие. Ответ есть, а keyword-поиск его не видит. Так проявляется флективность: одно слово живёт в десятке форм.

To surface-form BM25 these two texts are strangers. The answer exists, and keyword search cannot see it. This is fusionality: one word lives in a dozen forms.

Английский прощает: play/plays — общий корень play. Русский не прощает: корень скрыт за окончанием. Насколько дорого — посчитаем в Акте 2. English forgives: play/plays share the stem play. Russian does not: the root hides behind the ending. How costly — measured in Act 2.

Cold-open paradox, the same shape as L16's torn page. Query "котята играют" (kittens play, both plural/present); the answer "котёнок играет" (a kitten plays, singular/other form). Same two lemmas, zero shared surface forms — so surface-form BM25 treats them as unrelated. English's light morphology mostly gets away with it (play/plays share the stem); Russian's rich inflection does not. Act 2 measures the exact ranking failure on our toy corpus.
