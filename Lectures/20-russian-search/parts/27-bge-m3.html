Для русского это удобно: sparse-ветка ловит точные термины (имена, коды), dense-ветка — смысл поверх морфологии. Гибрид из L8 — внутри одной модели.Handy for Russian: the sparse branch catches exact terms (names, codes), the dense branch catches meaning past morphology. The L8 hybrid — inside one model.

BGE-M3 (Chen et al. 2024, arXiv:2402.03216) as the flagship multilingual retriever, and a neat callback to L7/L8. The three M's: multi-linguality (100+ languages incl. Russian, one cross-lingual space); multi-functionality (a single forward pass emits a dense embedding like L7, a learned-sparse representation like SPLADE from L8, and a multi-vector representation like ColBERT from L8); multi-granularity (up to 8192 tokens, long docs whole). For Russian this is especially useful because the sparse branch preserves exact terms — names, product codes, legal citations — where dense alone might blur them, giving you the L8 hybrid inside one model.
