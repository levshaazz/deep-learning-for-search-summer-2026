B. BM25 суммирует только по \(t \in q \cap d\). Запрос дал формы «котята», «играют»; в документе — «котёнок», «играет». Как строки они не равны, пересечение пусто → сумма пуста → ровно 0.0. Длина (A) и idf (C) не при чём: слагаемых просто нет. BM25 прекрасно работает с кириллицей (D) — проблема в морфологии, а не в алфавите. Лемматизация делает пересечение непустым. B. BM25 sums only over \(t \in q \cap d\). The query gave the forms “котята”, “играют”; the document has “котёнок”, “играет”. As strings they are unequal, so the intersection is empty → the sum is empty → exactly 0.0. Length (A) and idf (C) are irrelevant: there are simply no terms. BM25 handles Cyrillic fine (D) — the problem is morphology, not the alphabet. Lemmatization makes the intersection non-empty.
Quiz on the mechanism. Correct answer B: BM25 sums only over shared terms t ∈ q ∩ d, and no surface form matched, so the intersection is empty and the score is exactly 0.0. Distractors: A blames length normalization (the term count is zero, not a small factor), C claims zero idf (the terms are not even present), D blames Cyrillic (BM25 is alphabet-agnostic; the problem is morphology).
