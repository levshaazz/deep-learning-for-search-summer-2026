Дефолт для русского прод-поиска: лемматизированный BM25 + мультиязычный плотный, слитые RRF. Остальное — настройка под домен и бюджет.The default for Russian production search: lemmatized BM25 + a multilingual dense model, fused by RRF. The rest is domain and budget tuning.

The practitioner's decision table, tying every act together. Keyword/exact-term search → BM25 + lemmatization (cheap, transparent, fixes forms). Semantic/paraphrase → multilingual-E5/BGE-M3 (meaning past morphology, no lemmatizer). Production best baseline → hybrid (dense + lemmatized BM25 via RRF from L8) — exact terms and meaning together. Narrow Russian domain → a ru-specific model or fine-tuning. Cross-lingual ru↔en → a multilingual vector or LaBSE (one shared space). The default recommendation for Russian production search: lemmatized BM25 fused with a multilingual dense retriever by RRF; everything else is domain and budget tuning.
