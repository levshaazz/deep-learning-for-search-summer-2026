Мешок строк не знает морфологии A bag of strings knows no morphology

BM25 суммирует вклад термов, общих у запроса и документа. Если запрос — «котята», а документ — «котёнок», общего терма нет: вклад нулевой, документ даже не кандидат.BM25 sums the contribution of terms the query and document share. If the query is “котята” and the document says “котёнок”, there is no shared term: the contribution is zero, the document is not even a candidate.

  • ·Хуже: побеждает не тот. Документ, случайно повторивший точную форму запроса, обходит настоящий ответ — даже если он не по теме.Worse: the wrong doc wins. A document that happens to repeat the query’s exact form out-ranks the true answer — even when it is off-topic.
  • ·idf раскалывается. Десять форм одного слова — десять редких термов; частотная статистика размывается, веса врут.idf splinters. Ten forms of one word are ten rare terms; the frequency statistics smear and the weights lie.

Лечение — нормализация до индексации: свести и запрос, и документ к общей форме, чтобы термы совпали. Считаем это руками на следующих слайдах.The cure is to normalize before indexing: fold both query and document to a common form so terms can match. We measure it by hand next.

The mechanism of the failure. BM25 only scores shared terms, so if query "котята" and document "котёнок" share no surface string, the true answer scores zero and never enters the candidate set — while a document that echoes the exact query form, even off-topic, wins. A second harm: inverse document frequency splinters across the paradigm's ten forms, so term weights are miscalibrated. The fix is normalization applied symmetrically to query and corpus before indexing. The next two slides run BM25 on our toy corpus, surface-form then lemmatized, and watch the ranking invert.
