Gotcha 4 — the keyboard-layout typo, a uniquely Russian (bilingual-keyboard) failure. Typing "привет" without switching from the English layout yields "ghbdtn" — the same physical keys, Latin output, meaningless to the index; these queries return nothing. It is common enough that every serious Russian search stack handles it. Cure: a deterministic ЙЦУКЕН↔QWERTY key-position map (ghbdtn→привет is a one-to-one transform), applied as layout detection plus a "did you mean" correction. Cheap, deterministic, and it recovers a whole class of otherwise-dead queries.
