Act 4 as one reference table, now with the column that carries the lesson: where each cure belongs. ё/е (char_filter, both arms), case (lowercase plus a keyword field, both arms), NFC/NFD (normalize on input, both arms), homoglyphs (UTS #39 confusables, both arms), transliteration (variant dictionary plus the dense arm, query preprocessor), keyboard layout (ЙЦУКЕН↔QWERTY map, query preprocessor), stop words and negation (subtract не/ни/без from the list, index analyzer), hyphen/space (both arms). The closing line replaces the old restatement of the thesis: the "where" column matters more than the "cure" column, because a one-sided fix is measurably worse than no fix — that is exactly the 0.000 row of the ё/е ladder.
