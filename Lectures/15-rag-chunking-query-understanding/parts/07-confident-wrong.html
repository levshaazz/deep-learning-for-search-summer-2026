Уверенно ≠ верноConfident ≠ correct

почему голой LLM нельзя доверять как поисковому ответуwhy a bare LLM can't be trusted as a search answer

Три провалаThree failures

  • УстареваниеStale — параметрическая память застыла на момент обучения.parametric memory froze at training time.
  • Без ссылокUnciteable — не может указать на источник.it cannot point to a source.
  • Уверенна в любом случаеConfident either way — верный ответ и выдуманный звучат одинаково.a correct answer and a fabricated one sound identical.

Лекарство: заземлениеThe fix: grounding

Не модель побольше — поиск. Не проси модель знать; заставь её прочитать то, что мы извлекли, и отвечать только по этому, со ссылками. Это и есть цикл RAG.Not a bigger model — retrieval. Don't ask the model to know; make it read what we retrieved, then answer using only that, with citations. That is the RAG loop.

problem-ungrounded. Parametric staleness + no citation + confident hallucination. Grounding, not scale, is the fix.
