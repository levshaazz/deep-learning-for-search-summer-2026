Multi-query

спроси несколькими способами, возьми объединениеask several ways, take the union
ОпределениеDefinition
Пусть LLM перепишет запрос в несколько парафразов, извлеки top-k для каждого и верни объединение их результатов.Have an LLM rewrite the query into several paraphrases, retrieve the top-k for each, and return the union of their results.
  • ·Почему работает: каждая формулировка попадает возле разной части релевантного множества. Один запрос может пропустить «желудочковую систолу»; другой, вокруг «диастолы», её ловит. Объединение покрывает больше золотого множества — оно поднимает полноту.Why it works: each phrasing lands near a different part of the relevant set. One query might miss "ventricular systole"; another phrased around "diastole" catches it. The union covers more of the gold set — it lifts recall.
  • ·Цена: один вызов LLM, чтобы сгенерировать парафразы, затем несколько поисков вместо одного. Результаты дедуплицируются, прежде чем попасть в бюджет генератора.Cost: one LLM call to generate paraphrases, then several retrievals instead of one. The results are de-duplicated before they hit the generator's budget.
  • ·Он расширяет покрытие; следующий ход — HyDE — вместо этого меняет форму запроса. Они дополняют друг друга.It widens coverage; the next move — HyDE — instead changes the shape of the query. They are complementary.
multi-query definition. Paraphrase → retrieve each → union → recall lift. Cost: 1 LLM call + several retrievals, de-duplicated. Contrast with HyDE (shape, not coverage). The by-hand lift (0.4→0.8) is two slides on.
