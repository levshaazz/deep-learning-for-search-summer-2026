Маршрутизация отвечает на «куда должен пойти этот запрос?»; конструирование — на «какую форму должен принять этот запрос?». Вместе они превращают одну прямую трубу в небольшую систему, которая подстраивается под вопрос — без рукописного движка правил.Routing answers "where should this query go?"; construction answers "what shape should this query take?". Together they turn a single flat pipe into a small system that adapts to the question — without a hand-written rule engine.
