Closes gap G6 — the deck gave only 2^H, which is the convention students will almost never meet in practice. PPL = b^{H_b}: the base of the exponent must equal the base of the logarithm in the loss. Papers and frameworks report nats (torch.nn.functional.cross_entropy is a natural log), so their PPL is exp(loss). 1 nat = 1.4427 bits (data/l17-entropy.json natsBits). The failure mode is nasty precisely because it is quiet: 2^loss of a nats loss lands in a believable range. Also: PPL is not comparable across tokenizers or normalisations — a BPE model and a character model can never be ranked by perplexity. Attribution: the term is Jelinek–Mercer–Bahl–Baker 1977; do NOT cite Cover & Thomas, which does not contain the word.
