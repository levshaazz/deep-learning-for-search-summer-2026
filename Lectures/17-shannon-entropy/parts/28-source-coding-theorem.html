теорема Шеннона о кодировании источника (1948) Shannon's source coding theorem (1948)
Теорема · кодирование источника Theorem · source coding
Любой однозначно декодируемый (без потерь) код тратит в среднем не меньше H бит на символ — и найдётся код, тратящий меньше H+1. Any uniquely-decodable (lossless) code spends on average no fewer than H bits per symbol — and some code spends fewer than H+1.
$$ H(X) \;\le\; \bar{L} \;\lt\; H(X) + 1 $$

где L̄ — средняя длина кода. Ни один кодер не пробьёт H; хорошие подходят к нему вплотную. where L̄ = the code's average length. No coder beats H; good ones hug it.

Красная черта прибора = H. Стрелка подходит к ней, но не пересекает. The meter's red line = H. The needle nears it but never crosses.

Shannon's source coding theorem (1948): for any uniquely-decodable code, the average length L̄ is sandwiched H ≤ L̄ < H+1. So H is a hard lower bound — no lossless coder gets below it — and it is achievable to within one bit (block coding closes the gap). Fixed-width 8-bit ASCII ignores the skew and wastes bits; an optimal prefix code hugs H. This is the red floor line of the surprise meter made rigorous.
