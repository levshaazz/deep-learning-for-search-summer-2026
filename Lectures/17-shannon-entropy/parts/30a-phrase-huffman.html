A real Huffman code over the observed letter frequencies gives L̄ = 3.6923 bits/letter = 144 bits total, against 156 bits for a fixed 4-bit code and 312 for ASCII; the entropy floor is 143.0 bits. The pedagogical payload is the 1-bit gap: on a message this short the theorem's slack (< 1 bit per SYMBOL in the worst case) collapses to about one bit for the whole message, because the code is nearly complete. Also worth stating: comparing to ASCII is a category error unless you say the alphabet — the same trap as the enwik8-vs-text8 slide in act 5.
