Чему вы научитесь What you will be able to do

измерить удивление · найти его пол measure surprise · find its floor
  • ✓ Определить энтропию и собственную информацию — удивление в битах: верное событие = 0 бит, редкое = много; \(H(X) = -\sum p\log_2 p\) = ожидаемое удивление = минимум средних да/нет-вопросов. Define entropy and self-information — surprise in bits: a sure thing = 0 bits, a rare symbol = many; \(H(X) = -\sum p\log_2 p\) = expected surprise = the minimum average yes/no questions.
  • ✓ Посчитать её вручную — честная монета = 1 бит, честная кость = \(\log_2 6\) бит, а смещённая монета падает ниже 1 бита \((H \lt 1 \Rightarrow\) перекос эксплуатируем\()\). Compute it by hand — a fair coin = 1 bit, a fair die = \(\log_2 6\) bits, and a biased coin drops below 1 bit \((H \lt 1 \Rightarrow\) the skew is exploitable\()\).
  • ✓ Измерить энтропию английского и сыграть в угадайку — \(F_n\) n-граммная энтропия падает к ≈1 бит/буква; носитель угадывает ~4 из 5 букв по контексту (reported, Shannon 1951). Measure the entropy of English and play the guessing game — \(F_n\) n-gram entropy falls toward ≈1 bit/letter; a native speaker guesses ~4 of 5 letters from context (reported, Shannon 1951).
  • ✓ Увидеть кодирование источника как пол сжатия — H — жёсткий пол, который не обойдёт ни один кодер; у диадического источника оптимальный префиксный код достигает ровно \(1.75\) бита. See source coding as the compression floor — H is the hard floor no coder beats; a dyadic source's optimal prefix code hits exactly \(1.75\) bits.
  • ✓ Перейти по мосту к языковым моделям — \(H(p,q) \ge H(p)\), KL = лишние биты за неверную модель, перплексия = \(2^{H}\); обучение LM = минимизация кросс-энтропии; а IDF = собственная информация. Cross the bridge to modern LMs — \(H(p,q) \ge H(p)\), KL = the excess bits for the wrong model, perplexity = \(2^{H}\); training an LM = minimizing cross-entropy; and IDF = self-information.
Five measurable outcomes: (1) define entropy + self-information as surprise in bits (sure=0, rare=many; H = expected surprise = min avg yes/no questions); (2) compute by hand — fair coin 1 bit, die log₂6 ≈ 2.585, biased coin H<1 (exploitable); (3) measure the entropy of English and run Shannon's guessing game (79/102 letters right ⇒ ~4 of 5 determined by context, ≈1 bit/letter); (4) source coding = the hard compression floor, dyadic code hits 1.75 bits exactly; (5) the modern bridge — cross-entropy ≥ entropy, KL = excess bits, perplexity = 2^H, IDF = self-information. Each is revisited in its act.
