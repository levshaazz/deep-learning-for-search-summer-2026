state → questions

Один вызовOne call

$$\mathrm{state}\longrightarrow (Q_1\parallel Q_2\parallel Q_3)$$

\(\mathrm{state}\) — общий вход модели, \(\mathrm{state}'\) — вход после обновления кодом.\(\mathrm{state}\) is the shared model input; \(\mathrm{state}'\) is the input updated by code.

\(Q_1,Q_2,Q_3\) — отдельные типизированные вопросы. Знак \(\parallel\) означает вопросы одного вызова без зависимости по ответам.\(Q_1,Q_2,Q_3\) are separate typed questions. The \(\parallel\) sign groups questions in one call with no answer dependency.

Вопросы читают один вход. Ответ Q₁ ещё не доступен вопросу Q₂.Questions read the same input. Q₂ cannot yet read Q₁’s answer.

Зависимый шагA dependent step

$$Q_1\longrightarrow\mathrm{state}'\longrightarrow Q_2$$

Код собирает новый контекст. Для его проверки нужен следующий вызов.Code builds a new context. Checking it requires the next call.

Параллельное вычисление не доказывает независимость событий: \(P(A\cap B)=P(A)P(B\mid A)\), если \(P(A)>0\).Parallel computation does not prove event independence: \(P(A\cap B)=P(A)P(B\mid A)\), when \(P(A)>0\).
