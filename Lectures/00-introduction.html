What is

Section break into the course's big-picture motivation.
"
Search is everywhere.

the arc of Deep Learning for Search
The hook. Every product you touch runs a retrieval system underneath — web search, e-commerce, recommendations, your code editor, the chatbot answering support tickets. We will trace the whole arc: from counting words to teaching neural networks to understand meaning, store it in vector databases, and ground language models in retrieved evidence. What you will be able to do

Objectives
  • ✓ Build an end-to-end neural search / RAG pipeline, from corpus to answer.
  • ✓ Reason about classical IR versus neural retrieval, and when each wins.
  • ✓ Evaluate retrieval and ranking with proper metrics — \(\text{nDCG@}k\), MAP, MRR, \(\text{Recall@}k\).
  • ✓ Design a search system for production: latency, scale, and feedback loops.
  • ✓ Read and implement key papers behind modern retrieval.
These are the course-level outcomes — measurable skills, not topics. By the final defense you should be able to ship a small neural search system and defend your design choices with metrics.

Get the most out of lectures

Read the linked paper before class · run the lab code yourself · ask in the moment, not after.

Prerequisites & tools

  • · Python — comfortable reading and writing it.
  • · Basic ML, linear algebra, and probability.
  • · Tools: PyTorch, HuggingFace, FAISS, Elasticsearch / Solr concepts.

You do not need prior search experience — that is what the first two weeks are for.

Two halves: what the course feels like, and what you should bring. The biggest predictor of success is reading the paper before the lecture and actually running the lab code rather than just reading it.
