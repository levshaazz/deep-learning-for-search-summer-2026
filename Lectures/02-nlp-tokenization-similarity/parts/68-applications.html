The "so what" table. The point is that measure choice is task-driven and tied to representation: dense → cosine/dot, sets → Jaccard+MinHash, ranks/CF → Pearson, distributions → KL/JS/Wasserstein. RAG and semantic search (cosine on normalized sentence embeddings) are the ones you will use most this course; drift monitoring returns when we discuss production systems.
