One glyph, many tokens

emoji ZWJ & CJK

A single emoji can be several byte tokens (joined by zero-width joiners); one Chinese character is typically 2–3 byte-level tokens. Visual atom ≠ token atom.

"One character = one token" is a comfortable lie. Emoji are sequences of code points glued by zero-width joiners; a family emoji is really man+ZWJ+woman+ZWJ+girl. And under UTF-8, a Chinese character is 3 bytes, so byte-level BPE spends 2–3 tokens on it. This directly feeds the fertility / token-tax slide coming up.
