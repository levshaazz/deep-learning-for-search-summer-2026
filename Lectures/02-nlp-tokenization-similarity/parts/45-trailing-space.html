Чувствительность к концевому пробелуTrailing-space sensitivity

" the" и "the" — это разные токены. Промпт, заканчивающийся концевым пробелом, попадает вне распределения и ухудшает продолжение." the" and "the" are different tokens. A prompt ending in a trailing space lands off-distribution and degrades the completion.

Почему орфография даётся тяжелоWhy spelling is hard

«Сколько R в слове strawberry?» и «переверни эту строку» — трудны, потому что модель никогда не видит отдельных букв — только непрозрачные куски-токены — под cl100k strawberry — это str + aw + berry."How many R's in strawberry?" and "reverse this string" are hard because the model never sees individual letters — only opaque token chunks — under cl100k strawberry is str + aw + berry.

Операции на уровне символов требуют, чтобы модель запомнила буквенное содержимое каждого токена. Во время выполнения она не смотрит на буквы.Character-level operations require the model to have memorized the letter content of each token. It is not looking at letters at run time.

Both quirks come from the same fact: the model's atoms are tokens, not characters. " the" ≠ "the" because the leading-space token is a distinct id (byte-level BPE design from earlier). And counting letters in "strawberry" fails because the model sees "str"+"aw"+"berry" (cl100k), not s-t-r-a-w-... — it would have to have learned the spelling of each token. This is why letter-counting and string-reversal trip up otherwise strong models.
