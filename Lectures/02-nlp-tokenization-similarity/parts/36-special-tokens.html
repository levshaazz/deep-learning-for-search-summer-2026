Special tokens & chat templates

reserved ids the framework inserts

The classic set

  • ·[CLS] — sequence-summary slot (BERT classification).
  • ·[SEP] — separates two segments, e.g. query | document in a BERT reranker.
  • ·[PAD] — batch filler, masked out of the loss.
  • ·[MASK] — hidden position the MLM must predict (~15%).
  • ·[UNK], BOS / EOS (<s> / </s>).

Chat templates & a pitfall

ChatML uses <|im_start|> / <|im_end|>; LLaMA-3 uses <|begin_of_text|>, <|start_header_id|>, <|eot_id|>. Added by tokenizer.apply_chat_template().

!
Duplicate-BOS bug

Applying a chat template and add_special_tokens=True inserts BOS twice → degraded quality. Pick one.

Special tokens are not learned by BPE — they are reserved ids the framework inserts. The [SEP] case is your bridge to search: a BERT cross-encoder reranker takes "[CLS] query [SEP] document [SEP]" and scores relevance, which is exactly next week's topic. The duplicate-BOS bug is a real, common foot-gun in production fine-tuning pipelines.
