Using a tokenizer (HuggingFace)

from transformers import AutoTokenizer

tok = AutoTokenizer.from_pretrained("bert-base-uncased")

# Split a rare word into subword pieces (## = WordPiece continuation)
tok.tokenize("unhappiness")
# -> ['un', '##hap', '##pi', '##ness']

# Encode to integer ids (adds [CLS] ... [SEP])
tok.encode("unhappiness is unbearable")
# -> [101, 4895, 24395, 8197, 2791, 2003, 4895, 4783, 6906, 3468, 102]

# For untrusted text, disable special tokens to avoid injection
tok.encode(user_text, add_special_tokens=False)

The ## prefix marks a WordPiece continuation — a piece that attaches to the previous token rather than starting a new word.

Live this if you have a kernel. "unhappiness" is one word to a human, four tokens to BERT. .tokenize gives pieces; .encode gives ids wrapped with [CLS]/[SEP]. The last line is the security note from the brief: untrusted input should be encoded with add_special_tokens=False so an attacker cannot smuggle role-control tokens like <|im_end|>. Ids shown are illustrative of shape, not memorized values.
