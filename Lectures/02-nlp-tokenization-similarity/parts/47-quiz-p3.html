Quick check

Audience question
A model counts the wrong number of R's in "strawberry". The best single explanation is:
AIt only sees opaque token chunks, never individual letters.
BThe vocabulary is too small to contain "strawberry".
CTrailing spaces corrupted the input.
Reveal explanation
A. The atom of computation is the token, not the character — "strawberry" is typically split into straw+berry, so the model never inspects letters at run time; counting R's requires memorised spellings for every subword. B is false (byte-level fallback guarantees coverage, so an OOV "strawberry" can't happen); C is a different (real) bug.
Reinforces slide 42. The trap is C — students invoke OOV, but byte-level fallback means "strawberry" is always representable; the issue is granularity, not coverage.
