What students think

“Every token in the vocabulary has a sensible meaning.”

Some tokens are glitch tokens — e.g. SolidGoldMagikarp (a scraped Reddit username). It earned a vocabulary slot because it appeared while training the tokenizer, but was rare or absent when training the model, so its embedding stayed essentially untrained. Prompting it produces bizarre behaviour: the model repeats "distribute", refuses, or hallucinates. Lesson: the tokenizer's vocabulary and the model's training data must share the same distribution.

Concrete anchor. GPT-2 BPE token id 43453 (the leading-space variant  SolidGoldMagikarp). Rumbelow & Watkins (LessWrong, Feb 2023) documented that asking GPT-3.5 to repeat the string would return "distribute" or other nonsense; the same vocabulary entry is inert in many later models because the username vanished from filtered training data.

A vivid, famous bug. The tokenizer and the language model are trained on different (or differently filtered) corpora. A string can win a token slot during tokenizer training, then almost never appear during model training — leaving a token whose embedding never moved from initialization. Feed it in and the model behaves erratically. The takeaway is general: distribution mismatch between vocabulary and training data creates dead, dangerous tokens.
