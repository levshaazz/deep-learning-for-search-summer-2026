Токены становятся целочисленными idTokens become integer ids

«студенты открыли свои книги»"students opened their books"

«students opened their books» → токены → id 11 | 298 | 34 | 567. id — это просто индекс поиска; смысл — в эмбеддинге, на который он указывает."students opened their books" → tokens → ids 11 | 298 | 34 | 567. The id is just a lookup index; the meaning is in the embedding it points to.

Concrete and reassuring: tokenization plus a vocabulary is just a dictionary from token-string to integer. The integers are arbitrary — what matters is that the same token always gets the same id, so the embedding lookup is consistent. The semantics live entirely in the embedding vectors, which we learn later.
