Отступы несут смыслIndentation is semantic

В Python ведущий пробел и есть структура блоков. Ранние токенизаторы тратили по токену на каждый пробел, дробя код с отступами и растрачивая контекст.In Python, leading whitespace is the block structure. Early tokenizers spent one token per space, fragmenting indented code and wasting context.

GPT-3.5/4 добавили отдельные токены для серий из 4/8/16 пробелов — конкретная причина, почему они гораздо лучше справляются с кодом.GPT-3.5/4 added single tokens for runs of 4/8/16 spaces — a concrete reason they handle code far better.

Выбор формата = стоимость в токенахFormat choice = token cost

YAML обычно требует меньше токенов, чем JSON, для тех же данных — меньше пунктуации (нет фигурных скобок, меньше кавычек и запятых).YAML usually needs fewer tokens than JSON for the same data — less punctuation (no braces, fewer quotes/commas).

Совет по prompt-engineering: для промптов, где важен каждый токен, предпочитай YAML или компактные форматы; каждый сэкономленный токен — это дешевле инференс и больше полезного контекста.Prompt-engineering tip: for token-tight prompts, prefer YAML or compact formats; every saved token is cheaper inference and more usable context.

Two practical levers. First, indentation: if every space is its own token, a deeply nested function explodes in length and the model loses structure — so adding multi-space tokens directly improved code ability. Second, serialization format matters: JSON's braces, quotes and commas cost tokens that YAML avoids. These are cheap wins once you know the tokenizer is the bottleneck.
