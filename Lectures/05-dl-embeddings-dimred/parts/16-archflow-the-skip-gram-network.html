Начинаем со словаря из 8 слов и one-hot центрального слова king. Сеть собирается по одному блоку за шаг — жмите →.We start with the 8-word vocabulary and the one-hot for the centre word king. The network assembles one block per step — press →.

Появляется \(W\)The matrix \(W\) appears
$$W\in\mathbb{R}^{8\times 4}$$

Каждая строка \(W\) — это вектор одного слова. one-hot king в позиции 0 указывает на строку king (подсвечена).Each row of \(W\) is one word’s vector. The one-hot king at position 0 points at the king row (highlighted).

\(W\) = таблица поиска\(W\) = the lookup table
$$W^{\top}\mathbf{e}_{\texttt{king}} = W_{[\texttt{king}]}$$

Умножить one-hot на \(W\) — значит просто выбрать строку. Эта строка \([.485,.660,-.573,-.022]\) и есть вектор слова.Multiplying a one-hot by \(W\) just selects a row. That row \([.485,.660,-.573,-.022]\) is the word’s vector.

Проекция → logitsProjection → logits
$$z_j = W_{[j]}\cdot h\quad(j=1\ldots 8)$$

Скалярное произведение скрытого вектора с каждой строкой \(W\) (веса связаны) даёт 8 оценок.The hidden vector dotted with each row of \(W\) (tied weights) gives 8 scores, one per vocab word.

softmax
$$p_j=\frac{e^{z_j}}{\sum_k e^{z_k}},\quad \textstyle\sum p_j=1$$

Распределение по контексту: центр king (\(.174\)) исключён, поэтому топ-контекст — prince (\(.165\)), затем queen (\(.164\)). Сумма \(=1\).A distribution over context: the centre word king (\(.174\)) is excluded, so the top context word is prince (\(.165\)), then queen (\(.164\)). They sum to \(1\).

Игрушечное упрощение: мы связываем выходные веса с \(W\) (\(W'=W\)), чтобы на схеме была одна матрица; настоящий skip-gram (слайды 14–15) держит отдельную матрицу контекста \(W'\) с векторами \(u_c\). Именно из-за связывания центр king даёт максимум сам себе (скалярное произведение строки с собой), поэтому его и исключаем.Toy simplification: we tie the output weights to \(W\) (\(W'=W\)) so the figure stays one matrix; real skip-gram (slides 14–15) keeps a separate context matrix \(W'\) of \(u_c\) vectors. Tying is also why the centre word king scores highest for itself (a row dotted with itself), which is why we exclude it.

The skip-gram network drawn as a forward pass, the same figure as the book widget, but built up one block per step so the pipeline grows rather than appearing all at once. Step zero shows only the vocabulary — the eight real words king, queen, man, woman, prince, throne, cat, computer — beside the one-hot column, with king lit. Step one, the embedding matrix W appears with king's row highlighted — a single one at position zero selects exactly that row. Step two is the punchline: multiplying that one-hot by W just selects a row, so the embedding matrix literally is the lookup table, and king's row, point four eight five, point six six, minus point five seven three, minus point zero two two, is the word's vector. Step three, the tied output projection dots that hidden vector with every row of W to produce eight logits. Step four, softmax turns them into a context distribution summing to one. The largest cell, point one seven four, is king itself — the centre word — which is excluded from context prediction, so it is greyed and struck through; the top context word is therefore prince at point one six five, with queen just behind at point one six four.
