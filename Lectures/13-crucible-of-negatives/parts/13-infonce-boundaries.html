the honest reading of the bound
Three honest caveats · before we mine harder
  • ×It does not ‘maximise MI’. It saturates a \(\log N\) bound — a ceiling, not an optimum.
  • ·A bigger batch buys harder negatives only if the batch is diverse. Duplicates and near-clones add count, not difficulty.
  • ·Temperature is a knob with a cost. Too small and the gradient piles on one negative — possibly a toxic one.
Three caveats that frame the rest of the deck: InfoNCE saturates a log N bound (not MI-maximisation); batch size only helps if the batch is diverse; low τ concentrates the gradient on one negative — which foreshadows the toxic-hardest / impostor failure mode coming next.
