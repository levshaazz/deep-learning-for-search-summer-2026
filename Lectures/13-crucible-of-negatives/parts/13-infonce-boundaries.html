Три честные оговорки · прежде чем майнить труднееThree honest caveats · before we mine harder
  • ×Он не ‘максимизирует ВИ’. Он насыщает границу \(\log N\) — это потолок, а не оптимум.It does not ‘maximise MI’. It saturates a \(\log N\) bound — a ceiling, not an optimum.
  • ·Больший батч покупает более трудные негативы, только если он разнообразен. Дубликаты и почти-клоны добавляют число, а не трудность.A bigger batch buys harder negatives only if the batch is diverse. Duplicates and near-clones add count, not difficulty.
  • ·Температура — ручка с ценой. Слишком мала — и градиент сваливается на один негатив — возможно, токсичный.Temperature is a knob with a cost. Too small and the gradient piles on one negative — possibly a toxic one.
Three caveats that frame the rest of the deck: InfoNCE saturates a log N bound (not MI-maximisation); batch size only helps if the batch is diverse; low τ concentrates the gradient on one negative — which foreshadows the toxic-hardest / impostor failure mode coming next.
