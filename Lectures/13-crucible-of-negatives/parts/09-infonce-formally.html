InfoNCE: выбери позитив из NInfoNCE: pick the positive out of N

поиск как вопрос с выбором ответаretrieval as a multiple-choice question
Определение · контрастивная потеряDefinition · the contrastive loss
$$ \mathcal{L} = -\log P^+,\quad P^+ = \frac{e^{\,\cos(q,d^+)/\tau}}{e^{\,\cos(q,d^+)/\tau} + \sum_{i=1}^{N-1} e^{\,\cos(q,d_i^-)/\tau}} $$

where ℒ = the loss, q = the query, d+ = the positive, di− = the i-th negative, cos = cosine similarity, τ = temperature, N = candidates (1 positive + N−1 negatives), P+ = probability on the positive.

  • ·Вопрос с выбором ответа среди \(N\) кандидатов — 1 позитив + \(N-1\) негативов; оцени каждого по сходству, софтмакс при \(\tau\), вся вероятность на \(d^+\).A multiple-choice question over \(N\) candidates — 1 positive + \(N-1\) negatives; score each by similarity, softmax at \(\tau\), all probability on \(d^+\).
  • ·Лучшие негативы делают вопрос труднее и информативнее.Better negatives make the question harder and more informative.
  • ·\(\tau\) управляет тем, насколько резко модель вынуждают выбирать.\(\tau\) controls how sharply the model is forced to choose.
InfoNCE = softmax over N candidates = 1 positive + (N−1) negatives, at temperature τ; loss is -log P+. (N is the number of CANDIDATES the softmax chooses among — the same N as the log N ceiling on S12.)
