InfoNCE: pick the positive out of N

retrieval as a multiple-choice question
Definition · the contrastive loss
$$ \mathcal{L} = -\log P^+,\quad P^+ = \frac{e^{\,\cos(q,d^+)/\tau}}{e^{\,\cos(q,d^+)/\tau} + \sum_{i=1}^{N-1} e^{\,\cos(q,d_i^-)/\tau}} $$

where ℒ = the loss, q = the query vector, d+ = the positive passage, di− = the i-th negative, cos = cosine similarity, τ = the softmax temperature, N = the number of candidates (1 positive + N−1 negatives), P+ = the model's probability on the positive.

  • ·A multiple-choice question over \(N\) candidates — 1 positive + \(N-1\) negatives; score each by similarity, softmax at temperature \(\tau\), put all probability on \(d^+\).
  • ·Better negatives make the question harder and more informative.
  • ·\(\tau\) controls how sharply the model is forced to choose.
InfoNCE = softmax over N candidates = 1 positive + (N−1) negatives, at temperature τ; loss is -log P+. (N is the number of CANDIDATES the softmax chooses among — the same N as the log N ceiling on S12.)
