From cheap-and-static to model-mined

the first rungs are cheap; the turn is letting the model pick its own opponents

Static

  • Random — almost always easy; little gradient.
  • In-batch — reuse the other queries’ positives in the batch for free; a bigger batch buys more (and slightly harder) negatives. Local and easy.
  • BM25-hard — lexically similar passages that look right. But BM25 is model-independent, so it soon stops matching what the dense model actually confuses.

Dynamic

  • ANCE — index the whole corpus with the current model, retrieve each query’s nearest non-positives, train against those. The negatives keep up as the model improves.
  • The sparring ghosts — re-indexing is slow, so between refreshes the negatives go stale (hard→easy).
  • STAR / ADORE — go per-step: freeze the document side, train the query encoder, and the negatives stay genuinely current.
The arc, static→dynamic. ANCE is the turn that changed dense retrieval. The Sparring Ghosts (NEW mascot) = stale negatives between index refreshes. STAR/ADORE close the staleness gap per-step. Next: the darker failure — when the hardest opponent is a friend.
