Кросс-энкодер (Судьи)The Cross-encoder (Judges)

совместный вход → полное внимание → один логитjoint input → full attention → one logit

Запрос и документ читаются вместе: токены запроса смотрят на токены документа через \([\text{SEP}]\) (callback L6: внимание). Точно, но оценка — свойство пары: кэша нет. Это интервью один-на-один.Query and document are read together: query tokens attend to doc tokens across \([\text{SEP}]\) (callback L6: attention). Accurate, but the score is a property of the pair: no cache. It is a one-on-one interview.

The Judge's architecture. Concatenate CLS, the query tokens, a SEP, the document tokens, and a SEP into one joint input. Run it through the transformer with full self-attention, so query tokens attend to document tokens across the separator — the interaction a bi-encoder can never have. Read the CLS vector through a small linear head and a sigmoid into one relevance score. It is a one-on-one interview: accurate because both are read together, uncacheable for the same reason.
