Полный поиск и RAGFull search and RAG

Разведчики и Судьи — ядро. Вокруг них живёт продукт: приём → чанкование → эмбеддинг → индекс → извлечение → переранжирование → собрать контекст → LLM → ответ с цитатами. Это и есть RAG.Scouts and Judges are the core. Around them lives a product: ingest → chunk → embed → index → retrieve → rerank → assemble context → LLM → an answer with citations. That is RAG.

The last turn — from the cascade as an idea to the cascade as a product. Retrieve-then-rerank is the engine, but a real search or RAG system wraps it in a whole pipeline: ingest and chunk and embed and index offline, then retrieve and rerank and assemble and generate online. The next slides give the full pipeline as a live widget, the vector databases that store the index, the hybrid trick that makes retrieval robust, and a production checklist. This is where everything in the lecture lands in a shipping system.
