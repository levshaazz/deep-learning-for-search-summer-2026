Один вход на паруOne input per pair\([\text{CLS}]\,q_1\dots q_m\,[\text{SEP}]\,d_1\dots d_n\,[\text{SEP}]\)

where q1…qm = the m query tokens, d1…dn = the n document tokens.

Токены запроса и документа склеиваются в одну последовательность с разделителями. \([\text{CLS}]\) — «итоговый слот», его финальный вектор и станет оценкой; \([\text{SEP}]\) размечает границу. Теперь внимание может дотянуться от любого токена запроса до любого токена документа (callback L2: токены).Query and document tokens are glued into one sequence with separators. \([\text{CLS}]\) is the “summary slot” whose final vector becomes the score; \([\text{SEP}]\) marks the boundary. Now attention can reach from any query token to any document token (callback L2: tokens).

The construction, token by token. Start with CLS, append the query tokens, a SEP, the document tokens, and a final SEP. CLS is a summary slot; its final-layer vector becomes the score. The SEP markers tell the model where the query ends and the document begins. Crucially, all of these sit in one sequence, so attention can connect any query token to any document token — the next slide shows that interaction live.
