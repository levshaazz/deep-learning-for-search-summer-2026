Labs & Homework

7 activities · weeks 3–14 · 3 labs, 3 homeworks and the final project · implement by hand, measure, compare

These activities turn the lectures into working code. Each Lab is a small, hands-on build; each Homework is a deeper experimental study plus a paper-reading essay. In all of them, you implement the core retrieval and ranking algorithms by hand — that is the point. Pick an activity below.

From classical IR (BM25, rank fusion, ranking metrics) to neural retrieval — bi-/cross-encoders and the reranking cascade, ColBERT late interaction, SPLADE learned sparse, hybrid fusion, and Learning to Rank — then indexing at scale (IVF, Product Quantization, HNSW) and retrieval-augmented generation with its evaluation (chunking, query rewriting, RAGAS-style metrics, LLM-as-judge bias).

Common setup (applies to every activity)

Ground rules

  • Implement the core scoring, fusion, reranking, indexing and ranking logic by hand: the inverted index, TF-IDF, BM25, RRF, ColBERT MaxSim, the SPLADE sparse dot, RankNet/LambdaRank, the ANN index structures (IVF inverted lists + nprobe scan, PQ codes + the ADC table, the exact re-rank), RAG chunking and query-rewrite recombination, and every metric (nDCG, MAP, MRR, context precision/recall). No rank_bm25, no pytrec_eval, no library rank-fusion or learning-to-rank scorers, no faiss / hnswlib / scann / annoy or a managed vector DB, and no RAGAS/ragas library for the graded parts.
  • Allowed helpers: dataset loading (ir_datasets / beir / HuggingFace datasets), numpy, plotting, a tokenizer/stemmer, pretrained encoders (sentence-transformers, cross-encoders, SPLADE, ColBERT), k-means (sklearn) for the ANN coarse quantizer and PQ codebooks, and — where an activity allows it — a small local generator for query rewrites / judging. The encoders and generator only supply embeddings, logits or text; you do not train them, and the scoring, fusion, reranking, indexing, chunking and metric logic stays yours.
  • Be reproducible: fixed random seed (20260605), the fixed query subsets stated per activity, deterministic output. A grader must reproduce your numbers by re-running.
  • Submit code that runs end-to-end plus a short report (PDF). State every formula variant you chose (tf scheme, idf form, gain function).

Dataset & access

Activities 1 and 2 use BEIR: the Labs use nfcorpus (≈3.6K docs, 323 test queries, graded qrels); the Homeworks may additionally repeat the headline run on scifact. Lab 3 and Homework 3 instead use EnterpriseRAG-Bench (onyx-dot-app, MIT) — a synthetic enterprise corpus (Slack, Gmail, GitHub, Jira, Confluence, Drive, …) with ground-truth documents AND gold answers per question — loaded and subset inside those two activities. The neural activities also load small pretrained encoders (named per activity, all CPU-runnable on the subset). Load the BEIR corpus via ir_datasets:

import ir_datasets
ds = ir_datasets.load("beir/nfcorpus/test")     # graded relevance (0..2)
docs    = {d.doc_id: d.text for d in ds.docs_iter()}
queries = {q.query_id: q.text for q in ds.queries_iter()}
qrels   = {}
for qr in ds.qrels_iter():
    qrels.setdefault(qr.query_id, {})[qr.doc_id] = qr.relevance

Alternatives: the beir package GenericDataLoader, or HuggingFace datasets (BeIR/nfcorpus). Fixed query set: the first 30 test queries sorted by query_id for the Lab; the full test query set for the Homework. If memory is tight, restrict the corpus to documents that appear in any qrel plus a seed-20260605 random sample, and document the subsetting.
